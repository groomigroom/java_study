dto 예제 DTO.html에도 정리하기...

Spring Web: @RestController, @PostMapping, @RequestBody, @RequestMapping 등 웹 요청 처리와 REST API 개발에 필요한 핵심 기능을 제공합니다.
Lombok: @Getter, @Setter, @NoArgsConstructor, @AllArgsConstructor 어노테이션을 통해 Getter, Setter, 생성자 코드를 자동으로 컴파일 시점에 생성해 줍니다.

start dependency lombok 미리 설정하고

javaimport lombok.Getter;
import lombok.Setter;
import lombok.NoArgsConstructor;
import lombok.AllArgsConstructor;

@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
public class UserRequestDto {
    private String username;
    private String email;
    private int age;
}

컨트롤러 예제

import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/users")
public class UserController {

    @PostMapping
    public String createUser(@RequestBody UserRequestDto requestDto) {
        // 받은 DTO 데이터를 활용하는 로직
        String name = requestDto.getUsername();
        return "회원 생성 성공: " + name;
    }
}



결론부터 말씀드리면, 보내는 JSON 데이터의 키(Key) 이름과 DTO의 필드명이 정확히 일치한다면 값이 정상적으로 잘 들어옵니다.
아무 값도 들어오지 않는 것처럼 느껴지셨다면 HTTP 요청을 보낼 때 JSON 형식을 잘못 맞추었을 확률이 높습니다. 스프링이 DTO에 값을 바인딩하는 원리와 확인해야 할 점을 정리해 드립니다.
## 1. 값이 정상적으로 들어오는 JSON 요청 예시
@RequestBody는 클라이언트가 보낸 JSON 데이터를 자바 객체(DTO)로 변환합니다. 이때 필드명이 같아야 매핑이 됩니다. [1] 

* 요청 URL: POST http://localhost:8080/api/users
* HTTP Header: Content-Type: application/json
* HTTP Body (JSON):

{
  "username": "홍길동",
  "email": "hong@example.com",
  "age": 25
}


위와 같이 보낸다면 컨트롤러에서 requestDto.getUsername()을 호출했을 때 "홍길동"이 정상적으로 출력됩니다.
## 2. 값이 안 들어오는 대표적인 이유 (실수하기 쉬운 포인트)

* JSON 키 이름 불일치: JSON에서 "name": "홍길동"으로 보내면 DTO의 username 필드와 이름이 달라 값이 들어가지 않고 null이 됩니다.
* Header 미설정: 요청 헤더에 Content-Type: application/json을 설정하지 않으면 스프링이 JSON 데이터로 인식하지 못해 변환에 실패합니다.
* 타입 불일치: age 필드는 int 타입이므로 JSON에서 "age": "스물다섯"과 같이 문자열로 보내면 파싱 에러(400 Bad Request)가 발생합니다.

## 3. 스프링 내부 동작 원리 (Lombok과의 관계)
스프링은 내부적으로 Jackson이라는 라이브러리를 사용해 JSON을 자바 객체로 바꿉니다. [2, 3] 

* Jackson은 기본적으로 DTO의 Getter 또는 Setter 메서드를 기준으로 JSON의 키(Key)를 찾습니다.
* 현재 코드에 롬복의 @Getter, @Setter가 붙어있으므로 getUsername(), setUsername() 메서드가 자동으로 생성된 상태입니다.
* 따라서 스프링이 username이라는 JSON 키를 보고 setUsername()을 호출하여 값을 안전하게 넣어줍니다. [4]
