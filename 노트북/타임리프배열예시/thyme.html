---------------------------------------- 작성하신 코드는 자바 문법 오류와 타임리프 바인딩 오류로 인해 정상적으로 작동하지 않고 컴파일 에러 및 500 에러(PropertyNotFoundException)가 발생합니다. 두 가지 핵심적인 원인과 이를 올바르게 수정한 코드를 정리해 드립니다. ------------------------------ ## ❌ 작동하지 않는 이유 1. 자바의 중괄호 리터럴 초기화 오류 * 자바에서는 {"김구름", "멍멍이", "비숑"} 같은 방식의 배열 리터럴을 단독으로 대입하거나 메서드 인자로 보낼 수 없습니다. List나 String[] 배열 형태로 명확히 생성해야 합니다. 2. 타임리프(Thymeleaf) Property 객체 접근 오류 * 현재 모델에 담아 보낸 데이터는 단순 문자열(String)들의 묶음입니다. * 하지만 HTML 코드에서는 th:text="${user.name}" 처럼 user 객체 내부에 name이라는 멤버 변수(Getter)가 있는 것처럼 접근하고 있어 Property 또는 필드를 찾을 수 없다는 에러(500)가 발생합니다. 단순 문자열을 출력할 때는 ${user}만 적어야 합니다. ------------------------------ ## 🛠️ 올바르게 수정한 코드## 1. 자바 스프링 컨트롤러 수정 중괄호 대입 대신 자바의 List.of() 또는 Arrays.asList()를 사용하여 단순 문자열 리스트를 생성하도록 변경합니다. [1] package groomi.groomgroom; import org.springframework.stereotype.Controller;import org.springframework.ui.Model;import org.springframework.web.bind.annotation.GetMapping;import java.util.List; // 👈 List 임포트 필요 @Controllerpublic class HelloController { @GetMapping("hello") public String hello(Model model) { // List.of()를 사용하여 올바르게 리스트를 생성하고 담아줍니다. model.addAttribute("users", List.of("김구름", "멍멍이", "비숑")); return "hello"; } } ## 2. 타임리프 HTML 수정 리스트 원소 자체가 문자열이므로 .name 구조를 빼고 ${user}를 직접 출력하게 만듭니다.
