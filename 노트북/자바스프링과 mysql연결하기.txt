자바 스프링과 mysql 연결하기

##  1. 의존성 추가 (build.gradle)
JPA를 쓰기 위한 spring-boot-starter-data-jpa(Starter Data JPA)와 함께, MySQL 데이터베이스와 연결해 줄 MySQL Driver가 추가로 필요합니다.

dependencies {
    // 1. Spring Data JPA
    implementation 'org.springframework.boot:spring-boot-starter-data-jpa'
    
    // 2. MySQL 드라이버 (반드시 필요)
    runtimeOnly 'com.mysql:mysql-connector-j'
}

##  2. 엔티티(Entity) 예시 코드
엔티티 클래스에서 @Id와 @GeneratedValue를 아래와 같이 매핑합니다.

import jakarta.persistence.Entity;
import jakarta.persistence.GeneratedValue;
import jakarta.persistence.GenerationType;
import jakarta.persistence.Id;

@Entitypublic class User {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY) // MySQL AUTO_INCREMENT 매핑
    private Long id;

    private String name;
    
    // 기본 생성자, Getter, Setter 생략
}

##  내부 동작 원리

* strategy = GenerationType.IDENTITY로 설정하면, 자바에서 new User()로 객체를 만들 때 id 값을 비워두고(null) DB에 저장합니다.
* MySQL이 데이터를 저장(INSERT)하는 순간 자동으로 비어있는 id에 1, 2, 3... 순서대로 번호를 채워줍니다.



ddl-auto 설정을 아예 적지 않거나 none으로 설정하면, 스프링 부트는 데이터베이스 테이블을 자동으로 생성하거나 수정하지 않습니다.
이 상태에서 프로젝트를 실행하면 MySQL에 user 테이블이 존재하느냐 없느냐에 따라 결과가 완전히 달라집니다.
------------------------------
## 1. MySQL에 user 테이블이 없는 경우 ➡️ 에러 발생
자바 코드(User 엔티티)만 있고 MySQL에 실제 테이블이 없다면, 스프링 부트 실행 자체는 성공할 수 있으나 데이터를 저장하거나 조회하는 순간 에러가 발생하며 프로그램이 멈춥니다.

* 발생하는 대표적인 에러: Table '데이터베이스이름.user' doesn't exist
* 이유: JPA가 "user 테이블에서 데이터를 꺼내와라"라는 SQL을 MySQL로 보냈는데, MySQL이 "그런 테이블은 없다"라고 거절하기 때문입니다.

## 2. MySQL에 이미 user 테이블이 있는 경우 ➡️ 정상 작동
만약 과거에 프로그램을 실행해서 테이블이 이미 만들어졌거나, 본인이 MySQL WorkBench 등에서 직접 SQL로 테이블을 만들어 두었다면 아무 문제 없이 정상 작동합니다.

* 동작 방식: JPA는 자바의 User 엔티티 구조와 MySQL에 이미 존재하는 user 테이블을 그대로 매핑하여 데이터를 정상적으로 넣고 뺍니다.

## 3. 테이블은 있지만 자바 코드 구조를 바꾼 경우 ➡️ 매칭 에러 발생
ddl-auto를 끈 상태에서 자바 코드의 필드를 수정하면 DB에 반영되지 않아 에러가 납니다.

* 예시: 자바 코드에 private String email; 필드를 새로 추가함.
* 결과: ddl-auto가 없으므로 MySQL 테이블에는 email 컬럼이 생기지 않습니다. 이 상태로 데이터를 저장하거나 조회하려고 하면 컬럼 미존재 에러(Unknown column 'email' in 'field list')가 발생합니다.

------------------------------
## 💡 요약 및 실무 팁

* 개발 초기 단계: 자바 코드가 계속 변하므로 ddl-auto=update나 create를 적극적으로 사용하는 것이 편합니다.
* 실무 및 운영 단계: 실수로 데이터가 지워지거나 테이블 구조가 꼬이면 대형 사고가 나기 때문에, ddl-auto 설정을 무조건 끄거나 none으로 두고 DB 관리자가 직접 작성한 스크립트로만 테이블을 관리합니다.

------------------------------
현재 테이블 생성을 테스트해 보시는 중인가요?
만약 직접 MySQL에 테이블을 생성하는 SQL 구문(DDL)이 필요하시거나, 연결 후 원하는 대로 데이터가 들어가는지 확인하는 방법(Repository 작성 등)이 궁금하시다면 언제든 말씀해 주세요!




##  3. 설정 파일 추가 (application.yml)
src/main/resources/application.yml (또는 application.properties) 파일에 MySQL 연결 정보를 적어주어야 스프링이 정상적으로 실행됩니다.

spring:
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://localhost:3306/YOUR_DB_NAME?serverTimezone=Asia/Seoul
    username: YOUR_USERNAME
    password: YOUR_PASSWORD

  jpa:
    hibernate:
      ddl-auto: update # 엔티티 구조를 보고 DB 테이블을 자동으로 생성/수정해줍니다.
    show-sql: true     # 실행되는 SQL 쿼리를 콘솔에 보여줍니다.
