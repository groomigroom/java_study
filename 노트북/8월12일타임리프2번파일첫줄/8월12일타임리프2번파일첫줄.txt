제공해주신 코드는 스프링 부트(Spring Boot)가 아닌 순수 자카르타 
서블릿(Jakarta Servlet) 환경의 타임리프 공식 예제(GTVG) 구조입니다.
스프링 부트는 자체적으로 강력한 MVC 아키텍처와 타임리프 자동 설정을 제공하므로, 
위와 같은 복잡한 추상화 객체(IWebExchange, WebContext, Writer 등)를 직접 다룰 필요가 없습니다.
위 코드의 비즈니스 로직(데이터 바인딩 및 매핑)을 스프링 부트 방식으로 전환하여 
작동시키는 방법을 정리해 드립니다.
------------------------------
## 1. 컨트롤러 전환 (HomeController.java)
스프링 부트에서는 IGTVGController 인터페이스 구현이나 templateEngine.process() 
직접 호출이 필요 없습니다. 
@Controller 어노테이션과 Model 객체를 사용하면 스프링이 알아서 처리합니다.

package groomi.groomgroom; // 본인의 패키지 경로에 맞게 수정
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.GetMapping;
import java.util.Calendar;

@Controller
public class HomeController {

    // ControllerMappings 클래스 대신 @GetMapping으로 URL을 매핑합니다.
    @GetMapping({"/", "/home"})
    public String home(Model model) {
        
        // WebContext.setVariable 대신 스프링의 Model에 데이터를 담습니다.
        model.addAttribute("welcomeMessage", "안녕하세요! GTVG 쇼핑몰에 오신 것을 환영합니다.");
        model.addAttribute("today", Calendar.getInstance());

        // 리턴한 문자열을 바탕으로 뷰 리졸버가 templates/home.html을 찾습니다.
        return "home";
    }
}


------------------------------
## 2. 타임리프 템플릿 위치 및 수정 (home.html)
스프링 부트에서는 무조건 아래 경로에 저장해야 합니다.

* 올바른 파일 경로: src/main/resources/templates/home.html

HTML 코드는 기존 예제 코드를 그대로 사용할 수 있습니다:

<!DOCTYPE html>
<html xmlns:th="http://www.thymeleaf.org">
<head>
    <title>Good Thymes Virtual Garden</title>
    <meta http-equiv="Content-Type" content="text/html; charset=UTF-8" />
</head>
<body>

    <!-- 컨트롤러에서 넘겨준 환영 메시지 출력 -->
    <h1 th:text="${welcomeMessage}">Hello World!</h1>
  
    <p>
        현재 시간: <span th:text="${#calendar.format(today, 'yyyy년 MM월 dd일 HH시 mm분')}">1970년 1월 1일</span>
    </p>

</body>
</html>

## 3. 필수 의존성 확인 (build.gradle)
스프링 부트가 타임리프를 자동으로 인지하고 연결할 수 있도록 build.gradle에 
스타터 라이브러리가 포함되어 있는지 확인하세요.

dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-thymeleaf'
    implementation 'org.springframework.boot:spring-boot-starter-web'
}

------------------------------
## 💡 핵심 요약
서블릿 방식의 예제를 스프링 부트로 가져올 때는 "URL 매핑은 @GetMapping으로, 
데이터 전달은 Model로, 파일은 resources/templates/로 이동"하는 규칙만 기억하시면 됩니다. 
위와 같이 구조를 변경한 후 애플리케이션을 구동하여 localhost:8080/ 또는 localhost:8080/home으로 접속해 보세요.
