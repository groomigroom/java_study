@RequestParam(value = "name", required = false)은 사용자가 웹 브라우저 주소창이나 폼(Form)을 
통해 보낸 데이터(name)를 자바 스프링 컨트롤러에서 받아올 때 쓰는 도구입니다. 
이 코드는 값이 없어도 오류를 내지 않고 안전하게 처리합니다.
## 코드 구성 요소

* @RequestParam: 웹 요청의 파라미터 값을 가져옵니다.
* value = "name": 전달받을 파라미터의 이름이 "name"임을 뜻합니다.
* required = false: 이 파라미터는 필수가 아닙니다. 값이 없어도 프로그램이 멈추지 않습니다.
* String name: 전달받은 값을 저장할 변수입니다. 값이 없으면 null이 들어갑니다.
* Model model: 컨트롤러에서 만든 데이터를 뷰(화면, HTML 등)로 보낼 때 사용하는 상자입니다. [1, 2, 3, 4] 

## 동작 방식

* 값이 있는 경우: /hello?name=홍길동으로 접속하면, name 변수에 "홍길동"이 들어갑니다.
* 값이 없는 경우: /hello로 접속해도 required = false 덕분에 오류가 나지 않고, name 변수에는 null이 들어갑니다.

## 주요 특징

* 유연성: 사용자가 값을 넣지 않아도 페이지가 정상적으로 열립니다.
* 기본값 처리: 값이 없을 때 기본값을 넣고 싶다면 defaultValue = "손님"을 추가할 수 있습니다.
* 데이터 전달: model.addAttribute("msg", name);처럼 쓰면 화면에 값을 보여줄 수 있습니다.

required = true가 들어가면 해당 파라미터는 필수 항목이 됩니다. 
즉, 사용자가 URL이나 폼을 통해 name이라는 값을 반드시 보내야만 페이지가 열립니다.

## 주요 변화와 특징

* 필수값 강제: 사용자가 name 값을 보내지 않으면 스프링이 요청을 거절합니다.
* 400 에러 발생: 값이 누락되면 브라우저에 HTTP Status 400 – Bad Request 에러 화면이 뜹니다.
* 기본값 (생략 시 상태): @RequestParam은 required 옵션을 적지 않으면 기본적으로 true로 설정됩니다.

## 요청 결과 비교

* /hello?name=Tom 접속 시: 정상 작동하며 name 변수에 "Tom"이 저장됩니다.
* /hello 접속 시: name 파라미터가 없으므로 화면에 400 에러가 발생하고 서버 로그에 경고가 찍힙니다.
