postman 설치 M4

https://www.postman.com/downloads/postman-agent/

여기서 설치해야 함.

Postman을 설치하는 방법은 Postman 다운로드 페이지 접속, Mac 칩 종류에 맞는 파일 선택, 
응용 프로그램(Applications) 폴더로 이동의 3가지 핵심 단계를 거치면 됩니다.
설치 방법 상세
다운로드 페이지 접속: Postman 다운로드 페이지에 접속합니다.
Mac 칩 종류 확인 및 선택:화면 왼쪽 위 Apple 아이콘 을 눌러 '이 Mac에 관함'에서 칩 종류를 확인합니다.
M1, M2, M3 등 애플 실리콘인 경우 Mac Apple Chip을 선택합니다.인텔 CPU인 경우 Mac Intel Chip을 선택합니다.
파일 압축 해제 및 이동:다운로드된 .zip 파일을 풀어 생성된 Postman 앱을 응용 프로그램(Applications) 폴더로 드래그하여 이동합니다.




아니오, Postman Agent와 Postman 데스크톱 앱은 다른 프로그램입니다. 에이전트만 설치한다고 해서 독립된 화면이나 프로그램이 실행되는 것이 아니며, 웹 브라우저에서 Postman을 사용할 때 로컬 통신을 돕는 보조 도구일 뿐입니다. 사이트에 접속하지 않고 바로 쓰려면 에이전트가 아니라 Postman 데스크톱 앱(Desktop App)을 설치해야 합니다.차이점 비교Postman Agent (데스크톱 에이전트)백그라운드에서 실행되며 유저 인터페이스(UI)가 없습니다.브라우저 웹 버전에서 CORS 제약을 우회하거나 localhost API를 호출할 때만 쓰입니다.반드시 웹 브라우저로 Postman Web 등에 접속해 연동해야 작동합니다.Postman Desktop App (데스크톱 앱)우리가 흔히 아는 독립된 실행 프로그램입니다.설치 후 바탕화면이나 시작 메뉴에서 바로 실행하여 브라우저 접속 없이 사용할 수 있습니다.해결 방법사이트 접속 없이 독립 실행형으로 쓰시려면 Postman Downloads에서 에이전트가 아닌 'Download the App' 버튼을 눌러 정식 데스크톱 클라이언트를 다시 다운로드하여 설치하셔야 합니다.
