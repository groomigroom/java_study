제시해주신 인터페이스는 실제 Thymeleaf 공식문서(Tutorial: Using Thymeleaf)의 튜토리얼 아키텍처에서 사용하는 핵심 인터페이스(IGTVGController)입니다.
스프링 부트(Spring Boot) 환경에서 이 인터페이스를 구현하고, 요청을 받아 타임리프 템플릿을 렌더링하는 구체적인 예제 코드를 작성해 드립니다.
------------------------------
## 1. 의존성 설정 (build.gradle)
스프링 웹과 타임리프를 사용하기 위해 아래 의존성이 필요합니다.

dependencies {
    implementation 'org.springframework.boot:spring-boot-starter-thymeleaf'
    implementation 'org.springframework.boot:spring-boot-starter-web'
}

## 2. 가상 도메인 인터페이스 정의
제시해주신 인터페이스와 함께 사용되는 타임리프 내장 인터페이스들을 설정합니다.

import org.thymeleaf.ITemplateEngine;import org.thymeleaf.web.IWebExchange;import java.io.Writer;
public interface IGTVGController {
    void process(
            final IWebExchange webExchange, 
            final ITemplateEngine templateEngine,
            final Writer writer)
            throws Exception;
}

## 3. 컨트롤러 구현체 작성 (HomeController)
주어진 인터페이스를 구현하여, 비즈니스 로직(데이터 담기)과 템플릿 렌더링을 처리하는 클래스입니다.

import org.springframework.stereotype.Component;import org.thymeleaf.ITemplateEngine;import org.thymeleaf.context.WebContext;import org.thymeleaf.web.IWebExchange;import java.io.Writer;import java.time.LocalDateTime;

@Component("/home") // URL 경로와 매핑하기 위해 빈 이름을 경로로 지정public class HomeController implements IGTVGController {

    @Override
    public void process(
            final IWebExchange webExchange, 
            final ITemplateEngine templateEngine,
            final Writer writer) throws Exception {

        // 1. 타임리프 전용 WebContext 생성 (요청, 응답, 서블릿컨텍스트 포함)
        final WebContext ctx = new WebContext(webExchange);
        
        // 2. 템플릿에 전달할 데이터(Variable) 바인딩
        ctx.setVariable("welcomeMessage", "GTVG 쇼핑몰에 오신 것을 환영합니다!");
        ctx.setVariable("serverTime", LocalDateTime.now());

        // 3. "home" 이라는 이름의 템플릿 파일(home.html)을 찾아 데이터와 합쳐서 writer로 출력
        templateEngine.process("home", ctx, writer);
    }
}

## 4. 스프링 MVC와 연결하는 메인 컨트롤러
스프링 서블릿 요청(HttpServletRequest)을 타임리프의 IWebExchange 형태로 변환하여 구현체로 넘겨주는 브릿지 역할을 합니다.

import jakarta.servlet.http.HttpServletRequest;import jakarta.servlet.http.HttpServletResponse;import org.springframework.stereotype.Controller;import org.springframework.web.bind.annotation.RequestMapping;import org.thymeleaf.ITemplateEngine;import org.thymeleaf.web.IWebExchange;import org.thymeleaf.web.servlet.JakartaServletWebApplication;
import java.io.Writer;import java.util.Map;

@Controllerpublic class GtvgMainController {

    private final ITemplateEngine templateEngine;
    private final Map<String, IGTVGController> controllers;

    // 스프링이 템플릿 엔진과 IGTVGController 구현체들을 자동으로 주입함
    public GtvgMainController(ITemplateEngine templateEngine, Map<String, IGTVGController> controllers) {
        this.templateEngine = templateEngine;
        this.controllers = controllers;
    }

    @RequestMapping("/**") // 모든 요청을 받아서 처리
    public void handleRequest(HttpServletRequest request, HttpServletResponse response) throws Exception {
        
        // 1. 요청 URL 분석 (예: /home)
        String requestURI = request.getRequestURI();
        IGTVGController controller = controllers.get(requestURI);

        if (controller == null) {
            response.sendError(HttpServletResponse.SC_NOT_FOUND);
            return;
        }

        // 2. 타임리프 5버전 기준: HttpServletRequest를 IWebExchange로 변환
        JakartaServletWebApplication application = JakartaServletWebApplication.buildApplication(request.getServletContext());
        IWebExchange webExchange = application.buildExchange(request, response);

        // 3. 응답 인코딩 및 Content-Type 설정
        response.setContentType("text/html;charset=UTF-8");
        Writer writer = response.getWriter();

        // 4. 우리가 만든 컨트롤러 실행
        controller.process(webExchange, templateEngine, writer);
    }
}

## 5. 타임리프 템플릿 파일 작성 (home.html)
src/main/resources/templates/home.html 경로에 파일을 생성합니다.

<!DOCTYPE html>
<html xmlns:th="http://thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>GTVG Home</title>
</head>
<body>

    <!-- 컨트롤러에서 담은 welcomeMessage 출력 -->
    <h1 th:text="${welcomeMessage}">기본 메시지 (치환됨)</h1>
    
    <!-- 컨트롤러에서 담은 서버 시간 출력 -->
    <p>현재 서버 시간: <span th:text="${#temporals.format(serverTime, 'yyyy-MM-dd HH:mm:ss')}">2026-01-01</span></p>

</body>
</html>

------------------------------
## 💡 코드 동작 원리 요약

   1. 사용자가 http://localhost:8080/home으로 접속합니다.
   2. GtvgMainController가 모든 요청(/**)을 잡아내어 URL이 /home임을 확인합니다.
   3. 빈 이름이 /home으로 등록된 HomeController 인스턴스를 찾아 실행합니다.
   4. HomeController 내부에서 타임리프 전용 컨텍스트에 데이터를 넣고 home.html 템플릿을 구동하여 화면을 완성한 뒤 사용자 브라우저로 내보냅니다.
