자바에서 int는 정수를 저장하는 기본 자료형(Primitive Type)이고, 
Integer는 int를 감싸서 만든 래퍼 클래스(Wrapper Class, 참조 자료형)입니다. 
int는 산술 연산이 가능하고 null을 쓸 수 없지만, 
Integer는 null을 저장할 수 있고 객체용 메서드를 쓸 수 있습니다.
주요 차이점
종류: int는 기본형(Primitive), Integer는 객체/참조형(Reference)
기본값: int는 0, Integer는 null
Null 처리: int는 null 불가, Integer는 null 가능 (데이터베이스 연동 시 유용)
컬렉션 사용: int는 ArrayList 등에 직접 사용 불가, 
Integer는 제네릭(List<Integer>)에 사용 가능
속도와 메모리: int가 메모리를 적게 쓰고 더 빠름
오토박싱 (Auto-boxing)자바는 int와 Integer를 서로 자동 변환해 줍니다.
int 값을 Integer에 넣을 때: 오토박싱 발생
Integer 값을 int에 넣을 때: 언박싱(Unboxing) 발생
