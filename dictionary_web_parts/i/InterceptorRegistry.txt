org.springframework.web.servlet.config.annotation.InterceptorRegistry

스프링 부트에서 InterceptorRegistry는 애플리케이션에 적용할 인터셉터
(Interceptor)들을 등록하고 관리하는 저장소(Registry)입니다.
스프링에서 인터셉터는 컨트롤러가 실행되기 전이나 후에 웹 요청을 가로채서 
특정 작업(로그인 체크, 권한 검사, 다국어 처리 등)을 수행하는 역할을 합니다.
InterceptorRegistry는 이러한 인터셉터들을 스프링 MVC 시스템에 등록하는 
명단 장부라고 생각하시면 됩니다.

💡 작성하신 메서드의 구체적인 의미

java
public void addInterceptors(InterceptorRegistry registry) {
    registry.addInterceptor(localeChangeInterceptor());
}
코드를 사용할 때는 주의가 필요합니다.
이 메서드는 WebMvcConfigurer 인터페이스에 정의된 메서드를 오버라이딩(재정의)한 
것으로, "내가 만든 인터셉터를 웹 요청 처리 과정에 포함시켜줘"라고 스프링에 명령하는 
역할을 합니다.
• registry.addInterceptor(...): 인자로 넘겨진 인터셉터 객체를 스프링 MVC가 관리하는 
인터셉터 목록에 추가합니다.
• localeChangeInterceptor(): 앞서 작성하셨던 LocaleChangeInterceptor 빈(Bean)을 호출하여 전달합니다.
즉, 이 코드가 실행됨으로써 "사용자가 URL에 ?language=en을 붙여서 요청할 때마다, 방금 등록한 
LocaleChangeInterceptor가 작동하여 언어를 동적으로 바꾸도록 허용하겠다"라는 최종 연결 작전이 완료되는 것입니다.

⚙️ 전체적인 흐름 정리 (종합)

앞서 질문하신 내용과 이번 내용을 합치면 스프링 부트에서 다국어 변경 인터셉터가 작동하는 
전체 그림이 완성됩니다.
1. 인터셉터 생성: LocaleChangeInterceptor를 만들고, 감지할 파라미터 이름을 "language"로 정함.
2. 인터셉터 등록: addInterceptors 메서드 안에서 registry.addInterceptor(...)를 통해 
이 인터셉터를 시스템에 등록함.
3. 실행: 이제 사용자가 어떤 페이지든 ?language=ko나 ?language=en으로 요청을 보내면, 
등록된 인터셉터가 가로채서 언어 환경을 자동으로 변경함.
보통 인터셉터를 등록할 때는 특정 URL 패턴에만 적용되도록 제한하기도 합니다. 


예를 들어 모든 요청에 적용할지, 아니면 특정 주소(예: /api/**)나 정적 파일(이미지, CSS 등)은 제외할지 설정하는 방법(addPathPatterns, excludePathPatterns)이 궁금하신가요?
