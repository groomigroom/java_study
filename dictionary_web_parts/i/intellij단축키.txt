인텔리제이에서 VS Code의 Shift + Alt + ↓처럼 "현재 줄을 아래로 복사하기"를 하려면 아래 두 가지 방법 중 편한 방법을 사용하시면 됩니다.방법 1. 인텔리제이 기본 단축키 사용 (추천)인텔리제이는 복사(Copy)와 붙여넣기를 한 번에 해주는 단축키가 기본으로 지정되어 있어 방향키를 누를 필요가 없습니다. 복사하고 싶은 줄에 커서를 두고 아래 단축키를 누르세요.Windows / Linux: Ctrl + DmacOS: Cmd + D💡 참고: 커서가 있는 줄 전체가 바로 아래 줄에 그대로 복사됩니다. (블록을 지정하지 않아도 됩니다.)방법 2. 단축키 설정을 VS Code와 똑같이 바꾸기인텔리제이의 단축키 환경(Keymap) 자체를 VS Code 스타일로 통째로 바꿀 수 있습니다. 이렇게 하면 Shift + Alt + ↓를 그대로 쓸 수 있습니다.설정창 열기: 단축키 Ctrl + Alt + S (macOS는 Cmd + ,)를 누릅니다.Keymap 메뉴 이동: 왼쪽 목록 최상단에 있는 Keymap을 클릭합니다.VS Code로 변경: 우측 화면 맨 위의 드롭다운(기본값 Windows 또는 macOS)을 눌러 VSCode로 변경합니다.저장: 우측 하단의 Apply 후 OK를 누릅니다.이제 VS Code에서 쓰던 Shift + Alt + ↓ (줄 복사), Alt + ↑/↓ (줄 이동) 등의 편리한 단축키를 인텔리제이에서도 그대로 사용할 수 있습니다.혹시 스프링 부트 프로젝트 에러는 잘 해결되셨나요? 단축키 관련해서 다른 동작(예: 줄 이동, 멀티 커서 등)도 VS Code처럼 바꾸고 싶으시다면 언제든 편하게 물어보세요!
