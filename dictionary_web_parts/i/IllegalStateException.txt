전자정부프레임워크(기반이 되는 스프링/자바 환경)에서 발생하는 IllegalStateException은 
"객체나 메서드가 현재 작업을 수행하기에 부적절한(잘못된) 상태일 때" 호출되었음을 알리는 자바 표준 런타임 예외입니다.

핵심 의미

• 상태(State)의 문제: 메서드 자체의 파라미터(인자)가 잘못된 것이 아니라, 호출된 타이밍이나 객체의 내부 상태가 해당 메서드를 실행할 준비가 되지 않았음을 뜻합니다. [1] (https://translate.google.com/translate?u=https://www.quora.com/How-can-I-resolve-illegal-State-Exception-in-Java&hl=ko&sl=en&tl=ko&client=sge)
• 자바(JDK) 기본 예외: 전자정부프레임워크나 스프링이 별도로 만든 예외가 아니라, 자바 언어(JDK) 자체에서 제공하는 RuntimeException의 자식 클래스입니다. [1] (https://www.inflearn.com/community/questions/1694091/%ED%91%9C%EC%A4%80-%EC%98%88%EC%99%B8%EC%99%80-%EC%BB%A4%EC%8A%A4%ED%85%80-%EC%98%88%EC%99%B8-%EC%82%AC%EC%9A%A9-%EC%A0%84%EB%9E%B5-%EC%A7%88%EB%AC%B8?srsltid=AYCX9vKx7nPihhE7aoFlqKzg9lY8az8VU3_88JFvqwNf0YSLjQjqAZpM)

대표적인 발생 상황 예시

1. 객체가 초기화되지 않았거나 이미 종료된 경우:
	• 예: 이미 닫힌(Closed) 스트림이나 커넥션에 대해 다시 읽기/쓰기 작업을 시도할 때
2. 세션이나 생명주기(Lifecycle)가 맞지 않는 경우:
	• 예: 이미 만료되었거나 유효하지 않은 객체/이미터(Emitter)를 통해 응답을 전송하려 할 때 [1] (https://do5do.tistory.com/19)
3. 비즈니스 로직 순서 오류:
	• 예: 특정 상태(예: CREATED, READY)에서만 호출할 수 있는 메서드가 다른 상태(COMPLETED 등)에서 호출될 때

IllegalArgumentException과의 차이점

• IllegalArgumentException: 메서드에 전달된 인수(Argument/Parameter) 값 자체가 잘못되었을 때 발생합니다 (예: 음수가 들어오면 안 되는데 -1이 전달된 경우). [1] (https://developer-c.tistory.com/95)
• IllegalStateException: 인수값은 정상일 수 있으나, 현재 객체의 상태가 해당 메서드를 실행하기에 부적절할 때 발생합니다 (예: 로그인하지 않은 상태에서 정보수정 메서드를 호출한 경우). [1] (https://translate.google.com/translate?u=https://www.quora.com/How-can-I-resolve-illegal-State-Exception-in-Java&hl=ko&sl=en&tl=ko&client=sge)
만약 현재 어떤 로직이나 코드 실행 중에 이 에러가 발생했다면, 해당 에러가 발생한 구체적인 코드나 에러 스택 트레이스(Stack Trace)를 공유해 주시면 원인을 파악해 드릴 수 있습니다.
