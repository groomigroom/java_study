IOException은 자바(Java)에서 파일 읽기/쓰기, 네트워크 통신, 데이터 스트림 전송 등 입출력(I/O) 작업을 수행하는 도중 예기치 못한 에러가 발생했을 때 던져지는 예외(Exception)입니다.
## 1. IOException의 의미와 용도
스프링 부트 환경에서 파일 시스템을 다루거나 외부 API와 통신할 때 가장 자주 마주치는 예외 중 하나입니다.

* 발생 상황:
* 존재하지 않는 파일을 읽으려고 하거나, 파일 권한이 없을 때
   * ObjectMapper로 JSON 데이터를 파싱하다가 데이터 형식이 잘못되었을 때 (JsonMappingException 등이 IOException을 상속받음)
   * 네트워크 연결이 끊기거나, 상대방 서버가 다운되어 데이터를 주고받지 못할 때
* 컴파일 시점 체크: 자바의 'Checked Exception'에 해당하므로, 이 예외가 발생할 가능성이 있는 코드는 반드시 try-catch 구문으로 감싸거나 메서드 선언부에 throws IOException을 명시해야 컴파일 오류가 나지 않습니다. [1] 

## 2. 속해있는 스타터 의존성 (Start Dependency)
IOException은 스프링 부트의 스타터 의존성과 전혀 무관합니다.

* 소속 패키지: java.io.IOException
* 포함 관계: 자바 언어 자체의 기본 명세인 JDK(Java Development Kit) 내장 라이브러리에 속해 있습니다.
* 결론: 스프링 부트 설정을 건드릴 필요 없이, 순수 자바(Java) 환경이라면 언제 어디서나 바로 사용할 수 있는 기본 클래스입니다.
