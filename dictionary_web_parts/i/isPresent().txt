스프링 부트(더 정확히는 자바 8부터 도입된 표준 자바 라이브러리)에서 .isPresent()는 Optional 객체 내부에 값이 존재하는지 여부를 확인하는 메서드입니다.
값이 있으면 true, 없으면(null이면) false를 반환합니다.
스프링 부트 개발에서는 주로 데이터베이스에서 데이터를 조회한 후(예: UserRepository.findById()), "조회된 데이터가 실제로 있는지" 안전하게 체크하기 위해 가장 많이 사용됩니다.
------------------------------
## 💡 왜 사용할까요? (NullPointerException 방지)
과거에는 데이터가 없을 때 null을 반환하여, 무심코 접근했다가 프로그램이 튕기는 NullPointerException (NPE) 에러가 자주 발생했습니다. Optional과 .isPresent()를 사용하면 이런 에러를 우아하게 방지할 수 있습니다.
## 기존 방식 (Null 체크)

User user = userRepository.findById(id); // 만약 데이터가 없으면 null 반환 (가정)if (user != null) {
    System.out.println(user.getName());
}

## Optional + .isPresent() 방식

// findById는 값이 있을 수도, 없을 수도 있어서 Optional로 감싸서 반환함
Optional<User> userOptional = userRepository.findById(id);
if (userOptional.isPresent()) {
    // 1. 내부의 값을 안전하게 꺼내기 위해 .get() 사용
    User user = userOptional.get(); 
    System.out.println(user.getName());
} else {
    // 2. 값이 없을 때의 예외 처리
    System.out.println("해당 유저를 찾을 수 없습니다.");
}

------------------------------
## 🛠️ 요즘 스타일: .isPresent() 대신 사용하는 더 좋은 방법들
최근 자바/스프링 부트 개발에서는 .isPresent()로 체크하고 .get()으로 꺼내는 방식보다, 함수형 스타일의 메서드를 사용해 한 줄로 처리하는 것을 더 권장합니다. 코드가 훨씬 간결해지기 때문입니다.

   1. ifPresent() (값이 있을 때만 특정 행동 실행)
   
   userRepository.findById(id)
       .ifPresent(user -> System.out.println(user.getName()));
   
   2. orElseThrow() (값이 없으면 에러를 던지고, 있으면 바로 객체 반환) ⭐ 가장 많이 씀
   
   // 값이 있으면 바로 user에 저장되고, 없으면 괄호 안의 예외가 발생함
   User user = userRepository.findById(id)
       .orElseThrow(() -> new IllegalArgumentException("유저가 존재하지 않습니다."));
   
   3. orElse() (값이 없으면 기본값 대체)
   
   // 데이터가 없으면 빈 User 객체를 기본값으로 사용
   User user = userRepository.findById(id).orElse(new User());
   
   
------------------------------
