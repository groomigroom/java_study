MVC

        
        자바 스프링에서 mvc의 의미?
        자바 스프링에서 MVC는 애플리케이션의 역할을 Model(모델),
        View(뷰), Controller(컨트롤러) 세 가지로 나누어 개발하는 디자인 패턴(Architectural Pattern)이자, 
        이를 지원하는 웹 모듈을 의미합니다.
        화면(UI)과 비즈니스 로직(Data)을 분리해
        유지보수와 협업을 쉽게 만듭니다.
        MVC 구성 요소별 역할
        Model (모델): 애플리케이션의 데이터,
        상태 및 비즈니스 로직을 담당합니다.
        데이터베이스와 소통하며 규칙에 맞는 데이터를 가공합니다.
        View (뷰): 사용자에게 보이는 화면(HTML, JSP,
        타임리프 등)을 담당하며,
        모델이 전달한 데이터를 시각적으로 표현합니다.
        Controller (컨트롤러): 사용자의 요청을 받아 모델을 호출하고,
        처리된 결과를 뷰에 전달하여 화면을 제어하는 중간 다리 역할을 합니다.
        스프링 MVC의 핵심 작동 구조
        DispatcherServlet: 모든 클라이언트의 요청을 가장 먼저 받아들이는 프론트 컨트롤러(Front Controller)입니다.
        HandlerMapping: 요청 URL을 어떤 컨트롤러가 처리할지 찾아줍니다.
        DispatcherServlet -> Controller -> Model -> View: 컨트롤러가 로직을 처리한 뒤 뷰 이름을 반환하고,
        최종 화면이 사용자에게 응답됩니다.
