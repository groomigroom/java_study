import java.util.Map;

자바 스프링에서 Map<Key, Value>은
키(Key)와 값(Value)을 한 쌍으로 데이터를 저장하고 관리하는 자바 
표준 자료구조 인터페이스를 말합니다. 
순서 대신 이름(키)표를 붙여 빠르게 값을 찾을 때 씁니다.
핵심 특징키-값 쌍: 고유한 키로 값을 저장하고 가져옵니다.
빠른 검색: 키만 알면 데이터 위치를 바로 찾아냅니다.
중복 불가: 키는 중복될 수 없으나 값은 중복될 수 있습니다.
스프링에서의 주요 사용 목적
JSON 데이터 처리: 컨트롤러에서 클라이언트로 보낼 데이터를 동적 
JSON 객체({ "key": "value" })로 만들 때 사용합니다.
파라미터 전달: 뷰와 서비스 사이에서 여러 데이터를 묶어 전달할 때 쓰입니다.
의존성 주입(DI): 스프링이 같은 타입의 여러 빈(Bean)을 Map 형태로 한 번에 주입받아 키 
이름으로 골라 쓰게 해줍니다.


자바의 Map 인터페이스에서 put() 메서드는 맵(Map) 안에 키(Key)와 값(Value)을 한 쌍으로 묶어서 저장(추가)하거나 수정하는 의미를 가집니다.
작성하신 코드의 put 메서드는 다음과 같이 동작합니다.

1. 데이터 저장 (추가)

기존에 맵 안에 존재하지 않는 새로운 키를 넣으면, 그 키와 값을 맵에 새로 추가합니다.
• properties.put("pageUnit", "10");
→ "pageUnit"이라는 이름의 키와 "10"이라는 값을 하나의 쌍으로 맵에 저장합니다.
• properties.put("pageSize", "10");
→ "pageSize"라는 이름의 키와 "10"이라는 값을 하나의 쌍으로 맵에 저장합니다.

2. 데이터 수정 (덮어쓰기)

Map은 구조상 중복된 키를 허용하지 않습니다. 만약 이미 존재하는 키로 put()을 다시 호출하면, 기존의 값이 새로운 값으로 변경(덮어쓰기) 됩니다.
• 예를 들어, 이미 "pageUnit"이 있는 상태에서 properties.put("pageUnit", "20");을 수행하면, "pageUnit"의 값은 "10"에서 "20"으로 바뀝니다.
쉽게 비유하자면:
Map을 하나의 사물함이라고 생각하면 편합니다. put("pageUnit", "10")은 "사물함에 'pageUnit'이라는 이름표를 붙여서 '10'이라는 물건을 넣어라"라는 명령어와 같습니다.
Map에 저장된 데이터를 꺼내 쓰거나(get), 삭제하는(remove) 방법 등 다른 메서드의 사용법도 필요하시면 함께 알려드릴까요?
