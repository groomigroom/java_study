자바 스프링에서 Map<Key, Value>은 키(Key)와 값(Value)을 한 쌍으로 데이터를 저장하고 관리하는 자바 표준 자료구조 인터페이스를 말합니다. 순서 대신 이름(키)표를 붙여 빠르게 값을 찾을 때 씁니다.핵심 특징키-값 쌍: 고유한 키로 값을 저장하고 가져옵니다.빠른 검색: 키만 알면 데이터 위치를 바로 찾아냅니다.중복 불가: 키는 중복될 수 없으나 값은 중복될 수 있습니다.스프링에서의 주요 사용 목적JSON 데이터 처리: 컨트롤러에서 클라이언트로 보낼 데이터를 동적 JSON 객체({ "key": "value" })로 만들 때 사용합니다.파라미터 전달: 뷰와 서비스 사이에서 여러 데이터를 묶어 전달할 때 쓰입니다.의존성 주입(DI): 스프링이 같은 타입의 여러 빈(Bean)을 Map 형태로 한 번에 주입받아 키 이름으로 골라 쓰게 해줍니다.
