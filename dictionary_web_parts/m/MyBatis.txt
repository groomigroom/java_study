MyBatis는 iBatis의 후속 버전으로, iBatis가 구글 코드로 이전하면서 이름이 MyBatis로 변경된 같은 계열의 퍼시스턴스(Persistence) 프레임워크입니다.


주요 차이점 비교


구분	iBATIS (구버전)	MyBatis (최신/후속 버전)
개발 및 관리	Apache Software Foundation 개발 (중단됨)	Google Code 이동 후 독립/GitHub 관리 (활성 유지)
패키지 및 정의	com.ibatis.*, <!DOCTYPE sqlMap ...>	org.apache.ibatis.*, XML Schema 및 <!DOCTYPE mapper ...>
변수 표현식	#id#, $id$	#{id}, ${id} (가독성 및 안전성 개선)
파라미터/결과 매핑	parameterClass, resultClass	parameterType, resultType (직관적 네이밍)
동적 SQL 태그	제한적인 동적 SQL 지원	<if>, <choose>, <when>, <otherwise>, <foreach> 등 대폭 강화
자바 요구 버전	JDK 1.4 이상	JDK 1.5 이상 (MyBatis 3.2+ 부터는 JDK 1.6 이상)
핵심 클래스	SqlMapClient	SqlSession 및 Mapper 인터페이스 지원
스프링 연동성	기본 지원	Spring / Spring Boot 연동 최적화 및 어노테이션 기반 매퍼 지원


핵심 요약

• iBATIS: 2010년부로 개발이 중단된 구버전으로 #id# 형태의 파라미터 문법과 SqlMapClient를 사용합니다.
• MyBatis: iBATIS 3.0 이상에서 이름이 바뀐 후속 버전으로, 자바 어노테이션 지원, 향상된 동적 SQL 태그, 안전한 
바인딩(#{}) 및 Spring Boot와의 매끄러운 통합 등을 제공합니다.
상세한 아키텍처와 활용법은 back-end-developer 티스토리 블로그나 h0-0cat 티스토리 블로그에서 확인할 수 있습니다.
