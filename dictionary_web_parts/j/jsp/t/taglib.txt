전자정부표준프레임워크(eGovFrame)를 포함한 Java 기반 웹 애플리케이션의 JSP 파일 상단에 선언되는 
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core"%> 코드는 JSTL(JSP Standard Tag Library)의 
'코어(Core)' 태그 라이브러리를 해당 JSP 페이지에서 사용하겠다고 선언하는 것입니다.
이 선언을 거치면 JSP 내부에서 Java 코드(스크립틀릿 <% %>)를 직접 쓰지 않고도, HTML과 유사한 태그 
형태로 조건문, 반복문, 변수 처리 등의 로직을 구현할 수 있습니다.

1. 각 속성의 세부 의미

• <%@ taglib ... %>: JSP 지시어(Directive) 중 하나로, 외부 태그 라이브러리를 현재 JSP 페이지에 가져와 
사용하겠다는 선언입니다.
• prefix="c": 가져온 태그들을 사용할 때 붙일 접두사(이름표)를 지정합니다. 관례적으로 Core 라이브러리는 c를 사용하며, 
이후 JSP 내에서 <c:if>, <c:forEach>와 같은 형태로 사용하게 됩니다.
• uri="http://java.sun.com/jsp/jstl/core": 가져올 태그 라이브러리의 고유 식별자(주소)입니다. 톰캣 등의 
WAS(Web Application Server)는 이 URI를 보고 내부 라이브러리(JAR 파일) 안에 정의된 태그 규칙과 매핑합니다.

2. 주로 사용하는 Core 태그 예시

이 선언을 한 후 JSP 안에서 다음과 같은 태그들을 활용하여 동적 페이지를 구성합니다.
• 변수 제어 (<c:set>, <c:out>)
	• 값을 저장하거나 안전하게 출력(XSS 방지)할 때 사용합니다.
• 조건문 (<c:if>, <c:choose>)jsp
<c:if test="${not empty user}">
    <p>${user.name}님 환영합니다.</p>
</c:if>
코드를 사용할 때는 주의가 필요합니다.
• 반복문 (<c:forEach>)
	• 전자정부프레임워크에서 DB로부터 가져온 목록(List) 데이터를 화면에 뿌릴 때 가장 많이 사용됩니다.
jsp
<c:forEach var="result" items="${resultList}">
    <tr>
        <td>${result.title}</td>
        <td>${result.writer}</td>
    </tr>
</c:forEach>
코드를 사용할 때는 주의가 필요합니다.
• URL 관리 (<c:url>)
	• 웹 애플리케이션의 컨텍스트 경로(Context Path)를 자동으로 포함한 안전한 URL을 생성합니다.

3. 전자정부표준프레임워크에서의 의미

전자정부표준프레임워크는 개발 표준화를 위해 JSP 내에 Java 소스 코드가 직접 들어가는 스크립틀릿(<％ ... ％>) 
사용을 지양하고, JSTL과 EL(Expression Language, ${...}) 사용을 적극 권장합니다.
따라서 이 선언문은 전자정부프레임워크로 작성된 거의 모든 공통 컴포넌트와 샘플 프로젝트(egovframework template)의 
JSP 화면단 상단에서 필수적으로 찾아볼 수 있는 핵심 코드입니다.
이 선언과 함께 자주 쓰이는 EL 변수 표현식(${...})이나, 전자정부프레임워크 전용 태그 라이브러리인 
<ui:pagination>(페이징 처리) 등의 활용법이 추가로 필요하시면 말씀해 주세요!

<%@ taglib prefix="spring" uri="http://www.springframework.org/tags"%> 코드는 
전자정부표준프레임워크(및 Spring MVC) JSP 파일에서 Spring 프레임워크가 제공하는 
다양한 커스텀 태그(Custom Tag) 라이브러리를 사용하겠다고 선언하는 문장입니다.
이 선언을 통해 JSP 내에서 자바 코드를 직접 쓰지 않고도 태그 형태로 스프링의 강력한 
기능들을 사용할 수 있게 됩니다.

핵심 역할 및 주요 기능

1. uri="..." (라이브러리 식별)
	• 스프링 태그 라이브러리의 고유 주소입니다. 이 주소를 바탕으로 프로젝트 내에 
포함된 스프링 관련 JAR 파일에서 해당 태그 정의 파일(TLD)을 찾아 맵핑합니다.
2. prefix="spring" (접두사 지정)
	• JSP 안에서 스프링 태그를 사용할 때 앞에 붙일 이름을 정의합니다. 꼭 spring이 
아니어도 상관없지만, 관례상 spring을 사용합니다.
	• 선언 후에는 JSP 내에서 <spring:태그명 ... /> 형태로 사용합니다.

가장 자주 쓰이는 핵심 태그 예시

• 다국어 및 메시지 처리 (<spring:message>)
	• 전자정부프레임워크에서 가장 많이 쓰이는 기능입니다. 화면에 보여줄 텍스트를 하드코딩하지 
않고 메세지 프로퍼티 파일(message-common.properties 등)에서 가져와 출력합니다.
	• 예: <spring:message code="button.create" /> ➔ 다국어 설정에 따라 "등록", "Create" 
등으로 자동 변환됩니다.
• URL 경로 제어 (<spring:url>)
	• 웹 애플리케이션의 컨텍스트 루트(Context Root) 경로를 자동으로 포함하여 절대 경로를 
안전하게 생성해 줍니다.
	• 예: <spring:url value="/css/egovframework/egov.css" var="cssUrl" />
• 테마 및 HTML 탈출 (<spring:theme>, <spring:htmlEscape>)
	• 웹사이트 스타일(테마)을 동적으로 변경하거나, 보안을 위해 HTML 특수문자를 치환(XSS 방지)할 때 
사용합니다.
추가로 궁금한 특정 스프링 태그의 사용법이나 오류 해결 방법이 있다면 말씀해 주세요!
