전자정부표준프레임워크(및 일반 Java Web Application)의 JSP 파일 최상단에 선언되는 이 코드는 웹 
브라우저와 서버가 JSP 파일을 처리할 때 사용할 문자 인코딩(글자 깨짐 방지)을 지정하는 지시어(Directive)입니다.
각 속성의 구체적인 의미는 다음과 같습니다.

1. contentType="text/html; charset=utf-8"

• 브라우저 전송용 인코딩 설정: 서버가 JSP를 실행하여 생성된 HTML 결과를 웹 브라우저로 보낼 때, 브라우저에게 
"이 문서의 종류는 HTML이며, UTF-8 인코딩으로 해석해서 보여달라"고 응답 헤더(HTTP Response Header)를 통해 알리는 역할을 합니다.
• 이 설정이 누락되거나 잘못되면 브라우저에서 한글이 깨져서 보일 수 있습니다.

2. pageEncoding="utf-8"

• JSP 파일 자체의 인코딩 설정: WAS(톰캣 등)가 JSP 파일 소스 코드를 읽어서 서블릿(Java 클래스) 파일로 변환(컴파일)할 때,
이 JSP 파일이 UTF-8 형식으로 저장되어 있다고 알려주는 역할을 합니다.
• JSP 파일 내에 작성된 한글(주석, static 텍스트 등)이 변환 과정에서 깨지는 것을 방지합니다.

💡 요약

• pageEncoding: 서버가 JSP 파일을 읽을 때 필요한 인코딩
• contentType: 브라우저가 결과를 받아서 보여줄 때 필요한 인코딩
전자정부표준프레임워크는 다국어 지원 및 한글 깨짐 방지를 위해 전역 시스템 인코딩을 UTF-8로 표준화하여 사용하는 것을 권장하므로, 
생성되는 모든 JSP 파일 상단에 이 코드가 필수적으로 포함됩니다.
추가로 전자정부표준프레임워크 환경에서 한글 깨짐 현상을 겪고 계시거나, 설정 파일(web.xml 등)의 필터 설정 방식이 
궁금하시면 언제든 말씀해 주세요!
