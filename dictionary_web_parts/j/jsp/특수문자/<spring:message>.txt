전자정부프레임워크(eGovFrame) JSP 템플릿에서 <spring:message code="button.create" />는 
다국어 지원(국제화, i18n)을 위해 메시지 프로퍼티 파일에 정의된 '등록' 또는 '생성' 버튼의 텍스트를 불러오는 태그입니다.
개발자가 JSP 파일에 "등록"이라는 글자를 직접 하드코딩하지 않고, 설정된 언어(국문, 영문 등)에 따라 적절한 
텍스트가 화면에 동적으로 표시되도록 합니다.

⚙️ 동작 원리 및 구성 요소

1. JSP 태그 선언:
JSP 상단에 스프링 태그 라이브러리가 선언되어 있어야 작동합니다.jsp
<%@ taglib prefix="spring" uri="http://springframework.org" %>
코드를 사용할 때는 주의가 필요합니다.
2. 메시지 프로퍼티 파일 (Message Property Files):
전자정부프레임워크의 프로젝트 내부(보통 src/main/resources/egovframework/message/ 경로)에 언어별 프로퍼티 
파일이 존재하며, button.create라는 키(Key)값으로 실제 출력될 텍스트가 지정되어 있습니다.
	• 국문 파일 (message-common_ko.properties):properties
button.create=등록
코드를 사용할 때는 주의가 필요합니다.
	• 영문 파일 (message-common_en.properties):properties
button.create=Create
코드를 사용할 때는 주의가 필요합니다.
3. 결과 화면 변환:
사용자의 브라우저 언어 환경이나 세션 설정이 국문이면 웹 브라우저에는 <button>등록</button>으로 변환되어 출력되고, 
영문 환경이면 <button>Create</button>로 자동으로 바뀌어 출력됩니다.

💡 주요 장점

• 다국어 처리 용이: 코드 수정 없이 프로퍼티 파일만 추가하면 새로운 언어를 쉽게 지원할 수 있습니다.
• 유지보수성 향상: '등록'이라는 버튼 명칭을 일괄적으로 '추가'나 '저장'으로 변경해야 할 때, 수많은 JSP 파일을 
고칠 필요 없이 프로퍼티 파일의 값 하나만 변경하면 프로젝트 전체에 적용됩니다.
추가적으로 프로젝트 내에서 해당 메시지 파일의 정확한 경로를 찾고 싶으시거나, 새로운 메시지 코드를 추가하고 적용하는 
방법이 궁금하시면 언제든 말씀해 주세요!

전자정부 표준프레임워크의 JSP 파일에서 <spring:message code="button.search" />는 다국어 처리(국제화, 
i18n)를 위해 설정된 프로퍼티 파일에서 button.search라는 키(Key)에 해당하는 텍스트(예: "조회" 또는 "Search")를 
동적으로 불러와 화면에 출력하는 태그입니다.
이 태그는 스프링 프레임워크의 메세지 소스(MessageSource) 기능과 연동되어 작동합니다. 핵심적인 의미와 작동 방식은 다음과 같습니다.

1. 작동 원리

1. 프로퍼티 파일(Property File) 조회: 프로젝트 내의 메세지 설정 파일(예: message-common_ko.properties, 
message-common_en.properties)에서 button.search라는 이름의 키를 찾습니다.
	• 한국어 설정 파일(_ko): button.search=조회
	• 영어 설정 파일(_en): button.search=Search
2. 언어별 동적 변환: 사용자의 브라우저 언어 환경(Locale)에 맞춰, 한국어 사용자에게는 '조회'(또는 '검색'), 
영어 사용자에게는 'Search'로 자동 변환되어 화면에 렌더링됩니다.

2. 사용하는 이유

• 다국어 지원: 소스 코드를 수정하지 않고 프로퍼티 파일만 추가하면 다양한 국가의 언어를 쉽게 지원할 수 있습니다.
• 유지보수 편의성: 화면에 보이는 버튼 명칭을 '조회'에서 '검색'으로 일괄 변경해야 할 때, 수많은 JSP 파일을 일일이 
수정할 필요 없이 프로퍼티 파일의 값 하나만 변경하면 프로젝트 전체에 적용됩니다.

3. JSP 상단 필수 선언

이 태그를 사용하려면 JSP 파일 최상단에 스프링 태그 라이브러리(Taglib)가 아래와 같이 선언되어 있어야 합니다.
jsp
<%@ taglib prefix="spring" uri="http://springframework.org" %>
코드를 사용할 때는 주의가 필요합니다.
전자정부 표준프레임워크 개발 중 텍스트가 올바르게 나오지 않거나 에러가 발생하시나요? 관련하여 도움이 필요하시면 
다음 중 어떤 상황인지 알려주세요.
• 화면에 텍스트 대신 ???button.search??? 형태로 출력되는 문제
• 실제 텍스트가 저장되어 있는 프로퍼티 파일(Properties)의 위치를 찾고 싶은 경우
• 버튼 클릭 시 실행되는 자바스크립트나 컨트롤러 연동에 대한 궁금증

전자정부 표준프레임워크(eGovFrame) 기반의 JSP 및 웹 애플리케이션에서 
<spring:message code='fail.common.sql' />은 데이터베이스(DB) 처리 중 
오류(SQL 에러)가 발생했을 때 사용자에게 보여줄 안내 문구를 출력하는 태그입니다.
이 태그가 실제 화면에서 어떻게 동작하고 어떤 의미를 갖는지 요약해 드립니다.

1. 핵심 동작 원리

• 다국어 및 메시지 관리: 전자정부 표준프레임워크는 Spring의 MessageSource 기능을 
사용하여 알림 메시지들을 한곳에서 관리합니다.
• 프로퍼티 파일 참조: JSP가 실행될 때, 설정된 메시지 파일(egovMessageSource 프로퍼티 
파일 등)에서 fail.common.sql이라는 키(Key)를 찾아 그에 해당하는 값(Value)을 불러와 화면에 보여줍니다.

2. 실제 화면에 출력되는 내용 (예시)

프로퍼티 파일(예: message-common_ko.properties)의 설정에 따라 다르지만, 일반적으로 
전자정부 표준프레임워크의 기본값은 다음과 같습니다.
• 기본 설정 메시지: 데이터베이스 오류가 발생하였습니다. 관리자에게 문의하시기 바랍니다.
• 따라서 JSP가 브라우저에 랜더링될 때는 태그가 사라지고 위와 같은 에러 안내 문구가 그 
자리에 출력됩니다.

3. 주요 개발 목적

• 유지보수 편의성: 에러 메시지를 JSP 코드에 직접 적지 않고 프로퍼티 파일에서 통합 관리하므로, 
문구를 수정할 때 소스 코드를 바꿀 필요 없이 메시지 파일만 수정하면 됩니다.
• 보안성 (SQL Injection 및 정보 노출 방지): DB 오류 발생 시 실제 SQL 문이나 시스템 에러 
로그(Stack Trace)를 사용자에게 그대로 보여주면 보안상 매우 위험합니다. 이를 정제된 공통 에러 
메시지로 대체하여 시스템 내부 정보를 보호합니다.
• 다국어 지원: 사용자의 언어 환경(국문, 영문 등)에 맞춰 자동으로 해당 국가의 에러 메시지를 
보여줄 수 있습니다.
추가적으로 해당 메시지의 실제 문구를 수정하고 싶으시다면 프로젝트 내 src/main/resources 하위의 
egovframework/message/com/message-common_ko.properties (또는 이와 유사한 경로의 프로퍼티 파일)에서 
fail.common.sql 값을 찾아서 변경하시면 됩니다.
혹시 에러 메시지가 발생하는 원인(서버 로그 내용)이나 메시지 설정 파일의 위치를 찾는 데 도움이 더 필요하신가요?

• code="list.sample": 불러올 메시지의 식별자(Key)입니다. 개발자는 이 키를 통해 원하는 문자열을 지정합니다.

해당 파일 안을 열어보면 다음과 같은 형태로 Key와 Value가 매핑되어 있습니다.
properties
# message-common_ko.properties 예시
list.sample=샘플 목록

list.sample=Sample List

추가로 해당 태그를 변경하거나 다른 메시지를 추가하는 방법이 궁금하시면 말씀해 주세요!
