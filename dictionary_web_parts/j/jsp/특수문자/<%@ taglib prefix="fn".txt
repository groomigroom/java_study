<%@ taglib uri="http://java.sun.com/jsp/jstl/functions" prefix="fn" %>

JSP에서 JSTL Functions 라이브러리를 fn이라는 접두사로 사용하겠다고 선언하는 코드입니다. 
주로 문자열 길이 확인, 포함 여부, 자르기, 치환 등 문자열이나 컬렉션 처리 함수를 EL(${...}) 안에서 쓸 때 사용합니다.

구성 요소 의미

• <%@ taglib ... %>: JSP 페이지에서 외부 태그 라이브러리나 함수를 쓰겠다고 알리는 지시자입니다.
• uri="http://java.sun.com/jsp/jstl/functions": JSTL 표준 함수 라이브러리를 식별하는 고유 주소(TLD 매핑 기준)입니다. 
인터넷에 실제로 접속하는 URL이 아니라 라이브러리를 구분하는 이름표 역할을 합니다.
• prefix="fn": 해당 함수들을 호출할 때 앞에 붙일 약어(접두사)입니다. 관례적으로 fn을 씁니다. 

주요 사용 예시 (EL과 함께 사용)

fn 함수는 <fn:...> 태그 형태가 아니라 ${fn:함수명(...)} 형태로 EL 안에서 호출합니다. 
• ${fn:length(list)} : 문자열 길이 또는 리스트·배열의 크기 반환
• ${fn:contains(str, 'abc')} : 특정 문자열 포함 여부(true/false)
• ${fn:substring(str, 0, 5)} : 문자열 일부 추출
• ${fn:replace(str, 'a', 'b')} : 특정 문자열 치환
• ${fn:split(str, ',')} : 구분자로 문자열을 나눠 배열로 반환 
원하시는 특정 기능(예: 문자열 자르기, 배열 길이 확인, 공백 제거)이나 현재 사용 중인 JSP/JSTL 버전을 알려주시면, 
바로 쓸 수 있는 예제 코드를 만들어 드릴 수 있습니다.
