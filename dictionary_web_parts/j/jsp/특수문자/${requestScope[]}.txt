전자정부표준프레임워크(eGovFrame)의 JSP에서 ${requestScope[]}는 현재 HTTP 요청(Request) 영역에 
저장된 데이터(Attribute)를 동적으로 꺼내오기 위해 사용하는 EL(Expression Language, 표현 언어) 문법입니다.
일반적으로 사용하는 점(.) 표기법과 대괄호([]) 표기법의 차이를 알면 이해하기 쉽습니다.

1. 핵심 의미 및 역할

• requestScope: Java(Controller 등)에서 request.setAttribute("키", 값) 또는 model.addAttribute("키", 값)으로 
담아 보낸 데이터가 저장된 공간(Map 형태)을 가리키는 EL 내장 객체입니다.
• [] (대괄호 연산자): 점(.) 대신 사용하여 속성 이름(Key)을 변수나 특수문자가 포함된 문자열로 동적 지정할 때 사용합니다.

2. 왜 점(.) 대신 []를 사용할까?

보통은 ${requestScope.userName}처럼 점(.)을 찍어 간단히 사용하지만, 다음과 같은 특수한 경우에는 반드시 []를 써야 합니다.

사용 목적	올바른 사용 예시 ([] 사용)	설명
1. 변수명으로 동적 접근	${requestScope[keyName]}	keyName이라는 변수에 들어있는 문자열을 키값으로 사용하여 
데이터를 꺼낼 때 (따옴표 없음)
2. 특수문자(., - 등) 포함	${requestScope['user.name']}
${requestScope['login-id']}	키 이름 자체에 점(.)이나 하이픈(-)이 들어가서 점 표기법으로 읽을 수 없을 때 (따옴표 필수)
3. 숫자로 시작하는 키	${requestScope['1stData']}	변수명 규칙상 점 뒤에 숫자가 바로 올 수 없을 때


3. 실무 코드 예시

Java (Controller)
java
@RequestMapping("/example.do")
public String example(ModelMap model) {
    model.addAttribute("user.id", "admin");     // 점(.)이 포함된 키
    model.addAttribute("targetKey", "user.id"); // 동적으로 찾을 키 이름
    return "exampleView";
}
코드를 사용할 때는 주의가 필요합니다.
JSP (View)
jsp
<!-- 1. 특수문자가 포함된 키값 직접 조회 -->
아이디: ${requestScope['user.id']}  <!-- 결과: admin -->

<!-- 2. 변수를 이용해 동적으로 조회 (가장 많이 쓰이는 패턴) -->
<c:set var="key" value="${targetKey}" />
아이디: ${requestScope[key]}        <!-- 결과: admin -->
코드를 사용할 때는 주의가 필요합니다.
참고: ${requestScope[]}처럼 대괄호 안을 완전히 비워둔 채로 작성하면 문법 오류(Syntax Error)가 발생합니다. 
반드시 안에 문자열('키')이나 변수명(변수)이 들어가야 합니다.
작성 중이신 실제 JSP 코드 구문이나 발생한 오류 메시지를 공유해 주시면, 해당 코드의 정확한 동작 방식이나 해결 방법을 알려드릴 수 있습니다.
