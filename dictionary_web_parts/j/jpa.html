JPA

자바 스프링에서 JPA(Java Persistence API)를 주로 사용하는 이유
객체 지향 프로그래밍과 관계형 데이터베이스 사이의 패러다임 불일치를 해결하고,
반복적인 SQL 작성 없이 생산성을 크게 높여주기 때문입니다.
JPA를 사용하는 주요 이유객체 중심 개발: SQL 중심적인 사고에서 벗어나 자바 객체 간의 연관관계와 상속을 그대로 활용해 DB를 다룰 수 있습니다.
반복 코드 감소: CRUD(생성·조회·수정·삭제)를 위한 지루하고 반복적인 SQL 쿼리를 직접 작성할 필요가 거의 없습니다.
유지보수 용이: 데이터베이스 테이블 컬럼이 변경되어도 자바 코드의 필드나 매핑 설정만 수정하면 되므로 관리가 편해집니다.
특정 DB 종속성 완화: Spring Data JPA 같은 확장 도구를 통해 표준화된 인터페이스로 데이터베이스를 다루어 기술 독립성을 유지합니다.
