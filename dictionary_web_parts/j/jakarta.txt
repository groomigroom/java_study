자바 자카르타(Jakarta EE)의 공식 메뉴얼 및 기술 문서를 확인할 수 있는 핵심 페이지는 다음과 같습니다. 목적에 맞는 공식 사이트를 방문하여 필요한 정보를 바로 찾아보실 수 있습니다.
## 1. 공식 학습 및 튜토리얼 (가장 추천)
자카르타의 전반적인 사용법, 시작 가이드, 공식 튜토리얼을 제공하는 메인 학습 허브입니다.

* 
* [Jakarta EE Learning Hub](https://jakarta.ee/learn/)
* [Jakarta EE 공식 튜토리얼 문서](https://jakarta.ee/learn/docs/jakartaee-tutorial/current/intro/overview/overview.html): 자카르타의 핵심 기술(Servlet, Persistence, REST 등)을 코드 예제와 함께 자세히 설명해 주는 웹 매뉴얼입니다. [1, 2] 
* 

## 2. 기술 스펙 및 Javadoc (API 매뉴얼)
자카르타 버전에 따른 개별 API 사양(Specification)과 자바독(Javadoc) 표준 문서를 볼 수 있는 페이지입니다. [3] 

* 
* [Jakarta EE Specifications 전체 보기](https://jakarta.ee/specifications/): 버전별(EE 8, 9, 10, 11 등) 전체 기술 표준 목록을 제공합니다. [4] 
* [Jakarta EE API Javadoc 모음](https://jakartaee.github.io/platform/): 패키지 구조와 클래스, 메서드 상세 명세서가 정리된 개발자용 레퍼런스 페이지입니다. [3, 5, 6, 7] 
* 

## 3. 주요 개별 기술 메뉴얼 페이지
가장 자주 쓰이는 핵심 스펙의 전용 가이드 페이지입니다.

* 
* [Jakarta Servlet (서블릿 표준 기술)](https://jakarta.ee/specifications/servlet/)
* [Jakarta Server Pages (구 JSP)](https://jakarta.ee/specifications/pages/) [7, 8, 9] 
* 

조회하려는 특정 기술 스펙(예: JPA/Persistence, REST 등)이나 자카르타 버전이 따로 있으신가요? 말씀해 주시면 해당 페이지로 바로 안내해 드리겠습니다.
