스프링 부트 환경에서 io.swagger.v3.oas.models.OpenAPI는 
Swagger(OpenAPI 3.0) 문서 전체를 
대변하는 핵심 설정 객체를 의미합니다.
[1] (https://adjh54.tistory.com/561), 
[2] (https://chanhan.tistory.com/entry/Spring-Swagger-Swagger-%EC%A0%81%EC%9A%A9%ED%95%98%EA%B8%B0-%EB%B0%8F-%EA%B8%B0%EB%B3%B8-%EA%B2%BD%EB%A1%9C-%EB%B3%80%EA%B2%BD%ED%95%98%EA%B8%B0)
스프링 부트에서 springdoc-openapi 
같은 라이브러리를 사용해 API 명세서를 
자동 생성할 때, 개발자가 문서의 제목, 
설명, 버전, 보안 설정(JWT 등)을 
전역적으로 커스텀하기 위해 @Bean으로 
등록하는 자바 클래스입니다. 
[1] (https://adjh54.tistory.com/561),
[2] (https://chanhan.tistory.com/entry/Spring-Swagger-Swagger-%EC%A0%81%EC%9A%A9%ED%95%98%EA%B8%B0-%EB%B0%8F-%EA%B8%B0%EB%B3%B8-%EA%B2%BD%EB%A1%9C-%EB%B3%80%EA%B2%BD%ED%95%98%EA%B8%B0)

주요 역할과 구성 요소

이 객체는 생성될 Swagger HTML 
문서의 가장 윗부분(헤더 및 공통 설정 
영역)을 채우는 역할을 합니다.

구성 요소	메서드 및 클래스	설명
문서 기본 정보	.info(new Info())	
API 명세서의 제목(Title), 
설명(Description), 버전(Version) 설정
보안 및 인증	.components(new Components())	
JWT(Bearer), API Key, OAuth2 등 
공통 보안 스키마 정의
전역 요구사항	.addSecurityItem()	
특정 API가 아닌 모든 엔드포인트에 인증 
헤더를 기본 적용할 때 사용

다음과 같이 @Bean으로 생성하여 반환합니다.

기본 정보(Info)와 JWT 보안(Components,

각 메서드별 세부 의미

Swagger UI 화면에 아래 정보들이 시각적으로 
예쁘게 박스 형태로 배치됩니다.
• .title("표준프레임워크 DeviceAPI 연계서비스 (Hybrid App)")
	• Swagger UI 페이지의 메인 
제목으로 노출됩니다. 스마트폰의 카메라, 
GPS 등 디바이스 자원을 사용하는 연계 서비스 
API라는 것을 알려줍니다.
• .description("표준프레임워크 하이브리드앱 실행환경  - iOS / Android 하이브리드앱 Rest 서비스")
	• 제목 바로 밑에 출력되는 상세 
설명글입니다. 이 API 문서가 iOS 및 
안드로이드 앱과 연동하기 위한 REST 
API라는 목적을 명시합니다.
• .version("5.0.0")
	• 오른쪽 상단 등에 작게 표시되는 
API의 현재 버전입니다. 전자정부 
표준프레임워크 최신 v5.0.0 기반으로
개발되었음을 뜻합니다.
• .contact(new Contact().name("표준프레임워크").email("..."))
	• 담당자 연락처 정보입니다. API 
사용 중 문의 사항이 있을 때 개발자들이
연락할 수 있도록 공식 지원 메일(egovframesupport@gmail.com)이
링크 형태로 제공됩니다.
• .license(new License().name("Apache License Version 2.0").url("..."))
	• 이 오픈소스 API 소프트웨어의 
라이선스 정책을 명시합니다. 클릭 시 전자정부 
표준프레임워크 공식 포털(https://www.egovframe.go.kr)로 
이동하도록 링크가 걸립니다.
