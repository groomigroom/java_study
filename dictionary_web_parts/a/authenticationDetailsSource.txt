스프링 부트에서 authenticationDetailsSource는 로그인 요청을 보낸 사용자의 부가적인 정보(IP 주소, 세션 ID 등)를 추출하여 Authentication 객체에 담아주는 역할을 하는 컴포넌트입니다.
이 기능 역시 spring-boot-starter-security 의존성에 속해 있습니다.
------------------------------
## 1. authenticationDetailsSource의 의미와 역할

* 웹 기반 부가 정보 추출: 단순 아이디/비밀번호 외에, 현재 로그인 요청이 들어온 웹 표준 정보(HttpServletRequest)를 분석합니다.
* WebAuthenticationDetails 생성: 기본적으로 WebAuthenticationDetailsSource 구현체가 사용되며, 요청한 클라이언트의 IP 주소(remoteAddress)와 세션 ID(sessionId)를 수집하여 WebAuthenticationDetails 객체로 포장합니다.
* 보안 및 로깅 활용: 수집된 IP나 세션 정보는 추후 이상 로그인 감지, 특정 IP 차단, 혹은 로그인 이력 로그(Log)를 남길 때 유수하게 활용됩니다.

## 내부 동작 흐름 예시

// 스프링 시큐리티 내부 필터(UsernamePasswordAuthenticationFilter)의 동작 방식 예시
// 1. 아이디, 패스워드로 인증 토큰 생성
UsernamePasswordAuthenticationToken authRequest = 
    new UsernamePasswordAuthenticationToken(username, password);
// 2. authenticationDetailsSource를 통해 IP, 세션 ID 등의 부가 정보를 추출하여 토큰에 세팅
authRequest.setDetails(authenticationDetailsSource.buildDetails(request));
// 3. 이후 인증 매니저에게 전달
    authenticationManager.authenticate(authRequest);

------------------------------
## 2. 포함된 Start Dependency (의존성)
스프링 시큐리티의 웹 보안 모듈에 포함되어 있으므로, 동일하게 아래 스타터 의존성이 필요합니다.

* Gradle: implementation 'org.springframework.boot:spring-boot-starter-security'
* Maven:

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>


------------------------------
## 💡 주로 언제 사용하나요? (커스텀 활용)
기본 제공되는 IP와 세션 ID 외에, 클라이언트가 보낸 특정 HTTP 헤더 값(예: 디바이스 기기 정보, 위치 정보 등)을 추가로 추출하여 인증 객체에 저장하고 싶을 때 이 인터페이스를 상속받아 커스텀 클래스를 만들어 사용합니다.

// 예시: 커스텀 DetailsSource 구현public class CustomAuthenticationDetailsSource 
        implements AuthenticationDetailsSource<HttpServletRequest, WebAuthenticationDetails> {
    
    @Override
    public WebAuthenticationDetails buildDetails(HttpServletRequest context) {
        // 기본 IP, 세션 ID 외에 다른 헤더 정보를 추가로 추출하는 로직 정의 가능
        return new WebAuthenticationDetails(context);
    }
}

------------------------------
현재 커스텀 필터(Filter)를 생성하면서 이 코드를 접하셨나요? 아니면 로그인 성공 시 사용자의 IP를 기록하는 기능을 구현 중이신가요? 어떤 기능을 구현하기 위해 이 코드를 보고 계시는지 말씀해 주시면 추가 조언을 드리겠습니다.
