AuthenticationConfiguration은 스프링 시큐리티에서 인증 관리자(AuthenticationManager)를 생성하고 가져올 수 있도록 도와주는 설정 클래스입니다.
## 💡 AuthenticationConfiguration의 의미와 역할

* 인증 관리자 추출: 스프링 부트 3.x 버전부터는 보안 설정 시 WebSecurityConfigurerAdapter를 상속받지 않고 컴포넌트 기반으로 설정합니다. 이때 스프링이 내부적으로 관리하는 AuthenticationManager를 안전하게 꺼내 쓰기 위해 이 클래스를 주입받습니다.
* 필터와의 연결: 앞서 질문하신 LoginFilter와 같은 커스텀 로그인 필터는 사용자 인증을 위해 AuthenticationManager가 필수적입니다. 이 필터에 인증 관리자를 넘겨줄 때 핵심적인 역할을 합니다.

@Configuration
@EnableWebSecuritypublic class SecurityConfig {

    // AuthenticationConfiguration 주입받기
    private final AuthenticationConfiguration authenticationConfiguration;

    public SecurityConfig(AuthenticationConfiguration authenticationConfiguration) {
        this.authenticationConfiguration = authenticationConfiguration;
    }

    @Bean
    public AuthenticationManager authenticationManager() throws Exception {
        // 주입받은 설정 객체에서 매니저를 꺼내서 빈으로 등록
        return authenticationConfiguration.getAuthenticationManager();
    }
}

------------------------------
## 📦 속해있는 Start Dependency (의존성)
이 클래스 역시 앞서 보신 필터들과 마찬가지로 Spring Security 의존성에 포함되어 있습니다.
## Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-security'

## Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>

------------------------------
이제 addFilterBefore, LoginFilter, 그리고 AuthenticationConfiguration까지 스프링 시큐리티의 핵심 부품들이 모두 모였습니다.
혹시 이 컴포넌트들을 하나로 조립하는 전체적인 SecurityConfig 설정 클래스 코드가 필요하신가요? 원하신다면 스프링 부트 3.x 버전 기준 최신 코드로 작성해 드릴 수 있습니다.
