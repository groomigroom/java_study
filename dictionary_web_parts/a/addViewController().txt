자바 스프링 부트(Spring Boot)에서 addViewController() 메서드의 의미와 이것이 속한 스타터 의존성(Starter Dependency)에 대한 핵심 요약입니다.
------------------------------
## 1. addViewController()란 무엇인가요?
addViewController()는 앞서 살펴본 ViewControllerRegistry 클래스가 제공하는 메서드입니다. 특정 URL 요청(경로)을 데이터 처리 없이 특정 뷰(HTML 파일 등) 화면으로 즉시 연결(매핑)하는 역할을 합니다.

* 기능: 별도의 @Controller 클래스와 메서드를 만들지 않고도, 단순 페이지 이동용 라우팅 설정을 쉽고 빠르게 추가할 수 있게 해줍니다.
* 연계 사용: WebMvcConfigurer 인터페이스의 addViewControllers 메서드를 오버라이딩하여 그 내부에서 호출합니다.

@Configurationpublic class WebConfig implements WebMvcConfigurer {

    @Override
    public void addViewControllers(ViewControllerRegistry registry) {
        // "/about" 주소로 들어오면 바로 "about.html" 뷰를 보여주도록 매핑합니다.
        registry.addViewController("/about").setViewName("about");
        
        // 리다이렉트 기능도 한 줄로 구현 가능합니다.
        // "/old-path"로 들어오면 "/new-path"로 리다이렉트 시킵니다.
        registry.addRedirectViewController("/old-path", "/new-path");
    }
}

------------------------------
## 2. addViewController()는 어떤 Start Dependency에 속해있나요?
이 메서드는 스프링 MVC의 핵심 라우팅 기능에 해당하므로, 웹 기능을 담당하는 웹 스타터에 포함되어 있습니다.

* 소속 클래스: org.springframework.web.servlet.config.annotation.ViewControllerRegistry
* 추가해야 할 스타터 의존성: spring-boot-starter-web

## 🛠️ 의존성 설정 방법
Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-web'

Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>

------------------------------
현재 화면 전환이나 단순 페이지 매핑을 위해 설정을 진행 중이신가요? addViewController()를 사용할 때 화면이 정상적으로 출력되려면 타임리프(Thymeleaf) 같은 뷰 템플릿 엔진 의존성이 프로젝트에 함께 추가되어 있어야 합니다. 혹시 화면을 띄우는 과정에서 404 에러나 템플릿 파싱 에러를 겪고 계신다면 어떤 오류인지 말씀해 주세요!
