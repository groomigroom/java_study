api

api API는 Application Programming Interface(응용 프로그램 프로그래밍 인터페이스)의 약자로, 서로 다른 소프트웨어가 서로 통신하고 데이터를 주고받을 수 있게 해주는 규칙이나 도구입니다. 식당에서 손님(클라이언트)이 주문을 하면 웨이터(API)가 주방(서버)에 전달하고 음식을 다시 가져다주는 것과 비슷한 역할을 합니다. API의 핵심 특징 연결성: 프로그램과 프로그램을 이어줍니다. 규칙 제공: 정해진 방식대로 요청하고 응답을 받게 돕습니다. 은닉성: 내부 작동 방식을 몰라도 기능을 쓸 수 있습니다. 일상 속 API 예시 날씨 앱: 기상청의 데이터를 가져와 화면에 보여줍니다. 지도 연동: 배달 앱에서 가게 위치를 지도에 띄울 때 네이버나 카카오 지도를 불러옵니다. 간편 로그인: 다른 웹사이트에서 '카카오로 로그인'을 누르면 인증 정보를 받아옵니다.
