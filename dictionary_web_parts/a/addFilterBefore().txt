addFilterBefore는 스프링 시큐리티(Spring Security)에서 특정 필터의 실행 순서를 커스텀 필터보다 앞서도록 지정하는 메서드입니다.
## 💡 addFilterBefore의 의미
스프링 시큐리티는 요청이 들어오면 여러 개의 필터가 사슬처럼 엮인 필터 체인(Filter Chain)을 거치게 합니다.

* 기본적으로 제공되는 인증/인가 필터들이 있습니다.
* 개발자가 직접 만든 커스텀 필터(예: JWT 토큰 검증 필터)를 기본 필터보다 먼저 실행하고 싶을 때 이 메서드를 사용합니다.
* 예를 들어, UsernamePasswordAuthenticationFilter가 작동하여 로그인 처리를 하기 전에, 요청 헤더의 JWT 토큰을 먼저 검증하고 싶을 때 사용합니다.

// 예시: JWT 필터를 로그인 필터 앞에 추가
http.addFilterBefore(jwtAuthenticationFilter, UsernamePasswordAuthenticationFilter.class);

------------------------------
## 📦 속해있는 Start Dependency (의존성)
이 메서드를 사용하기 위해 프로젝트 구성 파일(build.gradle 또는 pom.xml)에 추가해야 하는 스프링 부트 스타터 의존성은 Spring Security입니다. [1, 2, 3] 
## Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-security'

## Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>
