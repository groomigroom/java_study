질문하신 코드는 Spring Security에서 권한이 없는 사용자가 보호된 리소스에 접근하려 할 때(403 Forbidden 오류) 처리할 행동을 정의하는 코드입니다. [1, 2] 
각 질문에 대한 상세한 답변을 정리해 드립니다.
------------------------------
## 1. 코드의 의미

accessDeniedHandler((request, response, authException) -> {})


* 
* 의미: 로그인(인증)은 성공했으나, 해당 페이지나 API를 호출할 권한(Role/Authority)이 부족할 때 동작하는 커스텀 핸들러를 등록하는 것입니다. [1, 3] 
* 동작: 람다식 내부({})가 비어 있으므로, 현재 상태로는 권한 부족 예외가 발생하더라도 아무런 처리를 하지 않고 흰 화면이나 무응답 상태가 됩니다. 보통 이 안에서 "권한이 없습니다"라는 JSON 메시지를 보내거나 특정 에러 페이지로 리다이렉트하는 코드를 작성합니다. [3, 4] 
* 

## 2. 소속 Starter Dependency (의존성)
이 기능은 Spring Boot의 spring-boot-starter-security 라이브러리에 속해 있습니다.

* 
* Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>

* Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-security'

[5] 
*

## 3. 각 매개변수(Parameter) 3개의 역할
AccessDeniedHandler 인터페이스의 handle 메서드가 가진 3개의 파라미터입니다. (질문 내용의 authException은 통상적으로 accessDeniedException으로 명시하지만 역할은 같습니다.) [6, 7, 8] 

| 매개변수 | 타입 | 역할 |
|---|---|---|
| request | HttpServletRequest | 클라이언트가 보낸 HTTP 요청 정보를 담고 있습니다. 사용자가 어떤 URL(request.getRequestURI())을 요청하다가 거부당했는지 파악하거나, 세션 정보를 확인할 때 사용합니다. |
| response | HttpServletResponse | 클라이언트에게 보낼 HTTP 응답 정보를 제어합니다. 상태 코드를 403으로 지정하거나(setStatus(403)), JSON 에러 메시지를 본문에 쓰거나(getWriter().write()), 다른 페이지로 리다이렉트(sendRedirect()) 시킬 때 사용합니다. |
| authException (또는 accessDeniedException) | AccessDeniedException | 권한 부족으로 인해 발생한 구체적인 예외(에러) 정보를 담고 있습니다. 왜 접근이 거부되었는지 로그를 남기거나(e.getMessage()), 에러의 세부 원인을 분석할 때 참조합니다. |

## 💡 실무 활용 예시 (JSON 응답 반환)
실제 백엔드 API 서버를 개발할 때는 대개 아래와 같이 response 객체를 이용해 클라이언트에게 에러 코드를 던져주는 방식으로 채웁니다. [9, 10] 

.accessDeniedHandler((request, response, accessDeniedException) -> {
    response.setStatus(HttpServletResponse.SC_FORBIDDEN); // 403 지정
    response.setContentType("application/json;charset=UTF-8");
    response.getWriter().write("{\"error\": \"접근 권한이 없습니다.\"}");
})

인가(Authorization) 실패 외에 로그인 자체를 하지 않은 사용자(401 UnAuthorized)에 대한 실패 처리도 필요하신가요? 그렇다면 AuthenticationEntryPoint 설정 방법을 추가로 안내해 드릴 수 있습니다. [2, 11]
