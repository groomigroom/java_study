HashMap<>()은 키(Key)와 값(Value)의 쌍으로 데이터를 빠르게 저장하고 
검색하는 Java Collections Framework의 대표적인 자료구조 클래스입니다. 
순서 대신 고유한 키를 통해 값을 곧바로 찾을 수 있으며, 
스프링 환경에서는 주로 JSON 데이터 전달, 임시 데이터 그룹화, 
혹은 간단한 파라미터 처리에 쓰입니다.
주요 특징
키-값 구조: 데이터를 Key와 Value 한 쌍으로 묶어서 관리합니다.
빠른 속도: 해시(Hashing) 알고리즘을 써서 데이터 검색과 추가 속도가 매우 빠릅니다.
중복 불가: 키(Key)는 중복될 수 없으며, 같은 키로 값을 넣으면 기존 값이 덮어씌워집니다. 
값(Value)은 중복이 됩니다.
순서 없음: 데이터를 넣은 순서대로 유지되지 않습니다.
Null 허용: 키와 값에 null을 쓸 수 있습니다.
