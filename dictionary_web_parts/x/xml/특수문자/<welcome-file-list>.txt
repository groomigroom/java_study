전자정부 표준프레임워크(및 일반적인 Java 웹 애플리케이션)의 web.xml 파일에 설정되는 <welcome-file-list>는 
사용자가 도메인이나 디렉토리 경로의 끝에 구체적인 파일명을 지정하지 않고 접속했을 때, 서버가 자동으로 찾아 
보여줄 기본 페이지(웰컴 페이지)의 우선순위 목록을 의미합니다.
예를 들어, 사용자가 http://example.com 또는 http://example.com처럼 폴더 경로까지만 입력하고 엔터를 쳤을 때 작동합니다.

💡 주요 특징 및 동작 방식

• 기본 검색 순서: <welcome-file>로 지정된 파일명을 위에서부터 아래 순서대로 찾습니다. 가장 먼저 발견된 파일을 사용자에게 
보여줍니다.
• 스프링 MVC와의 연계 (전자정부 프레임워크의 특징): 전자정부 표준프레임워크는 Spring MVC 기반이므로 보통 index.jsp를 웰컴 
파일로 지정한 뒤, 그 내부에서 실제 메인 화면을 담당하는 스프링 컨트롤러 URL(예: egovSampleList.do 등)로 
리다이렉트(Redirect)시키는 방식을 자주 사용합니다.

📝 설정 예시

xml
<welcome-file-list>
    <welcome-file>index.jsp</welcome-file>
    <welcome-file>index.html</welcome-file>
</welcome-file-list>
코드를 사용할 때는 주의가 필요합니다.
• 사용자가 주소만 입력하고 들어오면 서버는 먼저 index.jsp가 있는지 확인합니다.
• index.jsp가 없다면 다음 순서인 index.html을 찾아 화면에 띄웁니다.
추가로 궁금한 점이 있으시다면 언제든 말씀해 주세요. 만약 현재 접속 시 에러가 나거나 특정 페이지로 이동시키고 싶은 상
황이시라면 다음 내용을 알려주세요. 상황에 맞는 해결 방법을 소개해 드리겠습니다.
• 접속 시도 시 발생하는 에러 코드나 현상
• 최종적으로 사용자가 도메인만 치고 들어왔을 때 보여주고 싶은 메인 화면의 URL 주소 형태
