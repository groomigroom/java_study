전자정부프레임워크(eGovFrame)의 로깅(Log4j 2 등) 설정 XML 파일에서 <PatternLayout>은 
로그 메시지의 출력 형식(포맷)을 지정하는 레이아웃 요소입니다. 
[1] (https://velog.io/@bread_dd/Log4j-2-%EC%A0%9C%EB%8C%80%EB%A1%9C-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0-%EA%B0%9C%EB%85%90)

주요 역할과 특징

• 로그 포맷 지정: 콘솔이나 파일 등에 기록되는 로그의 형태(날짜, 스레드 이름, 로그 레벨, 클래스명, 
메시지 본문 등)를 사용자가 원하는 패턴으로 커스텀할 수 있게 해줍니다. 
[1] (https://velog.io/@bread_dd/Log4j-2-%EC%A0%9C%EB%8C%80%EB%A1%9C-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0-%EA%B0%9C%EB%85%90)
• 패턴 변수(Conversion Characters) 사용: % 기호로 시작하는 포맷 문자를 사용하여 로그 정보를 조합합니다. 
[1] (https://velog.io/@bread_dd/Log4j-2-%EC%A0%9C%EB%8C%80%EB%A1%9C-%EC%82%AC%EC%9A%A9%ED%95%98%EA%B8%B0-%EA%B0%9C%EB%85%90)

자주 사용되는 패턴 문자 예시

• %d : 로그 발생 시간 (예: %d{yyyy-MM-dd HH:mm:ss})
• %p (또/는 %level) : 로그 레벨 (INFO, DEBUG, ERROR 등)
• %c (또/는 %logger) : 해당 로그를 호출한 클래스/로거 이름
• %t : 로그를 출력한 스레드 이름
• %m : 로그 메시지 본문
• %n : 줄바꿈(New Line)

설정 예시

xml
<Appenders>
    <Console name="Console" target="SYSTEM_OUT">
        <PatternLayout pattern="%d{yyyy-MM-dd HH:mm:ss} [%t] %-5level %c - %msg%n" />
    </Console>
</Appenders>
코드를 사용할 때는 주의가 필요합니다.
• 위 예시에서 <PatternLayout pattern="..." />은 [날짜] [스레드] [로그레벨] [클래스명] - 
[메시지] 형태로 로그를 출력하도록 정의한 것입니다.
추가적인 설정 방식이나 Log4j 2 관련 공식 가이드는 표준프레임워크 포털 eGovFrame에서 확인할 수 있습니다. 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte:fdl:logging&s[]=log4j)
현재 사용 중인 Log4j 버전(Log4j 1.x 또는 Log4j 2)이나 원하는 로그 출력 형식(날짜, 클래스명 등)을 알려주시면 알맞은 
<PatternLayout> 설정을 작성해 드릴 수 있습니다.
