전자정부프레임워크(eGovFrame) XML 설정 파일에서 <custom-filter> 태그는 스프링 시큐리티(Spring Security)의 
필터 체인(Filter Chain)에 사용자가 직접 구현한 맞춤형 필터(Custom Filter)를 특정 위치에 삽입할 때 사용하는 엘리먼트입니다.
스프링 시큐리티는 인증(Authentication)과 인가(Authorization)를 처리하기 위해 여러 개의 필터가 순서대로 동작하는 
'필터 체인' 구조를 가집니다. <custom-filter>는 이 표준 필터들 사이에 개발자가 만든 보안 로직을 끼워 넣는 역할을 합니다.

💡 주요 속성과 의미

보통 다음과 같은 형태로 설정됩니다.
xml
<sec:custom-filter ref="myCustomFilter" before="FORM_LOGIN_FILTER"/>
코드를 사용할 때는 주의가 필요합니다.
1. ref:
	• 스프링 빈(Bean)으로 등록된 사용자 정의 필터 객체의 ID를 지정합니다.
2. 위치 지정 속성 (아래 3가지 중 하나를 필수 선택):
	• before: 지정한 표준 필터가 실행되기 직전에 커스텀 필터를 실행합니다.
	• after: 지정한 표준 필터가 실행된 직후에 커스텀 필터를 실행합니다.
	• position: 지정한 표준 필터와 동일한 위치에 배치합니다. (기존 필터를 대체하거나 같은 단계에서 처리할 때 사용)

🛠️ 주로 언제 사용하나요?

• 중복 로그인 방지나 특수한 세션 제어가 필요할 때
• Form 로그인 처리 전후로 추가적인 보안 검증(VDI 체크, OTP 인증 등)을 수행할 때
• JWT(Json Web Token)나 OAuth2 기반의 커스텀 인증 토큰 검증 필터를 추가할 때
• 특정 IP 대역 접근 제어 등 프레임워크 기본 기능 외의 자체 보안 정책을 적용할 때
추가적인 프레임워크 설정이나 구체적인 구현 코드 예시가 필요하시면 언제든 말씀해 주세요! 구체적으로 어떤 보안 
기능(예: JWT, 중복 로그인 등)을 구현하려고 하시는지 알려주시면 알맞은 설정을 안내해 드리겠습니다.
