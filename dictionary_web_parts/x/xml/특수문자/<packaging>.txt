전자정부 표준프레임워크(메이븐 기반 프로젝트의 pom.xml)에서 <packaging> 태그는 
프로젝트를 빌드했을 때 생성될 결과물의 파일 형식(패키징 방식)을 정의하는 의미를 가집니다. [1] (http://210.180.118.83/swkim/crosswalk_back/commit/035990a)

주요 값과 의미

• war (Web Application Archive)
	• 웹 애플리케이션 형태일 때 사용합니다.
	• JSP, Servlet, HTML, 정적 자원 및 컴파일된 클래스 등이 포함되어 외장/내장 웹 서버(Tomcat 등)에 배포할 수 있는 형태로 빌드됩니다. (전자정부 표준프레임워크 웹 템플릿 프로젝트에서 가장 흔하게 쓰입니다.) [1] (https://hyemi6017.tistory.com/74), [2] (http://210.180.118.83/swkim/crosswalk_back/commit/035990a)
• jar (Java Archive)
	• 일반적인 자바 라이브러리나 실행 가능한 자바 콘솔/스프링 부트 기반 애플리케이션을 만들 때 사용합니다.
• pom
	• 결과물을 직접 생성하지 않고, 여러 개로 나누어진 자식 프로젝트들을 모아서 관리하는 멀티 모듈(Multi-module) 프로젝트의 부모 POM에서 사용합니다.

설정 예시 (pom.xml)

xml
<project xmlns="http://apache.org" ...>
    ...
    <groupId>egovframework</groupId>
    <artifactId>sample-project</artifactId>
    <version>1.0.0</version>
    
    <!-- 어떤 파일 형식으로 패키징할 것인가를 정의 -->
    <packaging>war</packaging> 
    ...
</project>
코드를 사용할 때는 주의가 필요합니다.
전자정부 표준프레임워크 및 메이븐에 대한 자세한 구조는 Spring 전자정부표준프레임워크에서 Maven pom.xml 정의와 구성 블로그 또는 표준프레엠워크 포털에서 참고하실 수 있습니다. [1] (https://hyemi6017.tistory.com/74)
현재 진행 중인 프로젝트가 웹 애플리케이션(war)인가요, 아니면 멀티 모듈 구조(pom)나 일반 라이브러리(jar) 설정에 대해 추가로 궁금한 점이 있으신가요?
