전자정부프레임워크(스프링 기반 AOP)에서 <aop:after-returning> 태그는 타겟 메서드가 예외 없이 
정상적으로 실행을 완료하고 결과값을 리턴한 후에 공통 기능(Advice)을 실행하도록 정의하는 설정입니다. 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte4.2:fdl:aop), [2] (https://lee-jung-hoon.github.io/2018/11/09/programming-spring-study-009/)

주요 특징 및 동작 방식

• 실행 시점: 핵심 비즈니스 로직(Target Method)이 오류나 예외 발생 없이 정상적으로 종료된 직후에 실행됩니다. [1] (https://tragramming.tistory.com/47)
• 반환값 활용: 메서드가 리턴한 결과값을 어드바이스(Advice) 메서드 내부에서 전달받아 처리할 수 있습니다. (예: returning="retVal" 속성을 통해 리턴값을 변수로 바인딩 가능) 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte4.3:fdl:aop:xmlschema)
• 주요 용도:
	• 정상 처리 결과에 대한 로그 기록
	• 리턴 데이터 후가공 또는 캐싱 처리
	• 성공 알림 발송 등

AOP Advice 태그 비교

• <aop:before>: 메서드가 실행되기 전에 실행
• <aop:after-returning>: 메서드가 정상적으로 리턴된 후에 실행
• <aop:after-throwing>: 메서드 실행 중 예외(Exception)가 발생했을 때 실행
• <aop:after>: 성공 여부와 상관없이 메서드 실행 종료 후 무조건 실행 [1] (https://dothewillof.tistory.com/94)
자세한 설정 방법과 가이드는 전자정부 표준프레임워크 AOP 가이드에서 확인할 수 있습니다. [1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte4.3:fdl:aop:xmlschema)
