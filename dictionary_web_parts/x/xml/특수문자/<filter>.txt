전자정부 표준프레임워크(eGovFrame)에서 web.xml 등의 설정 파일에 쓰이는 <filter> 태그는 자바 
서블릿(Servlet) 필터를 등록하는 역할합니다. [1] (https://www.egovframe.go.kr/wiki/doku.php?id=e
govframework:com:v3:cmm:urlrewrite), [2] (https://inetsos.tistory.com/entry/%EC%A0%84%EC%9E%90%EC%
A0%95%EB%B6%80%ED%94%84%EB%A0%88%EC%9E%84%EC%9B%8C%ED%81%ACeGovFrame%EC%9D%98-webxml-%EC%84%A4%EC%A0%95)
클라이언트의 요청(Request)이 서블릿이나 스프링의 DispatcherServlet에 도달하기 전 또는 응답(Response)이 
클라이언트로 나가기 전에 중간에서 가로채어 특정 부가 작업을 처리하도록 돕습니다. [1] (https://www.egovfra
me.go.kr/wiki/doku.php?id=egovframework:com:v3:cmm:urlrewrite)

주요 역할과 특징

1. 사전/사후 처리
	• 요청이 컨트롤러에 가기 전에 공통으로 처리해야 하는 작업(예: 문자셋 인코딩 변환, 로그인 여부 확인, 보안 검사 등)을 수행합니다.
2. XSS 및 보안 필터링
	• 대표적으로 HTMLTagFilter 같은 보안 필터를 등록해 <script>, <iframe> 같은 악성 HTML 태그를 필터링하여 XSS(크로스사이트스크립트) 공격을 방지합니다. [1] (https://inetsos.tistory.com/entry/%EC%A0%84%EC%9E%90%EC%A0%95%EB%B6%80%ED%94%84%EB%A0%88%EC%9E%84%EC%9B%8C%ED%81%ACeGovFrame%EC%9D%98-webxml-%EC%84%A4%EC%A0%95)
3. 멀티파트 요청 처리
	• 파일 업로드 시 multipartFilter 등을 등록하여 파일 데이터 파싱을 지원합니다. [1] (https://www.egovfram
e.go.kr/cmm/file/readDownloadFile.do?fileId=FILE_000000000012580&fileSn=0)

구조 예시 (web.xml)

<filter> 태그는 보통 필터 정의(vfilter)와 필터 매핑(vfilter-mapping)이 한 쌍으로 함께 쓰입니다. [1] (https:
//www.egovframe.go.kr/cmm/file/readDownloadFile.do?fileId=FILE_000000000012580&fileSn=0), [2] (https://i
netsos.tistory.com/entry/%EC%A0%84%EC%9E%90%EC%A0%95%EB%B6%80%ED%94%84%EB%A0%88%EC%9E%84%EC%9B%8C%ED%81%ACeGovFrame%EC%9D%98-webxml-%EC%84%A4%EC%A0%95)
xml
<!-- 1. 필터 정의 -->
<filter>
    <filter-name>HTMLTagFilter</filter-name>
    <filter-class>egovframework.rte.ptl.mvc.filter.HTMLTagFilter</filter-class>
</filter>

<!-- 2. 필터 매핑 (어떤 URL 패턴에 적용할 것인지 지정) -->
<filter-mapping>
    <filter-name>HTMLTagFilter</filter-name>
    <url-pattern>*.do</url-pattern>
</filter-mapping>
코드를 사용할 때는 주의가 필요합니다.
• <filter-name>: 필터의 이름을 지정합니다.
• <filter-class>: 실제로 어떤 자바 클래스가 필터 기능을 수행할지 경로를 명시합니다.
• <filter-mapping>: <url-pattern>(예: *.do)을 통해 특정 요청 주소에 이 필터를 작동시킬지 설정합니다. [1] 
(https://www.egovframe.go.kr/cmm/file/readDownloadFile.do?fileId=FILE_000000000012580&fileSn=0), [2] 
(https://inetsos.tistory.com/entry/%EC%A0%84%EC%9E%90%EC%A0%95%EB%B6%80%ED%94%84%EB%A0%88%EC%9E%84%EC%9B%8C%ED%81%ACeGovFrame%EC%9D%98-webxml-%EC%84%A4%EC%A0%95)
자세한 표준 설정 가이드는 전자정부 표준프레임워크 포털 또는 관련 표준프레임워크 개발가이드에서 확인할 수 있습니다. 
[1] (https://egovframe.go.kr/docs/5.0/common-component/elementary-technology/webeditor/)
현재 설정하시려는 특정 필터 이름이나 발생하고 있는 문제가 있다면 알려주세요. 추가로 분석해 드리겠습니다.
