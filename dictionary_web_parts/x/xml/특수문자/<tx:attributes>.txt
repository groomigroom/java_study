전자정부 표준프레임워크(스프링 기반)의 XML 설정 파일(context-transaction.xml 등)에서 <tx:attributes> 
태그는 트랜잭션을 적용할 대상 메서드의 상세 규칙(속성)을 정의하는 컨테이너 태그입니다. 
[1] (https://open.egovframe.org/nforges/qna/qna/2417/.do), [2] (https://subinto.tistory.com/38)

주요 의미 및 역할

• 트랜잭션 속성 정의: <tx:advice> 내부에 위치하며, 어떤 메서드에 어떤 트랜잭션 전파 방식(propagation), 
격리 수준(isolation), 읽기 전용 여부(read-only), 롤백 규칙(rollback-for)을 적용할지 세부 설정을 
감싸는 역할을 합니다.
• <tx:method>의 부모 태그: <tx:attributes> 안에는 실제 메서드 패턴과 속성을 지정하는 <tx:method> 태그가 들어가며, 
보통 여러 개의 <tx:method>를 정의합니다. [1] (https://open.egovframe.org/nforges/qna/qna/2417/.do), [2] (https://subinto.tistory.com/38)

설정 예시 (context-transaction.xml)

xml
<tx:advice id="txAdvice" transaction-manager="txManager">
    <tx:attributes>
        <!-- 모든 메서드(*)에 대해 트랜잭션을 적용하고, Exception 발생 시 롤백함 -->
        <tx:method name="*" propagation="PROPAGATION_REQUIRED" rollback-for="Exception"/>
        <!-- 'get*' 또는 'select*'로 시작하는 조회 전용 메서드는 읽기 전용으로 설정 가능 -->
        <tx:method name="get*" read-only="true"/>
        <tx:method name="select*" read-only="true"/>
    </tx:attributes>
</tx:advice>
코드를 사용할 때는 주의가 필요합니다.
• name="*": 적용할 메서드명을 뜻합니다. 와일드카드(*)를 사용하여 특정 패턴의 메서드 이름(예: get*, save*, *)을 
지정할 수 있습니다.
• propagation="PROPAGATION_REQUIRED": 트랜잭션이 이미 진행 중이면 해당 트랜잭션에 참여하고, 없으면 새로운 
트랜잭션을 생성합니다.
• rollback-for="Exception": 특정 예외가 발생했을 때 트랜잭션을 롤백하도록 설정합니다. (기본적으로 스프링은 
RuntimeException과 Error에서만 자동 롤백합니다.) [1] (https://open.egovframe.org/nforges/qna/qna/2417/.do), 
[2] (https://subinto.tistory.com/38)
이와 관련된 전체적인 트랜잭션 설정 구조는 표준프레임워크 포털에서 자세히 확인할 수 있습니다. [1] (https://www.
egovframe.go.kr/wiki/doku.php?id=egovframework:rte:sample:cvpl:transaction)
트랜잭션 설정과 관련하여 더 알고 싶으시면:
• 특정 메서드명 패턴별 전파 속성(Propagation) 설정 방법
• read-only="true"를 사용할 때의 이점
• 특정 예외 발생 시 롤백 처리하는 방법
등을 이어서 설명해 드릴 수 있습니다. 궁금하신 내용을 말씀해 주세요.
