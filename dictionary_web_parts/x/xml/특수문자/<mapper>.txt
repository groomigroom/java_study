전자정부 표준프레임워크(MyBatis/iBATIS 기반) XML 설정 및 Mapper 파일에서 <mapper> 태그는 자바 코드와 데이터베이스의 SQL 문장을 연결(Mapping)하는 영역의 최상위 루트(Root) 태그를 의미합니다. [1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte2:psl:data_access), [2] (https://www.egovframe.go.kr/docs/5.0/egovframe-runtime/persistence-layer/dataaccess-mybatis/dataaccess-mapper_xml_files/)

1. <mapper> 태그의 핵심 역할

• SQL 정의 파일의 시작점: 실행할 SQL 쿼리들(SELECT, INSERT, UPDATE, DELETE)을 감싸고 관리하는 메인 컨테이너입니다. [1] (https://www.egovframe.go.kr/docs/5.0/egovframe-runtime/persistence-layer/dataaccess-mybatis/dataaccess-mapper_xml_files/)
• 네임스페이스(Namespace) 매칭: <mapper namespace="패키지경로.MapperInterface"> 속성을 통해 자바 인터페이스와 XML 파일을 1:1로 연결합니다. 이를 통해 자바 메서드 호출 시 해당 XML에 작성된 SQL이 실행됩니다.
• 입출력 데이터 바인딩: SQL에 전달할 파라미터(parameterType)와 쿼리 결과를 자바 객체(resultType 또는 resultMap)로 자동 매핑해 주는 설정 공간을 제공합니다. [1] (https://www.egovframe.go.kr/docs/5.0/egovframe-runtime/persistence-layer/dataaccess-mybatis/dataaccess-mapper_xml_files/)

2. 기본 구조 예시

xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE mapper PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN" "http://mybatis.org">

<!-- mapper 루트 태그 -->
<mapper namespace="egovframework.example.sample.service.impl.SampleMapper">

    <select id="selectSampleList" parameterType="sampleVO" resultType="sampleVO">
        SELECT ID, NAME, DESCRIPTION 
        FROM SAMPLE 
        WHERE USE_YN = 'Y'
    </select>

</mapper>
코드를 사용할 때는 주의가 필요합니다.

3. 주요 하위 태그들

<mapper> 태그 내부에는 실제 DB 작업을 처리하기 위한 다양한 SQL 및 제어 태그가 위치합니다: [1] (https://www.egovframe.go.kr/docs/5.0/egovframe-runtime/persistence-layer/dataaccess-mybatis/dataaccess-mybatis-dynamic-sql/)
• <select>: 데이터 조회용 SQL 정의
• <insert>: 데이터 삽입용 SQL 정의
• <update>: 데이터 수정용 SQL 정의
• <delete>: 데이터 삭제용 SQL 정의
• <resultMap>: DB 컬럼명과 자바 VO 필드명이 다를 때 수동으로 매핑해 주는 규칙 정의
• <sql> / <include>: 반복되는 SQL 조각을 모듈화하여 재사용할 때 사용
• <if>, <where>, <foreach>: 조건에 따라 SQL이 동적으로 변하는 동적 SQL 처리 [1] (https://www.egovframe.go.kr/docs/5.0/egovframe-runtime/persistence-layer/dataaccess-mybatis/dataaccess-mybatis-dynamic-sql/)
자세한 작성 방법과 공식 가이드는 표준프레임워크 개발가이드 Mapper XML 파일 문서에서 확인할 수 있습니다. [1] (https://www.egovframe.go.kr/docs/5.0/egovframe-runtime/persistence-layer/dataaccess-mybatis/dataaccess-mapper_xml_files/)
만약 특정 <mapper> 네임스페이스 오류나 SQL 매핑 과정에서의 에러를 해결 중이시라면, 관련 에러 메시지나 mapper XML/Java 코드를 공유해 주세요.
