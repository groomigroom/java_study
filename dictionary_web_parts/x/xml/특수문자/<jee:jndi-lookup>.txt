전자정부표준프레임워크(및 스프링 기반 환경)의 XML 설정 파일에서 
<jee:jndi-lookup> 태그는 웹서버나 WAS(예: 톰캣, 웨이브릿 등)에 미리 등록되어 있는 
JNDI(Java Naming and Directory Interface) 자원을 찾아 스프링 빈(Bean)으로 등록할 때 사용합니다. 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte2:itl:naming_service), 
[2] (https://velog.io/@kkuldangi3/Spring-%ED%86%A0%EB%B9%84%EC%9D%98-%EC%8A%A4%ED%94%84%EB%A7%81-Vol.2-2%EC%9E%A5-%EB%8D%B0%EC%9D%B4%ED%84%B0-%EC%95%A1%EC%84%B8%EC%8A%A4-%EA%B8%B0%EC%88%A0)

주요 의미와 역할

• JNDI 리소스 참조: WAS 등에 설정된 데이터소스(DataSource)나 외부에 바인딩된 객체의 이름(jndi-name)을 조회(Lookup)하여 스프링 컨테이너가 관리하는 빈으로 가져옵니다. 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte2:itl:naming_service), 
[2] (https://velog.io/@kkuldangi3/Spring-%ED%86%A0%EB%B9%84%EC%9D%98-%EC%8A%A4%ED%94%84%EB%A7%81-Vol.2-2%EC%9E%A5-%EB%8D%B0%EC%9D%B4%ED%84%B0-%EC%95%A1%EC%84%B8%EC%8A%A4-%EA%B8%B0%EC%88%A0)
• 주요 사용 사례 (데이터베이스 연결 등):
	• 프로젝트 XML에서 직접 DB 접속 정보(Driver, URL, ID, Password)를 적는 대신, WAS에 미리 설정해둔 JNDI DataSource를 불러올 때 주로 쓰입니다.
	• 예시 코드:xml
<jee:jndi-lookup id="dataSource" jndi-name="jdbc/myDataSource" resource-ref="true" />
코드를 사용할 때는 주의가 필요합니다.
• 장점:
	• 개발 환경(로컬 PC)과 운영 환경(실서버 WAS)의 DB 연결 정보가 달라도, XML 코드를 수정할 필요 없이 WAS 설정만 바꾸어 유연하게 대응할 수 있습니다.
	• 민감한 DB 계정 정보를 소스코드나 설정 파일에 직접 노출하지 않고 WAS 보안 영역에 위임할 수 있습니다.
