전자정부프레임워크(스프링 기반 AOP)에서 <aop:after-throwing> 태그는 대상 
메서드가 실행되는 도중 예외(Exception)가 발생했을 때 공통 기능(Advice)을 
실행하도록 정의하는 XML 설정 요소입니다. 
[1] (https://lee-jung-hoon.github.io/2018/11/09/programming-spring-study-009/), [2] (https://dothewillof.tistory.com/94)

주요 특징

• 실행 시점: 타겟(Target) 메서드가 실행되다가 예외를 던지며(Throwing) 빠져나갈 때 동작합니다. 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte4.0:fdl:aop)
• 주요 용도:
	• 에러 발생 시 로그 기록 (Error Logging)
	• 예외 처리 및 알림 발송
	• 전자정부프레임워크의 Exception Handling 서비스에서 예외를 가로채어 공통 예외 처리기(ExceptionTransfer 등)로 
넘기는 용도 등으로 주로 활용됩니다. [1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte2:bsl:exception_handling)
• 정상 종료 시 미실행: 메서드가 예외 없이 정상 종료되거나 정상 리턴될 때는 실행되지 않습니다.

XML 설정 예시 속성

<aop:after-throwing> 태그는 주로 아래와 같은 속성들을 함께 사용합니다.
• method: 예외가 발생했을 때 실행할 공통 기능 클래스의 메서드명
• pointcut 또는 pointcut-ref: 공통 기능을 적용할 대상 메서드의 범위(포인트컷)
• throwing: 발생한 예외 객체를 전달받을 파라미터명 (예: throwing="ex")
관련 공식 문서는 표준프레임워크 포털 eGovFrame에서 확인할 수 있습니다. [1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte4.0:fdl:aop)
만약 <aop:after-throwing>을 설정하는 전체 XML 설정 구문 예시나 예외 객체를 바인딩해 활용하는 방법이 필요하시면 편하게 말씀해 주세요.
