전자정부 표준프레임워크(및 메이븐 기반 스프링 프로젝트)의 pom.xml 파일에서 
<dependencies> 태그는 프로젝트를 빌드하고 실행하는 데 필요한 외부 라이브러리(의존성)들을 
명시하고 관리하는 영역을 의미합니다. 

주요 역할과 특징

• 라이브러리 자동 다운로드: 프로젝트에 필요한 자바 라이브러리(.jar 파일)의 이름, 
그룹 ID, 버전 등을 <dependency> 하위에 작성하면, 메이븐(Maven)이 원격 저장소에서 
해당 파일을 자동으로 다운로드하여 프로젝트에 연결합니다.
• 의존성(Transitive Dependency) 자동 해결: 내가 추가한 라이브러리가 동작하기 위해 또 다른 
라이브러리가 필요하다면, 메이븐이 그 연관 라이브러리까지 알아서 함께 가져옵니다.
• 버전 관리: 전자정부 표준프레임워크 버전(egovframework.rte.version 등)이나 서블릿, 
JSTL, 데이터베이스 드라이버 같은 공통 모듈의 버전을 일괄적으로 정의하고 제어할 수 있습니다.

기본 구조 예시

xml
<dependencies>
    <!-- 전자정부 표준프레임워크 실행환경 라이브러리 예시 -->
    <dependency>
        <groupId>egovframework.rte</groupId>
        <artifactId>egovframework.rte.fdl.cmmn</artifactId>
        <version>3.10.0</version>
    </dependency>
    
    <!-- 서블릿 API 라이브러리 -->
    <dependency>
        <groupId>javax.servlet</groupId>
        <artifactId>servlet-api</artifactId>
        <version>2.5</version>
        <scope>provided</scope>
    </dependency>
</dependencies>
코드를 사용할 때는 주의가 필요합니다.
• <groupId>: 라이브러리를 만든 조직이나 그룹 이름
• <artifactId>: 라이브러리의 고유한 파일(프로젝트) 이름
• <version>: 사용할 라이브러리의 버전
• <scope>: 라이브러리가 사용되는 범위(예: compile, test, provided 등)
더 자세한 설정 가이드는 전자정부 표준프레임워크 위키(의존성 관리 메커니즘)에서 
확인할 수 있습니다. 
특정 라이브러리의 추가 방법이나 <dependencyManagement>와의 
차이점에 대해 알고 싶다면 편하게 말씀해 주세요.
