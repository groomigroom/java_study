전자정부 표준프레임워크(스프링 기반)의 XML 설정 파일에서 <context:annotation-config> 태그는 스프링 빈(Bean) 내에 선언된 
애노테이션(Annotation)을 활성화하는 역할을 합니다. [1] (https://jake-seo-dev.tistory.com/497)

주요 기능 및 특징

• 애노테이션 기반 설정 활성화: @Autowired, @Qualifier, @Resource, @PostConstruct, @PreDestroy, @Required 같은 표준 애노테이션을 
스프링 컨테이너가 인식하고 처리할 수 있게 만듭니다. [1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte:fdl:ioc_container:annotation-based_configuration)
• 의존성 자동 주입: XML에 일관되게 <bean> 태그로 의존관계를 직접 명시하지 않아도, 자바 코드 내 애노테이션을 통해 의존성(Bean)을 
자동으로 연결해 줍니다.
• 이미 등록된 빈 대상: 이 태그는 이미 Spring Container에 등록된 빈들을 대상으로 애노테이션을 처리합니다. (빈 자체를 스캔해서 찾아주는 기능은 없습니다.)

<context:annotation-config> vs <context:component-scan> 차이점


구분	<context:annotation-config>	<context:component-scan>
주요 역할	이미 등록된 빈 내부의 애노테이션을 활성화	패키지를 뒤져서 빈을 직접 스캔하고 등록 + 애노테이션 활성화 기능 포함
포함 관계	애노테이션 처리 기능만 수행	<context:annotation-config>의 기능이 포함되어 있음

• 보통 @Service, @Repository, @Controller, @Component 등을 자동 스캔해 사용하는 프로젝트에서는 <context:component-scan>을 
쓰면 <context:annotation-config>를 따로 중복해서 적어주지 않아도 됩니다. 
[1] (https://blog.naver.com/phm0515/223398323263?viewType=pc)
자세한 내용은 전자정부 표준프레임워크 위키에서 확인할 수 있습니다. 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte:fdl:ioc_container:annotation-based_configuration)
