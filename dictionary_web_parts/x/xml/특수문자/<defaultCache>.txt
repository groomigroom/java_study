전자정부 표준프레임워크(eGovFrame)에서 캐시 서비스로 사용하는 EhCache의 설정 파일(ehcache.xml) 안에 쓰이는 <defaultCache> 태그는 
개별 캐시를 직접 정의하지 않고 생성할 때 적용될 '기본 설정값'을 정의하는 필수 태그입니다. 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte2:fdl:cache_abstraction), 
[2] (https://hyeooona825.tistory.com/86)

1. 주요 의미와 역할

• 기본 템플릿 제공: 코드나 설정에서 별도의 <cache name="..."> 상세 설정 없이 새로운 캐시를 생성하거나 호출할 때, 
<defaultCache>에 정의된 속성값들을 기본적으로 상속받아 사용합니다.
• 필수 설정: EhCache를 동작시킬 때 반드시 하나 이상 존재해야 하는 기본 설정 블록입니다. 
[1] (https://hyeooona825.tistory.com/86)

2. 주요 속성 (Attributes) 예시

<defaultCache> 태그 내부에는 메모리 관리와 만료 시간을 결정하는 속성들이 포함됩니다:
• maxElementsInMemory: 메모리에 걹(저장)할 수 있는 최대 객체 개수
• eternal: 객체의 영속성 여부 (true이면 만료되지 않음)
• timeToIdleSeconds: 객체가 지정된 시간 동안 사용되지 않으면 만료되는 시간 (초)
• timeToLiveSeconds: 객체가 생성된 후 살아있을 수 있는 최대 시간 (초)
• overflowToDisk: 메모리 용량이 초과될 경우 디스크에 저장할지 여부
• memoryStoreEvictionPolicy: 메모리가 가득 찼을 때 어떤 객체를 먼저 제거할지 정책 (예: LRU, LFU, FIFO)

3. 관련 링크 및 공식 가이드

• 자세한 설정 방법은 표준프레임워크 포털 eGovFrame 캐시 추상화 가이드에서 확인할 수 있습니다.
