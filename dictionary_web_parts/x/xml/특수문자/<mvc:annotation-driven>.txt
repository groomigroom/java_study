전자정부표준프레임워크(및 기반인 Spring MVC) 설정 XML 파일에서 <mvc:annotation-driven> 
태그는 어노테이션 기반의 Spring MVC를 사용하기 위해 필요한 핵심 Bean들을 자동으로 등록하고 활성화해 주는 
설정입니다. [1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte2:ptl:spring_mvc_tag_co
nfiguration), [2] (https://velog.io/@hanblueblue/Spring-mvcannotation-driven)

주요 역할과 기능

• Spring MVC 기본 컴포넌트 자동 등록:
	• 요청을 처리할 Controller를 찾아주는 HandlerMapping과 실제로 요청을 실행하는 HandlerAdapter 등을 자동으로 
등록합니다. [1] (https://velog.io/@hanblueblue/Spring-mvcannotation-driven)
• 어노테이션 기반 Controller 활성화:
	• @Controller, @RequestMapping, @RequestParam, @PathVariable 등의 MVC 관련 어노테이션을 사용할 수 있게 
해줍니다. [1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte2:ptl:annotation-based_controller)
• 데이터 변환 및 포맷팅 지원:
	• JSON, XML 등을 처리하기 위한 HttpMessageConverter (예: Jackson) 등을 기본으로 설정해 줍니다. [1] (https:/
/velog.io/@hanblueblue/Spring-mvcannotation-driven)
• 데이터 검증(Validator) 및 파라미터 리졸버 지원:
	• @Valid 등을 이용한 입력값 검증 기능이나 커스텀 아규먼트 리졸버(argument-resolvers)를 쉽게 확장해서 쓸 수 있도록 
기반을 제공합니다. [1] (https://velog.io/@hanblueblue/Spring-mvcannotation-driven)

주의할 점

• 수동 Bean 중복 주의:
	• <mvc:annotation-driven>을 선언하면 관련 Bean들이 자동으로 생성되므로, 개발자가 동일한 역할의 Bean을 XML에 직접 
중복으로 등록하면 충돌이나 오동작이 발생할 수 있습니다. [1] (https://www.egovframe.go.kr/wiki/doku.php?id=egov
framework:rte2:ptl:spring_mvc_tag_configuration)
• 내부 커스터마이징의 한계:
	• 편리하지만 내부 동작을 세부적으로 바꾸기 어려울 때가 있습니다. 이 경우 태그를 제거하고 필요한 Bean들을 수동으로 직접 
등록해야 할 수도 있습니다. [1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte2:ptl:spring_mvc_tag_configuration)

ki/doku.php?id=egovframework:rte2:ptl:spring_mvc_tag_configuration)
