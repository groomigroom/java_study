전자정부 표준프레임워크(자바 기반)에서 <skipTests>는 빌드 도구인 메이븐(Maven)이 프로젝트를 패키징하거나 설치할 때 JUnit 등의 단위 테스트 실행을 건너뛰도록(Skip) 지정하는 설정입니다. [1] (https://yoons2owo.tistory.com/30), [2] (https://velog.io/@daydream/Maven-Maven-Build-test-skip), [3] (https://firstcheck.tistory.com/264)

핵심 의미 및 동작 방식

• 기능: 빌드 과정 중 test 단계를 생략하고 .jar 또는 .war 파일 같은 최종 결과물을 빠르게 생성합니다. [1] (https://cloud-allstudy.tistory.com/3544)
• 동작 특징 (-DskipTests 또는 <skipTests>true 기준):
	• 테스트 코드의 컴파일은 수행하므로, 테스트 코드 내에 문법 오류가 있다면 빌드가 실패합니다.
	• 다만, 실제 테스트 실행(JUnit 러너 작동)만 생략합니다. (컴파일조차 안 하고 완전히 건너뛰려면 -Dmaven.test.skip=true 옵션을 사용합니다) [1] (https://youngyin.tistory.com/m/587)

주로 사용하는 이유

1. 빌드 시간 단축: 테스트 케이스가 많거나 외부 연동 테스트가 포함되어 빌드에 시간이 오래 걸릴 때 빠르게 패키지화하기 위해 사용합니다. [1] (https://m.blog.naver.com/heehow/140188415489), [2] (https://hjjungdev.tistory.com/104)
2. 테스트 환경 제약: 로컬 개발 환경에 DB나 외부 API 서버 등이 연결되어 있지 않아 단위 테스트가 실패할 수밖에 없는 상황에서 빌드를 진행해야 할 때 유용합니다. [1] (https://cloud-allstudy.tistory.com/3544)
3. CI/CD 파이프라인: 이미 테스트가 완료되었거나 배포 중심의 빌드 단계를 수행할 때 불필요한 테스트 반복을 줄입니다. [1] (https://cloud-allstudy.tistory.com/3544)
