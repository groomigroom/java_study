전자정부프레임워크(스프링 기반)의 XML 설정에서 <aop:advisor> 태그는 어드바이스(Advice, 공통 기능)와 
포인트컷(Pointcut, 적용 위치)을 결합하여 관점(Aspect)을 완성하고 트랜잭션 등의 부가 기능을 특정 코드에 
적용할 때 사용하는 설정 요소입니다. 
[1] (https://egovframe.go.kr/cmm/file/readDownloadFile.do?fileId=FILE_000000000012598&fileSn=0), [2] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte4.1:fdl:aop:xmlschema)

주요 구성 및 의미

• 어드바이스 연결 (advice-ref):
	• 공통으로 실행할 로직(예: 트랜잭션 처리인 txAdvice 등)을 담고 있는 빈(Bean)의 ID를 참조합니다. 
[1] (https://egovframe.go.kr/cmm/file/readDownloadFile.do?fileId=FILE_000000000012598&fileSn=0)
• 포인트컷 연결 (pointcut-ref 또는 pointcut):
	• 공통 기능이 작동해야 할 메서드나 패키지 위치(포인트컷)를 지정합니다. 
[1] (https://tragramming.tistory.com/47), [2] (https://egovframe.go.kr/cmm/file/readDownloadFile.do?fileId=FILE_000000000012598&fileSn=0)

사용 예시

xml
<aop:config>
    <!-- 적용할 메서드 범위 정의 (포인트컷) -->
    <aop:pointcut id="serviceMethod" expression="execution(* com.example..impl.*Impl.*(..))" />
    
    <!-- 어드바이스와 포인트컷을 결합하는 어드바이저 -->
    <aop:advisor advice-ref="txAdvice" pointcut-ref="serviceMethod" />
</aop:config>
코드를 사용할 때는 주의가 필요합니다.
• 의미: serviceMethod라는 조건(어디에 적용할 것인가)에 txAdvice라는 트랜잭션 공통 기능(무엇을 실행할 것인가)을 엮어서(Advisor), 
서비스 계층 실행 시 자동으로 트랜잭션 관리가 동작하도록 만듭니다.
