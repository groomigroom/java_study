이클립스 인코딩 설정

이클립스에서 입력 자동 완성

## 1. 글자 입력 시 자동완성 창 바로 띄우기 (추천 설정)
이클립스는 기본적으로 .을 입력해야만 자동완성 창이 뜹니다.
알파벳만 입력해도 자동완성 창이 뜨도록 설정을 변경하면 List 입력 후 바로 import를 완료할 수 있습니다.

1. 이클립스 상단 메뉴에서 Window ➡️ Preferences로 이동합니다.
2. 왼쪽 메뉴에서 Java ➡️ Editor ➡️ Content Assist를 클릭합니다.
3. Auto Activation 항목을 아래와 같이 수정합니다:
* Enable auto activation: 체크 활성화
* Auto activation delay (ms): 0으로 변경 (딜레이 제거)
* Auto activation triggers for Java: 기존의 .을 지우고 아래 문자열을 복사해서 붙여넣습니다.

._abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ

4. 우측 하단의 Apply and Close를 눌러 저장합니다.
💡 사용 방법: 이제 코드창에 List를 타이핑하면 자동으로 후보 창이 뜹니다. 이때 java.util.List가 선택된 상태에서 Enter나 Space를 누르면 상단에 import문이 자동으로 작성됩니다.

## 2. 단축키 Ctrl + Space 활용하기
위 설정을 바꾸지 않더라도, 단어 입력 후 수동으로 자동완성을 호출할 수 있습니다.

1. 코드창에 List를 입력합니다.
2. 커서가 List 바로 뒤에 있는 상태에서 Ctrl + Space를 누릅니다.
3. 추천 목록에서 List - java.util을 선택하고 Enter를 누르면 자동으로 import문이 완성됩니다.

## 3. 일괄 자동 import 단축키 (가장 많이 쓰는 방식)
List나 ArrayList 등 import가 필요한 클래스 이름들을 쭉 작성한 뒤, 한 번에 해결하는 방법입니다.

* Ctrl + Shift + O (Organize Imports)

💡 사용 방법: 코드를 작성하다 보면 List에 빨간 줄(에러)이 생깁니다.
이때 이 단축키를 누르면 파일 내에 누락된 모든 import를 이클립스가 알아서 한 번에 추가해 줍니다.
(만약 List 이름을 가진 클래스가 여러 개라면 어떤 패키지의 List를 쓸지 고르는 팝업창이 뜹니다.)
