스프링 시큐리티(Spring Security) 환경 설정 시 사용하는 람다식 기반의 예외 처리(Exception Handling) 문법입니다.
질문하신 코드의 정확한 명칭과 세부 정보는 다음과 같습니다.
## 1. 문법의 의미
스프링 시큐리티에서 인증(Authentication)이나 인가(Authorization) 과정 중 에러가 발생했을 때, 어떻게 처리할지 정의하는 메서드입니다.

* .exceptionHandling(...): 예외 처리 기능을 설정하겠다고 선언하는 단계입니다.
* e -> e.메서드: Spring Security 6.x 버전부터 필수적으로 적용된 람다 DSL(Domain Specific Language) 문법입니다. e는 ExceptionHandlingConfigurer라는 설정 객체를 뜻하며, 뒤의 메서드를 통해 구체적인 에러 대응 방식을 지정합니다.

자주 쓰는 예시 코드:

.exceptionHandling(exception -> exception
    // 인증되지 않은 사용자가 접근했을 때 (401 에러)
    .authenticationEntryPoint(new CustomAuthenticationEntryPoint()) 
    // 권한이 없는 사용자가 접근했을 때 (403 에러)
    .accessDeniedHandler(new CustomAccessDeniedHandler()) 
)

------------------------------
## 2. 소속된 스타터 디펜던시 (Start Dependency)
이 문법은 Spring Security 라이브러리에 포함되어 있습니다. 프로젝트의 pom.xml(Maven) 또는 build.gradle(Gradle) 파일에 아래의 의존성을 추가해야 사용할 수 있습니다.
## Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-security'

## Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>

------------------------------
현재 어떤 종류의 에러(401 인증 실패, 403 권한 부족 등)를 처리하려고 하시는지 알려주시면, 상황에 맞는 구체적인 구현 코드와 메서드를 작성해 드릴 수 있습니다. 구현하고 싶으신 동작 방식을 알려주시겠어요?
