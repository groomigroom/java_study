전자정부 표준프레임워크(eGovFramework)에서 CodeGen Templates(Code Generation Templates, 코드젠 템플릿)은 
미리 정의된 템플릿을 활용해 반복적인 소스코드나 설정 파일(Configuration/Property 파일)을 자동으로 생성해 주는 
기능을 의미합니다.

주요 특징 및 목적

• CRUD 프로그램 자동 생성: 데이터베이스 테이블이나 도메인 모델을 바탕으로 
Controller, Service, ServiceImpl, Mapper(DAO), JSP 화면 등 기본적인 CRUD(Create, Read, Update, Delete) 
프로그램 소스코드를 일괄 생성합니다. 
• 환경 설정 파일(Configuration) 작성 간소화: 표준프레임워크 및 스프링(Spring) 기반 프로젝트에서 자주 
사용되는 각종 XML 설정 파일이나 프로퍼티(Property) 파일을 수동으로 일일이 작성하지 
않고 템플릿을 통해 쉽게 구성할 수 있습니다. 
• 개발 생산성 및 표준화 향상:
	• 개발자마다 코딩 스타일이 달라지는 것을 막고, 전자정부 표준 아키텍처에 부합하는 구조로 코드를 통일합니다.
	• 단순하고 반복적인 보일러플레이트(Boilerplate) 코드 작성 시간을 줄여 핵심 비즈니스 로직 구현에 집중하도록 돕습니다.

관련 공식 가이드 참고

템플릿 기반 코드 생성 기능의 상세 사용법과 적용 방식은 템플릿 기반 Code Gen - 표준프레임워크 포털 eGovFrame 및 
Code Generation - 표준프레임워크 포털 eGovFrame 위키 페이지에서 확인할 수 있습니다. 
CodeGen 템플릿 사용 방법이나 특정 버전(예: v4.0, v4.3, v5.0 등)에서의 구체적인 CRUD 생성 절차에 대해 더 알고 싶으시면 말씀해주세요.
