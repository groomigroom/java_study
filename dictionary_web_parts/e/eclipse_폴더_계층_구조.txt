이클립스(Eclipse) 패키지 탐색기에서 자바 패키지를 인텔리제이처럼 계층 구조(Hierarchical)로 변경하려면 패키지 프레젠테이션 설정을 바꾸면 됩니다.
다음 단계를 따라 설정해 보세요.

이클립스 패키지 계층 구조 변경 방법

1. 프로젝트 탐색기/패키지 탐색기 메뉴 클릭
	• 패키지 목록이 보이는 창(Package Explorer 또는 Project Explorer) 우측 상단에 있는 세로 점 3개 모양 아이콘(또는 아래 화살표 모양 ▼ 아이콘)을 클릭합니다.
2. Package Presentation 선택
	• 드롭다운 메뉴에서 Package Presentation 항목으로 마우스를 가져갑니다.
3. Hierarchical 선택
	• 현재 Flat으로 되어 있는 설정을 Hierarchical로 변경하여 클릭합니다.
설정을 마치면 인텔리제이나 일반 폴더 구조처럼 상위 패키지 내부에 하위 패키지가 계층적으로 정렬되어 보기 편하게 바뀝니다.
만약 위 설정을 바꿨는데도 원하는 대로 트리 구조가 나오지 않거나, Project Explorer와 Package Explorer 중 어떤 창을 쓰고 계시는지 알려주시면 추가로 안내해 드리겠습니다.
