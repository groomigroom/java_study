        맥에서 코딩할 때 환경 변수의 의미?
        맥에서 코딩할 때 환경 변수(Environment Variable)는 프로그램이 실행되는 운영체제(OS) 수준의 설정값 공간으로, 
        비밀번호 보호, 경로 지정, 모드 설정 등의 역할을 합니다.
        환경 변수의 주요 역할
        보안 정보 보호: API 키, 데이터베이스 비밀번호 등을 소스코드가 아닌 안전한 시스템 공간에 숨겨 유출을 막습니다.
        실행 경로($PATH): 자바(JDK), 파이썬 등 개발 도구의 위치를 맥 터미널이 어디서든 찾을 수 있게 연결합니다.
        모드 전환: 개발(development) 모드인지 실제 서비스(production) 모드인지 코드가 스스로 알게 돕습니다.
        맥에서의 특징과 사용법전역 적용: 맥의 터미널(Zsh 또는 Bash)에서 설정한 값은 
        그 안에서 실행되는 모든 프로그램과 코드가 읽을 수 있습니다.
        설정 파일: 주로 홈 디렉터리의 .zshrc 파일에 export 변수명="값" 형태로 적어두고 사용합니다.
        
        환경 변수(Environment Variable)는 운영체제(OS)가 컴퓨터 프로그램의 
        실행 방식에 영향을 미치기 위해 사용하는 '시스템 차원의 전역 변수'입니다.
        쉽게 말해, 내 컴퓨터가 모든 프로그램에게 
        "얘들아, 여기 정보 공유해 둘 테니 필요할 때 꺼내 써라" 하고 적어두는 메모장과 같습니다.
        
        ## 1. 일반 변수 vs 환경 변수
        
        * 일반 변수 (코드 안의 변수): 해당 프로그램이나 소스코드 내부에서만 작동하며, 프로그램이 종료되면 사라집니다.
        * 환경 변수 (OS 수준의 변수): 컴퓨터 시스템 전체에 적용되며, 터미널을 끄거나 
        프로그램이 종료되어도 컴퓨터에 계속 저장되어 있어 어떤 프로그램이든 호출해 쓸 수 있습니다.
        
        ## 2. 왜 '환경' 변수라고 부를까요?
        프로그램이 실행되는 주변 상황을 '환경(Environment)'이라고 합니다. 
        
        * "이 컴퓨터의 이름은 무엇인가?"
        * "현재 로그인한 사용자는 누구인가?"
        * "자바나 파이썬 같은 도구들은 어디에 설치되어 있는가?"
        
        프로그램은 실행될 때 이러한 주변 환경 정보를 알아야 정상적으로 작동할 수 있습니다. 
        운영체제는 이러한 정보를 '변수(이름=값)' 형태로 저장하여 프로그램에 제공합니다.
        ## 3. 현실 세계에 빗댄 비유
        
        * 일반 변수: 식당 안에서 주문을 받기 위해 직원끼리만 공유하는 '3번 테이블 메뉴' 메모지입니다. 식당 문을 닫으면 버려집니다.
        * 환경 변수: 구청이나 시청 게시판에 적힌 '지역 거주자 혜택 안내문'입니다. 그 지역에 사는 주민(프로그램)이라면 누구나 언제든 가서 읽고 활용할 수 있습니다.

        맥에서 이클립스로 자바가 정상적으로 작동되면 환경 변수 설정 안해도 되나?
        네, 맥에서 이클립스로 자바 코드가 정상적으로 실행되고 컴파일된다면 
        운영체제(터미널)에 환경 변수를 따로 설정하지 않아도 이클립스 내에서는 자바를 사용하는 데 지장이 없습니다.
        이유
        이클립스의 독립성: 이클립스는 실행될 때 운영체제의 PATH 환경 변수를 참고하는 대신, 
        자체 설정된 Installed JREs 또는 프로젝트별로 지정된 Build Path의 JDK 경로를 직접 사용합니다.
        macOS의 동작: 최근 맥OS 설치 프로그램들은 자바를 설치할 때 이클립스 같은 
        IDE가 인식할 수 있는 기본 경로(/Library/Java/JavaVirtualMachines/)에 파일을 두므로, 
        터미널용 ~/.zshrc 설정을 안 해도 이클립스가 스스로 찾아내기도 합니다.
        예외 및 권장 사항
        터미널 사용: 나중에 맥 터미널에서 java나 javac 명령어를 직접 치거나, 
        스프링 부트(Spring Boot) CLI, 메이븐(Maven), 그레이들(Gradle) 등의 빌드 도구를 
        외부 터미널에서 쓸 때는 환경 변수(JAVA_HOME, PATH) 설정이 필요합니다.
        버전 관리: 이클립스 안에서 여러 버전의 JDK를 바꿔가며 써야 할 때는 운영체제 변수보다 이클립스 
        메뉴인 [Eclipse] > [Preferences] > [Java] > [Installed JREs]에서 직접 경로를 관리하는 것이 더 안전합니다.
