SimpleDateFormat

        import java.text.SimpleDateFormat;

        자바에서 SimpleDateFormat 클래스는 날짜(Date) 객체를 원하는 포맷의 문자열로 변환하거나, 반대로 문자열을 Date 객체로 파싱할 때 사용합니다. [1] 
        ## 1. 기본 사용 순서
        
           1. java.text.SimpleDateFormat 패키지를 임포트합니다.
           2. 원하는 날짜 패턴을 생성자 인자로 전달하여 인스턴스를 만듭니다.
           3. format() 메서드로 날짜를 문자열로 변환하거나, parse() 메서드로 문자열을 날짜 객체로 변환합니다. [1, 2, 3, 4, 5] 
        
        ## 2. 자주 사용하는 날짜 패턴 기호
        
        | 기호 | 의미 | 표현 예시 |
        |---|---|---|
        | y | 연도 (Year) | yyyy(2026), yy(26) |
        | M | 월 (Month) | MM(08), M(8) |
        | d | 일 (Day) | dd(05), d(5) |
        | E | 요일 (Day in week) | E(수) |
        | H | 시간 (Hour, 0~23) | HH(14), H(14) |
        | m | 분 (Minute) | mm(30) |
        | s | 초 (Second) | ss(45) |
        
        
        ## 3. 실제 코드 예제## ① Date 객체를 원하는 문자열(String)로 바꾸기 (format) [6] 
        
        import java.text.SimpleDateFormat;import java.util.Date;
        public class DateFormatExample {
            public static void main(String[] args) {
                // 현재 날짜 객체 생성
                Date now = new Date();
                
                // 패턴 형식 지정
                SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss (E)");
                
                // 포맷팅 적용
                String formattedDate = sdf.format(now);
                
                // 결과 출력: 2026-08-05 14:30:45 (수) 형태
                System.out.println("현재 시간: " + formattedDate);
            }
        }
        
        ## ② 날짜 형식의 문자열(String)을 Date 객체로 바꾸기 (parse) [3] 
        문자열을 날짜로 변경할 때는 패턴이 정확히 일치해야 하며, 반드시 ParseException 예외 처리를 해야 합니다. [7, 8] 
        
        import java.text.ParseException;import java.text.SimpleDateFormat;import java.util.Date;
        public class DateParseExample {
            public static void main(String[] args) {
                String dateStr = "2026/08/05";
                
                // 입력할 문자열 구조와 똑같은 패턴 지정
                SimpleDateFormat sdf = new SimpleDateFormat("yyyy/MM/dd");
                
                try {
                    // 파싱 수행
                    Date parsedDate = sdf.parse(dateStr);
                    System.out.println("변환된 Date 객체: " + parsedDate);
                } catch (ParseException e) {
                    System.out.println("날짜 형식 포맷이 일치하지 않습니다.");
                    e.printStackTrace();
                }
            }
        }

        ## ⚠️ 주의할 점 (멀티스레드 환경)
        SimpleDateFormat은 스레드 안전(Thread-Safe)하지 않습니다. 여러 사용자가 동시에 접근하는 웹 애플리케이션(예: Spring 환경)의 멤버 변수로 공유하여 사용하면 날짜 데이터가 꼬이는 치명적인 오류가 발생할 수 있습니다. [9] 
        
        * 
        * 해결책: 메서드 내부의 지역 변수로 매번 생성해 쓰거나, 자바 8 이상부터 제공하는 스레드 안전한 java.time.format.DateTimeFormatter 클래스를 사용하는 것을 권장합니다.

        네, 자바에서 SimpleDateFormat은 공식적으로 @Deprecated(비권장) 처리되지는 않았으나,

        주요 문제점
        스레드 안전성 부족: 여러 스레드가 동시에 하나의 SimpleDateFormat 인스턴스를 공유하면 
        내부 상태가 꼬여 잘못된 날짜를 반환하거나 오류가 발생합니다.
        구형 API 기반: 낡은 Date 및 Calendar 클래스와 연동되므로 직관적이지 않고 버그를 유발하기 쉽습니다.
        대안 (권장 방식)DateTimeFormatter: 자바 8에 도입된 java.time.format.DateTimeFormatter를 사용하세요.
        특징: 스레드로부터 안전하며(Thread-safe), LocalDateTime 이나 ZonedDateTime 같은 
        모던 날짜/시간 API와 완벽하게 호환됩니다.


        Java의 SimpleDateFormat에서 .setLenient(false)는 날짜와 시간을 파싱(Parsing)할 때 입력값이 유효한지 엄격하게 
        검사하겠다는 의미입니다. [1] (https://m.blog.naver.com/zzang9ha/222156964344), [2] (https://duddns6393.tistory.com/351)

        1. lenient의 뜻
        
        • lenient: '관대한', '너그러운' 이라는 뜻입니다.
        • 기본값(true)일 때는 날짜 형식이 조금 어긋나거나 범위를 벗어나더라도 자동으로 보정해서 날짜로 바꿔줍니다.
        • false로 설정하면 보정하지 않고, 잘못된 날짜 형식이거나 존재하지 않는 날짜일 경우 예외(java.text.ParseException)를 발생시킵니다.

        97%88%EC%9A%A9-O-or-X-dateFormatsetLenientfalse), [2] (https://im-babycoder.tistory.com/3), [3] (https://dev-sheep.tistory.com/60)
        
        2. 동작 비교 (True vs False)
        
        예를 들어 날짜 문자열이 "2026-02-31"(2월에 31일은 존재하지 않음)인 경우:
        • .setLenient(true) (기본값)
        	• 너그럽게 처리하여 2월 31일을 자동으로 넘겨진 일수만큼 계산합니다. (예: 3월 3일 등으로 자동 보정)
        • .setLenient(false)
        	• 엄격하게 검사하여 실제로 존재하지 않는 날짜이므로 ParseException을 던집니다. [1] (https://brightgarden02.com/entry/Java
        -%EC%9E%85%EB%A0%A5%ED%95%A0-%EB%95%8C-%EB%82%A0%EC%A7%9C%EA%B7%9C%EC%B9%99-%EC%84%A4%EC%A0%95-%ED%97%88%EC%9A%A9-O-or-X-dateFormatsetLenientfalse),
