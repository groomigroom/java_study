        spring-boot-starter
        
        start dependency 찾아보기
        
        spring-boot-starter라는 start dependency가 자바 스프링에서 하는 역할
        spring-boot-starter는 필요한 라이브러리들을 하나로 묶어주는 편의 패키지입니다. 
        개발자가 직접 여러 개의 세부 라이브러리를 일일이 찾아서 추가하지 않아도, 
        하나의 스타터만 넣으면 관련된 필수 라이브러리들이 자동으로 함께 추가됩니다.
        주요 역할
        의존성 묶음 제공: 웹 개발용 spring-boot-starter-web을 넣으면 스프링 
        엠브이씨(MVC), 톰캣(Tomcat), 잭슨(Jackson) 등 웹에 필요한 수많은 라이브러리가 
        한 번에 다운로드됩니다.
        버전 충돌 방지: 스프링 부트 팀이 서로 잘 호환되는 라이브러리 버전들을 미리 
        골라 구성했으므로 버전 걱정이 없습니다.
        설정 단순화: 복잡한 설정 없이 빠르게 프로젝트를 시작할 수 있습니다.
