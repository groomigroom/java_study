SecurityContextHolder는 스프링 시큐리티에서 "현재 로그인한 사용자의 보안 컨텍스트(인증 정보)를 저장하고 관리하는 가장 핵심적인 저장소"입니다. [1] 
## 1. 스프링 부트에서의 의미

* 역할: 애플리케이션 안에서 "지금 이 요청을 보낸 사람이 누구인지" 전역적으로 확인할 수 있게 해줍니다.
* 보관 내용: 내부적으로 SecurityContext를 담고 있으며, 그 안에는 인증된 사용자의 정보, 권한(Role), 인증 상태를 담은 Authentication 객체가 들어있습니다.
* 작동 원리: 기본적으로 ThreadLocal 방식을 사용하여, 하나의 요청을 처리하는 같은 스레드 내에서는 어디서든 로그인한 사용자 정보에 접근할 수 있습니다. [2, 3, 4, 5, 6] 

[코드 예시: 현재 로그인한 사용자명 가져오기]

Authentication auth = SecurityContextHolder.getContext().getAuthentication();
String username = auth.getName(); // 현재 사용자 아이디

## 2. 포함되어 있는 스타터 의존성 (Start Dependency)
앞서 설명해 드린 AccessDeniedException과 마찬가지로 Spring Security 핵심 기능입니다. 프로젝트에 아래 의존성을 추가해야 사용할 수 있습니다. [7] 
Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-security'

Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>

## 3. 패키지 경로

* org.springframework.security.core.context.SecurityContextHolder [8]
