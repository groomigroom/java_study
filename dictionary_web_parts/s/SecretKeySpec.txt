SecretKeySpec 클래스의 의미와 사용 목적, 그리고 스프링 부트에서 이를 사용하기 위해 필요한 의존성 정보입니다.
## SecretKeySpec의 의미
SecretKeySpec은 자바 표준 암호화 아키텍처(JHA)에서 비밀 키(Symmetric Key, 대칭 키)를 암호화 알고리즘에 맞는 형태로 변환하고 포장(Encapsulation)하는 클래스입니다.

* 바이트 배열을 키 객체로 변환: 문자열이나 랜덤 생성된 바이트 배열(byte[])을 AES, DES, HmacSHA256 등의 알고리즘에서 인식할 수 있는 실제 Key 객체로 제공합니다.
* 주요 용도: 스프링 부트 애플리케이션에서 JWT(JSON Web Token) 서명 검증, 데이터베이스 필드 암호화, API 통신 데이터 암호화 등에 주로 사용됩니다.

------------------------------
## 속해있는 Starter Dependency (의존성)
SecretKeySpec을 사용하기 위해 별도의 스프링 부트 스타터 의존성을 추가할 필요가 없습니다.

* 자바 기본 내장 클래스: 이 클래스는 자바 표준 라이브러리인 javax.crypto.spec.SecretKeySpec에 속해 있습니다.
* 자동 제공: JDK(Java Development Kit) 자체에 포함되어 있으므로, 모든 스프링 부트 프로젝트에서 아무런 설정 없이 즉시 import하여 사용할 수 있습니다.

import javax.crypto.spec.SecretKeySpec;

------------------------------
## 실무 활용 예시 (JWT 서명 키 생성)
스프링 부트 시큐리티나 JWT 구현 시 주로 아래와 같은 형태로 SecretKeySpec을 활용합니다.

import javax.crypto.spec.SecretKeySpec;import java.security.Key;import java.util.Base64;
public class KeyGenerator {
    public Key getSigningKey(String secretKeyString) {
        // 1. 문자열 키를 바이트 배열로 디코딩
        byte[] keyBytes = Base64.getDecoder().decode(secretKeyString);
        
        // 2. SecretKeySpec을 사용하여 HMAC-SHA256 알고리즘용 키 객체 생성
        return new SecretKeySpec(keyBytes, "HmacSHA256");
    }
}
