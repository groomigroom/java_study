자바 스프링 부트(Spring Boot)에서 SecretKey는 주로 JWT(JSON Web Token) 토큰을 생성, 파싱, 검증할 때 사용하는 암호화 키 객체를 의미합니다.
## 🔑 SecretKey의 의미

* 암호화 및 검증: JWT의 변조를 막기 위해 서명(Signature)을 생성하고 검증하는 데 사용됩니다.
* 보안 키 표현: 자바 표준 보안 라이브러리(javax.crypto.SecretKey)의 인터페이스로, 대칭키 암호화 알고리즘(예: HMAC)의 키를 나타냅니다.

------------------------------
## 📦 속해있는 Starter Dependency (시작 의존성)
스프링 부트 자체에는 SecretKey 인터페이스가 기본 자바(JDK) 내장 라이브러리라 포함되어 있지만, 이를 실제로 활용하여 JWT를 구현할 때는 주로 jjwt 라이브러리나 Spring Security 관련 의존성을 추가해야 합니다.
가장 흔하게 사용하는 두 가지 의존성 구성은 다음과 같습니다.
## 1. JJWT (Java JWT) 라이브러리를 사용할 때 (가장 흔함)
Keys.secretKeyFor(SignatureAlgorithm.HS256) 같은 메서드로 SecretKey를 생성할 때 사용합니다. build.gradle에 아래 의존성들을 추가합니다. [1] 

dependencies {
    // JWT API
    implementation 'io.jsonwebtoken:jjwt-api:0.11.5'
    // JWT 구현체 및 Jackson 지원
    runtimeOnly 'io.jsonwebtoken:jjwt-impl:0.11.5'
    runtimeOnly 'io.jsonwebtoken:jjwt-jackson:0.11.5' 
}

## 2. Spring Security Starter를 사용할 때
스프링 생태계 표준 보안을 사용하며, 내부적으로 OAuth2나 JWT Jose 라이브러리를 연동할 때 사용합니다.

dependencies {
    // 스프링 시큐리티 스타터
    implementation 'org.springframework.boot:spring-boot-starter-security'
    // OAuth2 자원 서버(JWT 검증 기능 포함)
    implementation 'org.springframework.boot:spring-boot-starter-oauth2-resource-server'
}
