long now = System.currentTimeMillis(); 코드는 현재 시점의 시간(현재 시각)을 밀리초(ms, 1000분의 1초) 단위의 숫자로 구하는 자바의 표준 문장입니다. JWT 토큰을 만들 때 토큰의 '발급 시간(IssuedAt)'과 '만료 시간(Expiration)'을 계산하기 위한 기준점으로 가장 많이 사용됩니다. [1] 
이 코드가 속해 있는 스타터 의존성과 각 키워드의 개별 의미는 다음과 같습니다.
## 1. 속해 있는 스타터 의존성 (Start Dependency)
이 코드는 별도의 스타터 의존성이 필요 없습니다. 자바 언어의 가장 기본이 되는 핵심 라이브러리(java.lang 패키지)에 포함되어 있기 때문에, 스프링 부트 프로젝트를 생성하기만 하면 아무런 설정 없이 곧바로 사용할 수 있습니다.
------------------------------
## 2. 구성 요소별 의미

| 키워드 | 의미 | 설명 |
|---|---|---|
| System | 자바 표준 시스템 클래스 | 운영체제(OS) 및 시스템 관련 속성과 기능을 제공하는 자바 내장 클래스입니다. (java.lang.System) |
| currentTimeMillis() | 현재 시간을 밀리초로 반환하는 메서드 | 1970년 1월 1일 00:00:00 UTC (에포크 타임) 이후부터 현재까지 흐른 시간을 밀리초 단위로 측정하여 숫자로 돌려줍니다. |
| long | 64비트 정수형 데이터 타입 | 시간이 지나면서 밀리초 숫자가 매우 커지기 때문에, 일반 정수(int)가 아닌 더 큰 숫자를 저장할 수 있는 long 타입을 사용합니다. |

------------------------------
## 💡 JWT 구현 시 활용 예시
스프링 부트에서 JWT를 발급할 때 이 코드는 보통 다음과 같이 응용됩니다.

long now = System.currentTimeMillis();
// 1. 현재 시간을 발급 시간으로 설정
Date issuedAt = new Date(now); 
// 2. 현재 시간에 30분(30 * 60 * 1000ms)을 더해 만료 시간 설정
Date expiration = new Date(now + 1800000); 

현재 작성 중이신 JWT 발급 로직에서 토큰 유효 기간을 몇 분 또는 몇 시간으로 설정하려고 하시나요? 원하는 만료 시간 조건을 말씀해 주시면, 밀리초 단위로 정확히 계산된 시간 설정 코드를 작성해 드리겠습니다.
