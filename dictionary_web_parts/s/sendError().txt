sendError(HttpServletResponse.SC_UNAUTHORIZED)

제시해주신 코드는 서버가 클라이언트에게 "너는 인증되지 않은 사용자(401 Unauthorized)"라는 에러 상태를 전달하는 웹 표준 제어 명령입니다. [1] 
구체적인 의미와 포함된 스타터 의존성은 다음과 같습니다.
## 1. 코드의 의미
이 코드는 "클라이언트에게 HTTP status 401(인증 안 됨) 에러를 반환하고 응답을 종료하겠다"는 의미입니다.

* response.sendError(...): 서블릿(Servlet) 컨테이너에 지정된 HTTP 에러 상태 코드를 클라이언트에게 보내라고 명령하는 메서드입니다. 이 메서드가 호출되면 서버는 HTML 형태의 기본 에러 페이지(또는 톰캣 기본 에러 화면)를 클라이언트에게 전송합니다.
* HttpServletResponse.SC_UNAUTHORIZED: HTTP 표준 상태 코드인 401을 나타내는 자바 상수(Constant)입니다.
* 실제 효과: 이전 답변에서 다룬 AuthenticationEntryPoint 내부에서 이 코드를 실행하면, 인증되지 않은 사용자가 접근했을 때 브라우저에 "401 Unauthorized" 에러 창을 띄우거나 프론트엔드(React, Vue 등)에 401 에러를 응답으로 보냅니다.

## 2. 소속 스타터 의존성 (Starter Dependency)
이 문법은 자바 웹 개발의 기본인 자카르타 서블릿(Jakarta Servlet) API에 속해 있습니다. 스프링 부트 환경에서 웹 요청을 처리하려면 기본적으로 Spring Web 라이브러리가 필요합니다.
pom.xml(Maven) 또는 build.gradle(Gradle)에 아래 의존성을 추가해야 합니다.
Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-web'

Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>

(참고: HttpServletResponse 객체 자체는 spring-boot-starter-web에 내장된 톰캣(Tomcat) 라이브러리에서 제공하므로 별도의 추가 설정은 필요 없습니다.)
------------------------------
## 💡 앞서 질문하신 Spring Security와 결합하면 아래처럼 쓰입니다

.authenticationEntryPoint((request, response, authException) -> {
    // 인증 실패 시 클라이언트에게 즉시 401 에러를 전송함
    response.sendError(HttpServletResponse.SC_UNAUTHORIZED); 
})

혹시 현재 작업 중인 프로젝트가 웹 브라우저 화면(HTML)을 직접 보여주는 방식인가요, 아니면 JSON 데이터를 주고받는 REST API 서버인가요? 프로젝트의 아키텍처(클라이언트 환경)를 알려주시면 sendError 대신 커스텀 JSON 에러 메시지를 깔끔하게 보내는 방식을 추가로 가이드해 드리겠습니다.
