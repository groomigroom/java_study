Spring Boot와 Spring Security에서 LogoutFilter는 기본적으로 http.logout() 설정을 통해 자동으로 구성되며, 
사용자가 로그아웃 요청을 보낼 때 해당 요청을 가로채 세션 무효화, 쿠키 삭제, 인증 객체 제거 등의 
로그아웃 처리를 담당합니다. 
아래는 Spring Boot 3.x / Spring Security 환경에서 SecurityFilterChain을 통해 Logout 및 
LogoutFilter를 설정하고 커스텀 핸들러를 사용하는 예제입니다.

1. Spring Security 설정 클래스 예제 (SecurityConfig.java)

java
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.security.config.annotation.web.builders.HttpSecurity;
import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
import org.springframework.security.web.SecurityFilterChain;
import org.springframework.security.web.authentication.logout.HttpStatusReturningLogoutSuccessHandler;
import org.springframework.security.web.util.matcher.AntPathRequestMatcher;

@Configuration
@EnableWebSecurity
public class SecurityConfig {

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            // 기타 권한 및 CSRF 설정 (예시)
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/", /login", "/public/**").permitAll()
                .anyRequest().authenticated()
            )
            
            // LogoutFilter 관련 설정
            .logout(logout -> logout
                // 1. 로그아웃을 처리할 URL 지정 (기본값은 "/logout")
                .logoutRequestMatcher(new AntPathRequestMatcher("/logout", "POST"))
                
                // 2. 로그아웃 성공 시 이동할 URL 지정 (logoutSuccessHandler와 동시 사용 불가)
                .logoutSuccessUrl("/login?logout")
                
                // 3. 또는 커스텀 로그아웃 성공 핸들러 사용 (API 서버 등의 경우 상태코드 반환 등)
                // .logoutSuccessHandler(new HttpStatusReturningLogoutSuccessHandler())
                
                // 4. 로그아웃 시쿠키 삭제 (예: JSESSIONID)
                .deleteCookies("JSESSIONID", "remember-me")
                
                // 5. HTTP 세션 무효화 여부 (기본값 true)
                .invalidateHttpSession(true)
                
                // 6. SecurityContextHolder 비우기 (기본값 true)
                .clearAuthentication(true)
                
                // 7. 추가적인 커스텀 LogoutHandler 등록 (토큰 삭제, 로깅 등)
                .addLogoutHandler((request, response, authentication) -> {
                    System.out.println("커스텀 로그아웃 핸들러 실행: 사용자 = " + 
                        (authentication != null ? authentication.getName() : "Anonymous"));
                })
            );

        return http.build();
    }
}
코드를 사용할 때는 주의가 필요합니다.

2. LogoutFilter 동작 방식 요약

1. 요청 감지: 클라이언트가 설정된 URL(/logout)로 요청을 보내면 LogoutFilter가 이를 가로챕니다. 
(기본적으로 POST 요청 방식 사용 권장)
2. LogoutHandler 실행: 등록된 여러 LogoutHandler들(세션 무효화, 쿠키 삭제, 시큐리티 컨텍스트 클리어 등)이 
순차적으로 실행됩니다.
3. LogoutSuccessHandler 실행: 로그아웃 처리가 완료되면 logoutSuccessUrl로 리다이렉트하거나, 
설정한 logoutSuccessHandler를 호출하여 응답을 반환합니다.

11. LogoutFilter 자료를 참고하실 수 있습니다.

특정 REST API 응답 형태로 로그아웃 처리를 하길 원하시면 말씀해 주세요.
