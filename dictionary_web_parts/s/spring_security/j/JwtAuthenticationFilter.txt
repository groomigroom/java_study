Spring Boot와 Spring Security에서 JwtAuthenticationFilter는 클라이언트 요청의 헤더에서 JWT를 추출하고 유효성을 검증한 뒤, 
인증 객체를 SecurityContext에 등록하는 커스텀 필터입니다. 
중복 요청 방지를 위해 보통 OncePerRequestFilter를 상속받아 구현합니다.

1. JwtAuthenticationFilter 구현 개요

OncePerRequestFilter를 상속받는 JwtAuthenticationFilter는 doFilterInternal 메서드를 통해 매 요청마다 동작합니다.
• 토큰 추출: Authorization 헤더에서 Bearer 를 제외한 순수 JWT 문자열을 파싱합니다.
• 유효성 검증 및 인증: JwtTokenProvider를 통해 토큰의 유효성을 검사하고, 
유효할 경우 인증 객체를 가져와 SecurityContextHolder에 저장합니다.
• 체크: 필터 로직이 끝나면 filterChain.doFilter(request, response)를 호출하여 다음 필터로 요청을 넘깁니다. 
전체 Java 소스코드 구현 예제는 참조된 웹 문서에서 확인할 수 있습니다. 

2. SecurityConfig에 필터 등록하기 (Spring Security 6.x 이상 기준)

Spring Security 6 이상에서는 람다 기반 설정을 사용하며, CSRF 비활성화 및 세션 정책을 STATELESS로 설정한 뒤, 
addFilterBefore를 통해 UsernamePasswordAuthenticationFilter 앞에 JwtAuthenticationFilter를 위치시킵니다. 
상세 설정 코드는 참조 문서를 참고하시기 바랍니다. 

3. 핵심 동작 흐름 정리

1. 토큰 추출: 클라이언트가 Authorization: Bearer <token> 형태로 요청하면 토큰을 발췌합니다.
2. 검증: validateToken()을 통해 변조 여부 및 만료일을 체크합니다.
3. 인증 처리: getAuthentication()을 호출해 Authentication 객체를 생성하고 SecurityContextHolder에 담아 인증 상태를 유지합니다.
4. 체크: 이후 컨트롤러에 도달하기 전/후로 인증 정보가 SecurityContext에 존재하므로 인가(Authorization) 처리가 정상 수행됩니다.
참고할 수 있는 전체 구조와 상세 아키텍처는 Spring Security와 JWT 아키텍처 영상이나 Spring Security에서 JWT 인증 구조 설계하기 
글에서 확인할 수 있습니다.
만약 JwtTokenProvider 구현 코드나 로그인 시 토큰을 생성해 발급하는 AuthController 예제가 추가로 필요하시면 편하게 말씀해 주세요.
