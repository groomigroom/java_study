UsernamePasswordAuthenticationFilter.class는 스프링 시큐리티에서 폼 기반 로그인(아이디/비밀번호 인증)을 처리하는 핵심 기본 필터 클래스입니다.
------------------------------
## 💡 UsernamePasswordAuthenticationFilter.class의 의미와 역할

* 기본 로그인 가로채기: 사용자 입력을 처리하는 URI(기본값: /login)로 들어오는 POST 요청을 감시합니다.
* 파라미터 추출: 요청 본문이나 폼 데이터에서 username과 password 값을 추출합니다.
* 인증 시도: 추출한 정보를 기반으로 인증용 토큰 객체를 만들어 AuthenticationManager에게 검증을 넘깁니다.
* 순서의 기준점: 이 클래스는 스프링 시큐리티 필터 체인에서 매우 중요한 위치를 차지하므로, 앞서 질문하신 addFilterBefore(..., UsernamePasswordAuthenticationFilter.class)처럼 커스텀 필터의 실행 위치를 지정하는 기준점으로 자주 사용됩니다. [1] 

------------------------------
## 📦 속해있는 Start Dependency (의존성)
이 클래스 또한 앞서 확인하신 보안 컴포넌트들과 동일하게 Spring Security 의존성에 포함되어 있습니다.
## Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-security'

## Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>

------------------------------
## 🔍 두 단어의 각각의 의미 (UsernamePasswordAuthenticationFilter와 .class)
전체 코드는 자바 클래스 이름 뒤에 .class 문법이 붙은 형태입니다. 각각의 의미는 다음과 같습니다.
## 1. UsernamePasswordAuthenticationFilter
스프링 시큐리티가 제공하는 실제 자바 클래스(Class)의 이름입니다. 단어 그대로의 의미를 담고 있습니다.

* UsernamePassword: 아이디(username)와 비밀번호(password) 기반의 인증 정보라는 뜻입니다.
* Authentication: 사용자가 누구인지 신원을 확인하는 '인증' 작업이라는 뜻입니다.
* Filter: 서블릿 컨테이너단에서 요청을 가로채고 처리하는 '웹 필터'라는 뜻입니다. [2, 3] 

## 2. .class
자바 문법에서 클래스 이름 뒤에 붙이는 클래스 리터럴(Class Literal)입니다.

* 객체의 인스턴스(예: new Filter())를 뜻하는 것이 아니라, 해당 클래스 자체의 구조적 정보(타입 정보)를 참조하겠다는 의미입니다.
* addFilterBefore(myFilter, UsernamePasswordAuthenticationFilter.class) 코드에서 사용된 이유는, "실제 객체를 실행해라"가 아니라 "기본으로 등록되어 있는 필터들 중에서 UsernamePasswordAuthenticationFilter라는 타입을 가진 녀석을 찾아서 그 앞에 내 필터를 놓아라"라고 스프링에게 '타입 기준선'을 알려주기 위해서입니다.

------------------------------
이제 스프링 시큐리티의 인증 필터 흐름과 관련된 주요 개념들을 모두 짚어보셨습니다.
이 필터의 작동 방식을 변경하여 JSON 형태의 로그인을 처리하도록 코드를 수정하고 싶으신가요, 아니면 필터 실행 순서(Filter Chain) 전체를 시각적으로 확인하는 예제가 필요하신가요? 진행 중이신 작업 방향을 말씀해 주시면 맞춤형으로 안내해 드리겠습니다.
