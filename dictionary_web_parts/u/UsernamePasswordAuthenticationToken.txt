UsernamePasswordAuthenticationToken은 스프링 시큐리티(Spring Security)에서 사용자가 입력한 아이디(Username)와 비밀번호(Password) 기반의 인증 요청 데이터 및 인증 완료된 결과를 담는 핵심 객체입니다.
## 1. UsernamePasswordAuthenticationToken의 의미와 용도
스프링 부트 보안 시스템 안에서 인증(Authentication) 프로세스를 거칠 때 주고받는 '인증서' 역할을 합니다.

* 인증 전 (Unauthenticated): 사용자가 로그인 폼에 아이디와 비밀번호를 입력하면, 스프링 시큐리티는 이 값을 추출하여 UsernamePasswordAuthenticationToken 객체를 생성합니다. 이때는 아직 검증되지 않은 상태입니다.
* 인증 후 (Authenticated): AuthenticationManager가 비밀번호를 데이터베이스(DB) 정보와 비교하여 검증에 성공하면, 유저의 상세 정보(UserDetails)와 권한 목록(Authorities)을 담은 인증 완료된 새로운 Token 객체를 반환합니다.
* 시큐리티 컨텍스트 보관: 인증이 완료된 이 토큰 객체는 SecurityContextHolder에 저장되어, 애플리케이션 전역에서 "현재 로그인한 유저 정보"를 조회할 수 있게 해줍니다. [1] 

## 2. 속해있는 스타터 의존성 (Start Dependency)
이 클래스는 스프링 부트의 기본 웹 스타터가 아닌, 보안 전용 스타터 라이브러리에 속해 있습니다.

* 소속 패키지: org.springframework.security.authentication.UsernamePasswordAuthenticationToken
* 핵심 스타터: spring-boot-starter-security
* 결론: 이 객체를 빌드하고 사용하려면 프로젝트의 build.gradle 또는 pom.xml 파일에 스프링 시큐리티 스타터 의존성이 반드시 추가되어 있어야 합니다. [2] 

// Gradle 예시
implementation 'org.springframework.boot:spring-boot-starter-security'

------------------------------
현재 이 토큰을 사용해서 커스텀 로그인 필터를 구현하시거나, JWT(JSON Web Token) 도입 후 인증 객체를 생성하는 코드를 작성 중이신가요? 구현하고 계신 보안 방식(Session vs JWT)을 알려주시면 상황에 맞는 정확한 Token 생성 및 사용 예시 코드를 제공해 드릴 수 있습니다. [3]

UsernamePasswordAuthenticationToken.unauthenticated(username, password)는 스프링 시큐리티에서 "아직 인증되지 않은 ID/PW 기반의 인증 요청 객체"를 안전하게 생성하는 정적 팩토리 메서드(Static Factory Method)입니다.
------------------------------
## 1. 코드의 의미와 변경 배경
원래 스프링 시큐리티 구버전에서는 인증되지 않은 토큰을 만들 때 new UsernamePasswordAuthenticationToken(username, password)과 같이 생성자를 직접 사용했습니다.
하지만 스프링 시큐리티 5.6(스프링 부트 2.6) 버전부터 코드를 더 직관적이고 명확하게 읽을 수 있도록 메서드를 분리했습니다.

* 의미: "이 토큰은 사용자가 방금 입력한 정보이며, 아직 비밀번호 검증을 거치지 않은(unauthenticated) 임시 인증 요청 상태이다"를 명시합니다.
* 이후 흐름: 이렇게 생성된 토큰은 AuthenticationManager의 authenticate() 메서드로 넘겨져 실제 DB의 회원 정보와 일치하는지 검증을 받게 됩니다.

------------------------------
## 2. 매개 변수 2개의 의미
메서드에 들어가는 두 개의 인자 (username, password)는 사용자가 로그인을 시도할 때 입력한 핵심 자격 증명 데이터입니다.

   1. 첫 번째 매개변수 (username):
   * 의미: 사용자를 식별할 수 있는 아이디(ID) 또는 이메일 주소입니다.
      * 타입: 자바 객체(Object) 타입을 받지만, 일반적으로 String 문자열이 들어갑니다.
   2. 두 번째 매개변수 (password):
   * 의미: 해당 아이디의 가입 정보와 비교할 비밀번호(Password)입니다.
      * 타입: 보안을 위해 내부적으로는 암호화되지 않은 평문 상태로 전달되며, 인증 매니저가 DB 내의 암호화된 비밀번호와 일치하는지 비교하는 데 사용됩니다.
   
------------------------------
## 3. 속해있는 스타터 의존성 (Start Dependency)
앞서 질문하신 토큰 클래스의 내장 메서드이므로 필요한 의존성은 동일합니다.

* 소속 패키지: org.springframework.security.authentication.UsernamePasswordAuthenticationToken
* 핵심 스타터: spring-boot-starter-security
* 결론: 이 코드를 컴파일하고 사용하려면 프로젝트에 스프링 시큐리티 스타터 라이브러리가 반드시 빌드되어 있어야 합니다.

------------------------------
보통 이 코드는 JWT 로그인 필터나 커스텀 인증 필터를 구현할 때 로그인 요청을 가로채서 시큐리티 시스템에 넘겨주기 위한 첫 단계로 사용됩니다. 혹시 이 인증 요청 토큰을 생성한 이후, AuthenticationManager를 통해 실제 로그인을 처리하고 인증을 완료하는 전체 필터 흐름 코드가 필요하신가요?
