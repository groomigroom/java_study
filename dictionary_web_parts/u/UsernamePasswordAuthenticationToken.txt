UsernamePasswordAuthenticationToken은 스프링 시큐리티(Spring Security)에서 사용자가 입력한 아이디(Username)와 비밀번호(Password) 기반의 인증 요청 데이터 및 인증 완료된 결과를 담는 핵심 객체입니다.
## 1. UsernamePasswordAuthenticationToken의 의미와 용도
스프링 부트 보안 시스템 안에서 인증(Authentication) 프로세스를 거칠 때 주고받는 '인증서' 역할을 합니다.

* 인증 전 (Unauthenticated): 사용자가 로그인 폼에 아이디와 비밀번호를 입력하면, 스프링 시큐리티는 이 값을 추출하여 UsernamePasswordAuthenticationToken 객체를 생성합니다. 이때는 아직 검증되지 않은 상태입니다.
* 인증 후 (Authenticated): AuthenticationManager가 비밀번호를 데이터베이스(DB) 정보와 비교하여 검증에 성공하면, 유저의 상세 정보(UserDetails)와 권한 목록(Authorities)을 담은 인증 완료된 새로운 Token 객체를 반환합니다.
* 시큐리티 컨텍스트 보관: 인증이 완료된 이 토큰 객체는 SecurityContextHolder에 저장되어, 애플리케이션 전역에서 "현재 로그인한 유저 정보"를 조회할 수 있게 해줍니다. [1] 

## 2. 속해있는 스타터 의존성 (Start Dependency)
이 클래스는 스프링 부트의 기본 웹 스타터가 아닌, 보안 전용 스타터 라이브러리에 속해 있습니다.

* 소속 패키지: org.springframework.security.authentication.UsernamePasswordAuthenticationToken
* 핵심 스타터: spring-boot-starter-security
* 결론: 이 객체를 빌드하고 사용하려면 프로젝트의 build.gradle 또는 pom.xml 파일에 스프링 시큐리티 스타터 의존성이 반드시 추가되어 있어야 합니다. [2] 

// Gradle 예시
implementation 'org.springframework.boot:spring-boot-starter-security'

------------------------------
현재 이 토큰을 사용해서 커스텀 로그인 필터를 구현하시거나, JWT(JSON Web Token) 도입 후 인증 객체를 생성하는 코드를 작성 중이신가요? 구현하고 계신 보안 방식(Session vs JWT)을 알려주시면 상황에 맞는 정확한 Token 생성 및 사용 예시 코드를 제공해 드릴 수 있습니다. [3]
