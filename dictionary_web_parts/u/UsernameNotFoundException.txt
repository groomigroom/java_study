UsernameNotFoundException은 스프링 시큐리티에서 "로그인을 시도할 때, 사용자가 입력한 아이디(Username)에 해당하는 유저를 데이터베이스나 시스템에서 찾을 수 없을 때" 발생하는 예외입니다.
## 1. 스프링 부트에서의 의미

* 역할: 주로 사용자의 인증 정보를 조회하는 UserDetailsService 인터페이스를 구현할 때 사용됩니다. 데이터베이스에서 해당 아이디를 조회한 결과가 없으면 이 예외를 던지도록 설계되어 있습니다.
* 보안적 특징: 내부적으로 이 예외가 발생하더라도, 스프링 시큐리티는 클라이언트(화면)에 "아이디가 존재하지 않습니다"라고 구체적으로 알려주지 않는 것이 기본 설정입니다. 계정 존재 여부를 해커에게 노출하지 않기 위해 로그인 페이지에는 보통 "아이디 또는 비밀번호가 잘못되었습니다"라는 범용 메시지(BadCredentialsException 계열)로 전환되어 표시됩니다.

[코드 예시: UserDetailsService 구현]

@Servicepublic class CustomUserDetailsService implements UserDetailsService {
    
    @Autowired
    private UserRepository userRepository;

    @Override
    public UserDetails loadUserByUsername(String username) throws UsernameNotFoundException {
        return userRepository.findByUsername(username)
            .orElseThrow(() -> new UsernameNotFoundException("유저를 찾을 수 없습니다: " + username));
    }
}

## 2. 포함되어 있는 스타터 의존성 (Start Dependency)
앞서 질문하신 AccessDeniedException, SecurityContextHolder와 마찬가지로 Spring Security 라이브러리에 포함되어 있습니다.
Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-security'

Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>

## 3. 패키지 경로

* org.springframework.security.core.userdetails.UsernameNotFoundException

* orElseThrow() 뒤에 이 예외를 붙여 데이터베이스 조회와 예외 처리를 한 번에 묶는 전체적인 로그인 서비스 코드가 필요하신가요?
* 이 에러가 발생했을 때 클라이언트에게 "아이디가 틀렸다" 혹은 "비밀번호가 틀렸다"를 명확히 구분해서 메시지를 보내고 싶으신가요? (시큐리티 기본 설정을 바꾸는 법을 알려드릴 수 있습니다.)
* 소셜 로그인(OAuth2) 환경이라 아이디가 아닌 이메일이나 고유 고유 ID 기반으로 유저를 찾아야 하는 상황인가요?
