import org.commonmark.node.Node;

자바 스프링 부트에서 import org.commonmark.node.Node;의 Node는 마크다운 텍스트를 이루는 개별 구성 요소(제목, 문단, 링크, 이미지 등)를 추상화한 최상위 자바 객체(클래스)입니다. [오픈소스 마크다운 라이브러리인 commonmark-java 패키지에 포함되어 있습니다.]
앞서 설명해 드린 Parser가 마크다운 글 전체를 읽어서 컴퓨터가 이해할 수 있는 트리 구조로 쪼갠다고 말씀드렸는데, 그 트리 구조를 구성하는 나뭇가지와 잎사귀 하나하나가 바로 이 Node 객체입니다.
------------------------------
## 🧱 Node의 구체적인 의미와 특징## 1. 마크다운의 구성 요소를 다 담는 틀
마크다운 서식에는 # 제목, **굵게**, - 리스트 등 다양한 요소가 있습니다. 라이브러리 내부적으로는 이들을 Heading, StrongEmphasis, BulletList 같은 하위 클래스로 세분화해 두었는데, 이 모든 것들을 공통적으로 아우르는 부모(최상위) 타입이 바로 Node입니다.
## 2. 계층 구조(Tree)를 가짐
Node 객체는 마치 HTML 태그가 부모와 자식 관계를 가지는 것처럼, 자바 안에서 다음과 같은 부모-자식 연결 정보를 가지고 있습니다.

* node.getParent() : 나를 감싸고 있는 부모 노드 찾기
* node.getFirstChild() : 내 밑에 있는 첫 번째 자식 노드 찾기
* node.getNext() : 내 바로 옆에 있는 다음 형제 노드 찾기

## 안녕하세요
이곳은 **스프링** 게시판입니다.

Parser가 이를 분석하면 내부적으로 다음과 같은 Node들의 트리 구조가 생성되고, 그 중심에 Node 타입이 사용됩니다.

* Document (최상위 Node)
* 📂 Heading (Node의 일종 - Level 2 제목)
   * 📝 Text (Node의 일종 - "안녕하세요")
   * 📂 Paragraph (Node의 일종 - 본문 문단)
   * 📝 Text (Node의 일종 - "이곳은 ")
      * 📂 StrongEmphasis (Node의 일종 - 굵은 글씨)
      * 📝 Text (Node의 일종 - "스프링")
      * 📝 Text (Node의 일종 - " 게시판입니다.")
   
이 덩어리들을 통째로 자바에서는 Node document = parser.parse(text); 형태로 받아두는 것입니다. 그 후 HtmlRenderer가 이 Node 트리를 쭉 훑으면서 <h2>, <p>, <strong> 태그로 알맞게 바꾸어 최종 HTML을 완성합니다.
