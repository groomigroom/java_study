스프링 부트와 타임리프 환경에서 th:fragment는 다른 HTML 파일에서 재사용할 수 있도록 '이 태그 영역을 하나의 템플릿 조각(Fragment)으로 정의하겠다'고 선언하는 속성입니다.
이전 질문에서 확인했던 th:replace="~{파일경로 :: 조각이름}" 문법으로 불러와서 쓸 수 있는 '부품(조각)'을 만드는 역할을 합니다.
------------------------------
## 💡 핵심 기능 2가지

   1. 공통 컴포넌트(부품) 정의
   * 헤더, 푸터, 사이드바, 에러 메시지창, 페이지네이션 등 여러 화면에서 똑같이 반복되는 HTML 코드를 이 속성을 사용해 하나의 독립된 부품으로 만듭니다.
   2. 파라미터 전달 기능 (함수처럼 사용)
   * 자바나 자바스크립트의 함수(Method)처럼, th:fragment를 선언할 때 매개변수(파라미터)를 지정하면 외부에서 데이터를 넘겨받아 동적으로 조각을 렌더링할 수 있습니다.
   
------------------------------
## 💻 코드 예시로 보기## 1. 조각 정의하기 (부품 만들기)
src/main/resources/templates/common/footer.html 파일에 하단 푸터 영역을 정의합니다. 이때 파라미터(companyName)도 함께 받을 수 있도록 만들어 보겠습니다.

<!DOCTYPE html>
<html xmlns:th="http://thymeleaf.org">
<!-- 이 div 영역을 'siteFooter'라는 이름의 조각으로 정의하고, companyName을 인자로 받습니다 -->
<div th:fragment="siteFooter(companyName)">
    <footer>
        <p>© 2026 <span th:text="${companyName}">회사명</span>. All rights reserved.</p>
    </footer>
</div>

</html>

## 2. 조각 불러오기 (부품 조립하기)
메인 화면인 main.html에서 위에서 만든 푸터 조각을 불러옵니다. 이때 원하는 회사명을 인자값으로 넘겨줍니다.

<!DOCTYPE html>
<html xmlns:th="http://thymeleaf.org">
<body>

    <main>
        <h2>메인 콘텐츠 영역입니다.</h2>
    </main>

    <!-- common/footer.html 파일의 siteFooter 조각을 가져오면서 '네이버'라는 값을 전달합니다 -->
    <div th:replace="~{common/footer :: siteFooter('네이버')}"></div>

</body>
</html>

------------------------------
## 🔄 흐름 한눈에 이해하기
타임리프의 레이아웃(Layout) 시스템은 항상 정의(th:fragment)와 호출(th:replace 또는 th:insert)이 짝을 이루어 동작합니다.

* th:fragment="공통이름" ➡️ "이 영역을 공통이름이라는 부품으로 지정할게!" (제공자)
* th:replace="~{파일 :: 공통이름}" ➡️ "저 파일에 있는 공통이름 부품을 가져와서 내 태그랑 교체해 줘!" (소비자)

------------------------------
## 💡 꿀팁: 파라미터가 없는 단순 조각 정의
인자값이 필요 없는 단순한 형태라면 아래와 같이 괄호를 생략하고 이름만 적어서 정의하면 됩니다.

<div th:fragment="simpleHeader">
    <nav>심플한 네비게이션 바</nav>
</div>

이제 타임리프 폼(th:object, th:field)부터 레이아웃 조각(th:fragment, th:replace, ~{...})까지 핵심 속성들을 모두 살펴보았습니다.
혹시 이 개념들을 활용해서 웹 페이지의 전체적인 틀(상단/본문/하단)을 잡는 레이아웃 구성을 직접 구현해 보고 싶으신가요? 필요하시다면 구조화된 예시 코드를 작성해 드릴 수 있습니다.
