자바 스프링 부트에서 TypeReference<>()는 Jackson 라이브러리로 복잡한 JSON(예: List<UserDto> 또는 Map<String, Object>)을 자바 객체로 변환할 때, 자바의 제네릭(Generic) 타입 정보를 보존하기 위해 사용하는 추상 클래스입니다.
앞서 질문하신 .readValue() 메서드와 함께 사용되며, 이 역시 스프링 부트 내장 클래스가 아니라 내부 탑재된 Jackson 라이브러리(com.fasterxml.jackson.core.type.TypeReference)의 기능입니다 [json-jackson].
이와 관련된 상세한 의미와 필수 스타터 의존성은 다음과 같습니다.
------------------------------
## 1. TypeReference<>()의 핵심 의미
자바는 컴파일이 끝나고 코드가 실행될 때 generic 타입 정보가 사라지는 타입 이레이저(Type Erasure) 특징을 가지고 있습니다.
단순히 .readValue(json, List.class)라고만 작성하면, Jackson은 List 안의 내용물이 어떤 객체인지 알 수 없어 기본 형태인 Map 구조로 변환해 버립니다. 이때 TypeReference를 사용하면 "이 JSON을 UserDto 객체들이 담긴 리스트로 정확히 변환해 달라"고 런타임 시점까지 타입 정보를 명확하게 전달할 수 있습니다.
## 💡 실제 사용 예시

ObjectMapper objectMapper = new ObjectMapper();
String jsonArray = "[{\"name\":\"홍길동\",\"age\":25}, {\"name\":\"이순신\",\"age\":30}]";
// ❌ generic 타입 정보가 소실되어 List<LinkedHashMap> 구조로 잘못 변환됨
List<UserDto> list = objectMapper.readValue(jsonArray, List.class); 
//  TypeReference를 사용하여 List<UserDto>로 정확하게 변환
List<UserDto> correctList = objectMapper.readValue(
    jsonArray, 
    new TypeReference<List<UserDto>>() {} // 괄호 뒤에 {} 가 붙는 '익명 클래스' 형태로 선언합니다.
);

------------------------------
## 2. 이게 속해있는 Start Dependency (스타터 의존성)
TypeReference는 Jackson 라이브러리의 핵심 코어 모듈에 포함되어 있습니다. 따라서 .readValue()와 마찬가지로 웹 관련 기본 스타터를 프로젝트에 추가하면 자동으로 설치되어 바로 사용할 수 있습니다.
## 1) 웹 MVC 환경 (가장 보편적)
스프링 부트로 일반적인 웹 API(REST API)를 만들 때 사용하는 Spring Web 스타터에 기본 포함되어 있습니다.

* Gradle: implementation 'org.springframework.boot:spring-boot-starter-web'
* Maven: <artifactId>spring-boot-starter-web</artifactId>

## 2) 화면/웹 기능 없이 JSON 파싱 기능만 독립적으로 쓰고 싶을 때

* Gradle: implementation 'org.springframework.boot:spring-boot-starter-json'
* Maven: <artifactId>spring-boot-starter-json</artifactId>

의존성이 주입되면 패키지 상단에 import com.fasterxml.jackson.core.type.TypeReference;를 선언하여 사용합니다 [json-jackson].
------------------------------
## 💡 실무 사용 시 팁
new TypeReference<...>() {} 구문 맨 뒤에 중괄호 {}가 붙는 이유는, 자바에서 제네릭 타입 정보를 런타임까지 영속적으로 남기기 위해 익명 서브클래스를 생성하는 독특한 기법(Super Type Token)을 사용하기 때문입니다. {}를 생략하면 컴파일 에러가 발생하므로 문법에 주의해야 합니다.
지금까지 질문하신 내용(RefreshEntity ➡️ UserDetails ➡️ UserRepository ➡️ AuthenticationServiceException ➡️ .readValue() ➡️ TypeReference)을 보면, 데이터베이스나 Redis에서 사용자/토큰 정보(JSON 구조)를 가져와 세부적으로 파싱하고 스프링 시큐리티 인증을 처리하는 고난도 로직을 구현 중이신 것 같습니다.
혹시 특정 JSON 데이터를 자바 객체(List 또는 Map)로 변환하는 과정에서 매핑 에러(MismatchedInputException 등)가 발생했나요? 변환하려는 JSON 예시 문과 타겟 자바 클래스 구조를 공유해 주시면 올바른 코드 구조를 잡아드리겠습니다!
