Thymeleaf에서 th:if="${product != null}"은 product 객체가 null이 아닐 때(즉, 데이터가 존재할 때)만 해당 HTML 태그를 화면에 렌더링(출력)하라는 의미의 조건문입니다. [1, 2] 
## 💡 핵심 동작 원리

* 
* 조건이 참(true)일 때: product라는 이름으로 전달된 데이터가 비어있지 않다면 태그와 그 하위 요소들이 정상적으로 출력됩니다.
* 조건이 거짓(false)일 때: product가 존재하지 않는다면(null), 해당 HTML 태그 전체가 웹 브라우저 화면에서 아예 사라집니다. [1, 2] 
* 

------------------------------
## 🛠️ 왜 주로 사용할까요? (사용 목적)
서버에서 데이터를 받아올 때, 상품 데이터가 없는 상태에서 속성을 조회하면 NullPointerException(서버 에러)이 발생합니다. 이를 방지하기 위해 안전장치로 사용합니다. [3, 4] 
## 1. 잘못된 코드 (에러 발생 위험)

<!-- 만약 product가 null이면 product.name을 참조할 때 에러가 발생합니다 -->
<div>
    <p th:text="${product.name}">상품명</p>
</div>

## 2. 올바른 코드 (th:if로 예외 처리)

<!-- product가 존재할 때만 내부 코드가 실행되므로 안전합니다 -->
<div th:if="${product != null}">
    <p th:text="${product.name}">상품명</p>
</div>

------------------------------
## 🔗 연관된 팁

   1. 반대 조건 처리 (th:unless): 만약 데이터가 없을 때 문구를 보여주고 싶다면 th:unless를 함께 사용할 수 있습니다.
   
   <div th:unless="${product != null}">
       <p>등록된 상품이 없습니다.</p>
   </div>
   
   2. 더 짧은 문법 (Safe Navigation Operator): 단순 텍스트 출력 시 에러를 막고 싶다면 ? 기호를 붙여 th:text="${product?.name}" 형태로도 작성할 수 있습니다. [1, 3, 4, 5, 6]
