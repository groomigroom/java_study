DTD 및 XSD의 다운로드 설정 XML (Wild Web developer)에서 download external resources like referenced dtd, xsd 체크하기 이 옵션을 체크하는 이유는 XML 파일에 정의된 외부 DTD나 XSD 파일을 이클립스가 인터넷에서 직접 내려받아 XML 오류(빨간줄)를 없애고 자동 완성 및 유효성 검증을 정상적으로 수행하도록 허용하기 위해서입니다. 이 설정을 켜지 않으면 Downloading external resources is disabled 경고나 에러가 발생합니다. 주요 이유 및 효과 외부 파일 다운로드 허용: MyBatis 등의 설정 파일에 쓰인 외부 http:// 주소의 DTD/XSD 스키마 파일을 가져옵니다. 에러 표시 해결: 파일이 없어 발생하는 가짜 코드 오류(빨간 밑줄)를 없애줍니다. 코드 편의 기능: 태그 자동 완성 및 올바른 작성 여부 검사를 돕습니다.
