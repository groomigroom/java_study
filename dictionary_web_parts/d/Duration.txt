스프링 부트(Spring Boot)에서 java.time.Duration은 외부 설정 파일(application.properties 또는 application.yml)의 시간(간격) 관련 값을 자바 코드 객체로 자동 변환(Binding)하여 주입받을 때 사용하는 표준 시간 타입입니다. [1] (https://stackoverflow.com/questions/51818137/spring-boot-2-converting-duration-java-8-application-properties), [2] (https://rightmove.blog/property-binding-to-java-time-in-spring-boot/)

주요 의미와 특징

1. 외부 설정 값의 자동 바인딩
	• @ConfigurationProperties 등을 사용할 때, 설정 파일에 적은 시간 값을 Duration 타입 필드로 바로 매핑할 수 있습니다.
	• 예: session-timeout=10s 라고 작성하면 자바 코드에서 Duration sessionTimeout 으로 안전하게 주입받습니다. [1] (https://jdriven.com/blog/2024/10/Spring-Boot-Sweets-Using-Duration-Type-With-Configuration-Properties), [2] (https://docs.spring.io/spring-boot/reference/features/external-config.html), [3] (https://docs.spring.io/spring-boot/docs/2.4.2/reference/html/spring-boot-features.html), [4] (https://stackoverflow.com/questions/51818137/spring-boot-2-converting-duration-java-8-application-properties)
2. 지원하는 입력 포맷 (3가지 방식)
	• 숫자만 입력 (기본값 밀리초 ms): timeout=5000 (별도 지정이 없으면 5000밀리초 = 5초)
	• 단위 접미사 결합 (가독성 우수): 10s(초), 3m(분), 2h(시간), 500ms(밀리초), 100ns(나노초), 5d(일) 등
	• ISO-8601 표준 포맷: PT10S(10초), PT1M30S(1분 30초) 등 [1] (https://devdojo.academy/en/blog/duration-configurationproperties-yaml-10-milliseconds/), [2] (https://stackoverflow.com/questions/51818137/spring-boot-2-converting-duration-java-8-application-properties)
3. 기본 단위 커스텀 (@DurationUnit)
	• 숫자로만 적었을 때 밀리초 대신 다른 단위(예: 초)를 기본값으로 쓰고 싶다면 @DurationUnit(ChronoUnit.SECONDS) 어노테이션을 필드에 붙여줄 수 있습니다. [1] (https://docs.spring.io/spring-boot/reference/features/external-config.html), [2] (https://devdojo.academy/en/blog/duration-configurationproperties-yaml-10-milliseconds/)

코드 예시

• 설정 파일 (application.yml)yaml
app:
  session-timeout: 30s
  read-timeout: 1500ms
코드를 사용할 때는 주의가 필요합니다.
• 자바 설정 클래스java
import java.time.Duration;
import org.springframework.boot.context.properties.ConfigurationProperties;

@ConfigurationProperties(prefix = "app")
public class AppProperties {
    private Duration sessionTimeout;
    private Duration readTimeout;

    // Getter, Setter 생략
}
코드를 사용할 때는 주의가 필요합니다.
만약 특정 설정값(예: spring.redis.timeout 등)의 적용 방식이나 변환 중 발생한 에러에 대해 알고 싶다면 어떤 설정 프로퍼티를 사용 중인지 알려주세요.
