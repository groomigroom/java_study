dispatchserverlet

        5자바 스프링 mvc에서 DispatcherServlet
         자바 스프링 MVC에서 DispatcherServlet(디스패처 서블릿)은
        모든 HTTP 요청을 가장 먼저 받아 알맞은 컨트롤러에 전달하고,
        처리 결과를 받아 응답하는 프론트 컨트롤러(Front Controller)입니다.
        스프링 MVC의 핵심 엔진 역할을 합니다.
        주요 역할과 특징
        요청 통합 관리: 모든 웹 요청을 단일 서블릿에서 먼저 받아서 공통 작업을 처리합니다.
        컨트롤러 위임: 어떤 컨트롤러가 요청을 처리해야 할지
        찾아서 작업을 넘겨줍니다.
        응답 생성: 컨트롤러가 돌려준 결과와 화면(View) 
        정보를 바탕으로 최종 응답을 만듭니다.
        동작 흐름
        클라이언트가 요청을 보냅니다.
        DispatcherServlet이 요청을 받습니다.
        HandlerMapping에게 알맞은 컨트롤러를 찾아달라고
        부탁합니다.
        HandlerAdapter를 통해 컨트롤러를 실행합니다.
        컨트롤러가 비즈니스 로직을 처리하고 결과를 돌려줍니다.
        ViewResolver를 통해 뷰(화면) 파일을 찾거나 
        데이터를 변환합니다.최종 결과를 클라이언트에게 응답합니다.
