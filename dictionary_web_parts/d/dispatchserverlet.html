DTO

DTO(Data Transfer Object)는 데이터 전송 객체를 뜻합니다.
이는 컨트롤러, 서비스, 리포지토리 등 서로 다른 계층 사이에서 데이터를 주고받기 위해 사용하는 순수한 자바 객체입니다.
주로 데이터를 담는 필드와 간단한 Getter/Setter 메서드만 가집니다.
DTO의 주요 특징
로직 없음: 순수하게 데이터를 담는 용도로만 쓰이고 비즈니스 로직은 포함하지 않습니다.
계층 간 분리: 데이터베이스와 연결된 엔티티(Entity) 클래스를 직접 화면이나 클라이언트에 노출하지 않도록 보호합니다.
유연성: 클라이언트가 요구하는 데이터 모양과 데이터베이스의 테이블 구조가 다를 때 중간에서 형태를 맞춰줍니다.
DTO를 쓰는 이유
보안 강화: 데이터베이스의 민감한 정보(예: 비밀번호 등)가 클라이언트에 그대로 노출되는 것을 막습니다.
유지보수 편리: 데이터베이스 구조가 바뀌어도 DTO와 엔티티를 분리해 두면 코드가 쉽게 망가지지 않습니다.
성능 향상: 필요한 데이터만 골라서 담을 수 있어 불필요한 데이터 전송을 줄입니다.


dto 예제
start dependency lombok 미리 설정하고

javaimport lombok.Getter;
import lombok.Setter;
import lombok.NoArgsConstructor;
import lombok.AllArgsConstructor;

@Getter
@Setter
@NoArgsConstructor
@AllArgsConstructor
public class UserRequestDto {
    private String username;
    private String email;
    private int age;
}

컨트롤러 예제

import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/users")
public class UserController {

    @PostMapping
    public String createUser(@RequestBody UserRequestDto requestDto) {
    // 받은 DTO 데이터를 활용하는 로직
        String name = requestDto.getUsername();
        return "회원 생성 성공: " + name;
    }
}
