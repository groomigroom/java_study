전자정부 표준프레임워크(개발환경, 기반이 되는 이클립스 기반 IDE)에서 Data Source Explorer는 이클립스 개발툴 내에서 외부 데이터베이스(DB)와 직접 연결하여 데이터를 관리하고 조회할 수 있는 뷰(View)를 의미합니다. [1] (http://standout.tistory.com/596), [2] (https://study-firebear.tistory.com/14)

주요 의미 및 역할

• 데이터베이스 연결 관리: MySQL, Oracle, MariaDB, Tibero, MS-SQL 등 다양한 종류의 외부 데이터베이스 드라이버를 등록하고 서버에 접속할 수 있습니다. [1] (http://standout.tistory.com/596)
• 스키마 및 테이블 구조 확인: 이클립스 창을 벗어나지 않고도 DB에 생성된 테이블, 뷰, 프로시저, 컬럼 구조, 데이터 타입 등을 직접 트리 형태로 탐색할 수 있습니다.
• SQL 쿼리 실행 및 데이터 조회: 특정 테이블의 데이터를 직접 조회(Data Output)하거나, 간단한 SQL 쿼리를 작성·실행하여 테스트해 볼 수 있습니다.
• 공통컴포넌트 및 개발 시 활용: 전자정부 표준프레임워크로 웹 프로젝트를 구축하거나 공통 컴포넌트(로그인, 게시판, 공통코드 등)를 설치할 때, DB 스키마가 정상적으로 생성되었는지 확인하거나 연동 정보를 테스트할 때 필수적으로 활용됩니다. [1] (https://egovframe.go.kr/cmm/file/readDownloadFile.do?fileId=FILE_000000000012769&fileSn=0), [2] (https://open.egovframe.org/nforges/qna/qna/7150/.do)

사용 방법 (기본 경로)

1. 이클립스 메뉴 상단에서 Window > Show View > Data Source Explorer를 선택해 뷰를 활성화합니다. [1] (http://standout.tistory.com/596), [2] (https://study-firebear.tistory.com/14)
2. Database Connections 항목에서 우클릭 후 New를 선택합니다. [1] (http://standout.tistory.com/596)
3. 사용할 데이터베이스 종류를 선택하고, 접속 정보(IP, Port, Database명, 사용자 ID, Password) 및 JDBC 드라이버를 설정하여 연결을 완료합니다. [1] (http://standout.tistory.com/596)
공식 가이드 및 관련 문서에 대한 자세한 내용은 표준프레임워크 개발가이드에서 확인할 수 있습니다. [1] (https://www.egovframe.go.kr/docs)
만약 Data Source Explorer를 설정하는 과정에서 특정 데이터베이스 드라이버 연결 오류나 공통컴포넌트 DB 생성 시 겪는 문제가 있다면 말씀해 주세요. 해결 방법을 안내해 드릴 수 있습니다.
