LoginFilter는 일반적으로 스프링 시큐리티에서 사용자의 로그인 요청(아이디/비밀번호 제출)을 가로채어 인증을 처리하는 커스텀 필터를 의미합니다.
스프링 시큐리티가 기본으로 제공하는 UsernamePasswordAuthenticationFilter를 상속받아, 서비스의 요구사항(예: JSON 형식의 로그인 요청 처리)에 맞게 직접 구현할 때 주로 이 이름을 사용합니다. [1] 
## 💡 LoginFilter의 의미와 역할

* 로그인 요청 가로채기: 사용자가 보낸 로그인 데이터(ID, PW)를 확인합니다.
* 인증 객체 생성: 수신한 정보를 바탕으로 UsernamePasswordAuthenticationToken 객체를 만듭니다.
* 인증 위임: 토큰 객체를 AuthenticationManager에게 전달하여 실제 데이터베이스의 정보와 일치하는지 검증을 요청합니다.
* 성공/실패 처리: 인증이 성공하면 JWT 토큰을 발급하거나 세션을 생성하고, 실패하면 에러 메시지를 반환합니다.

------------------------------
## 📦 속해있는 Start Dependency (의존성)
LoginFilter를 구현하고 사용하기 위해 필요한 스프링 부트 스타터 의존성은 Spring Security입니다.
## Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-security'

## Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-security</artifactId>
</dependency>
