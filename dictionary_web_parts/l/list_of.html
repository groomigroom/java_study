List.of

      자바 9부터 도입된 List.of()는 요소들을 모아 수정할 수 없는(불변, Immutable) 
      리스트를 간편하게 생성할 때 사용하는 정적 팩토리 메서드입니다. 
      생성된 리스트는 요소를 추가, 삭제, 수정할 수 없으며 null 값을 허용하지 않습니다.
      주요 특징
      불변성(Immutable): 리스트에 요소를 add, remove, set 하려고 하면 
      UnsupportedOperationException 에러가 발생합니다.
      Null 불가: 요소에 null을 지정하면 NullPointerException이 발생합니다.
      간결함: 코드가 짧아지고 가독성이 좋아집니다.코드 예제
      1. 기본 사용법java
      import java.util.List;

      public class ListOfExample {
          public static void main(String[] args) {
              // List.of를 이용한 불변 리스트 생성
              List puppys = List.of("구름이", "멍멍이", "멍멍구름");
              
              System.out.println(puppys); // [구름이, 멍멍이, 멍멍구름]
          }
      }
      코드를 사용할 때는 주의가 필요합니다.2. 예외 발생 상황 (수정 시도 및 Null 입력)
                java
      import java.util.List;
      
      public class ListOfErrorExample {
          public static void main(String[] args) {
              List list = List.of("A", "B");

      }
