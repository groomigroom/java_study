@AllArgsConstructor

        자바 스프링(Lombok 라이브러리)에서 @AllArgsConstructor는 클래스에 
        존재하는 모든 필드(변수)를 매개변수로 받는 생성자를 자동으로 만들어 주는 어노테이션입니다.
        주요 특징
        모든 필드 포함: 선언된 순서대로 모든 필드를 인자로 갖는 생성자가 코드 뒤에서 자동으로 만들어집니다.
        코드 줄이기: 개발자가 직접 public ClassName(필드1, 필드2...) 같은 생성자 코드를 일일이 쓰지 않아도 됩니다.
        주의할 점
        필드 순서 변경 위험: 필드 순서가 바뀌면 생성자 매개변수 순서도 같이 바뀝니다. 
        이로 인해 값 대입이 꼬일 수 있어 주의해야 합니다.
        스프링 빈 주입 시 지양: 스프링에서 의존성 주입을 할 때는 보통 필수 필드(final)만 받는 @RequiredArgsConstructor를 권장합니다. 
        모든 필드를 다 받는 @AllArgsConstructor는 실수가 생기기 쉬워 무분별한 사용은 피하는 편이 좋습니다.
