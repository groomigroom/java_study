전자정부 표준프레임워크(스프링 기반)에서 @Named 어노테이션은 자바 표준 의존성 
주입(DI, Dependency Injection) 규격인 JSR-330에 정의된 어노테이션으로, 
스프링의 @Component나 @Autowired와 비슷한 역할을 합니다. 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte4.1:fdl:ioc_container:jsr_330_standard_annotations)

주요 의미와 역할

• 빈(Bean) 등록 (@Component 대체)
	• 클래스 위에 @Named("beanName")을 붙이면, 해당 클래스를 스프링 컨테이너가 관리하는 스프링 빈(Bean)으로 자동 등록합니다.
	• 스프링 고유의 @Component 대신 자바 표준(JSR-330) 어노테이션을 사용하여 특정 프레임워크에 대한 종속성을 줄이고 싶을 때 활용합니다.
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte4.1:fdl:ioc_container:jsr_330_standard_annotations)
• 의존성 주입 시 빈 이름 지정 (@Qualifier 대체)
	• 필드나 생성자 등에 @Inject (자바 표준 @Autowired 대응)와 함께 사용해, 주입할 빈의 이름(ID)을 명시적으로 지정할 때 씁니다.
	• 스프링의 @Qualifier("name")과 거의 같은 기능입니다. 
[1] (https://engkimbs.tistory.com/entry/Spring-%EC%8A%A4%ED%94%84%EB%A7%81Spring-Qualifier-Named-Primary-%EC%9D%98%EC%A1%B4%EA%B0%9D%EC%B2%B4-%EC%84%A0%ED%83%9D), [2] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte4.1:fdl:ioc_container:jsr_330_standard_annotations)

스프링 어노테이션과의 비교


자바 표준 (JSR-330)	스프링 고유 어노테이션	역할
@Named	@Component 또는 @Qualifier	빈 등록 및 이름 지정
@Inject	@Autowired	의존성 객체 주입
@Singleton	@Scope("singleton")	빈의 스코프 설정

참고: 전자정부 표준프레임워크는 내부적으로 스프링 프레임워크를 사용하기 때문에, @Named를 사용하든 스프링의 
@Component / @Autowired를 사용하든 동작 방식과 결과는 거의 동일합니다.
