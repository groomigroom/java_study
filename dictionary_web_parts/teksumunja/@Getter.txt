롬복(Lombok)의 @Getter 어노테이션은 자바 컴파일 시점에 필드 값을 반환하는 get 메서드를 자동으로 생성합니다. 
이를 순수 자바 코드로 작성하면 다음과 같이 각 필드의 값을 반환하는 표준 메서드 형태가 됩니다.
## 1. 롬복을 사용한 코드

import lombok.Getter;

@Getterpublic class User {
    private String name;
    private int age;
    private boolean active; // boolean 타입 예시
}

## 2. 순수 자바로 변환한 코드 (동일한 기능)

public class User {
    private String name;
    private int age;
    private boolean active;

    // name 필드의 Getter
    public String getName() {
        return name;
    }

    // age 필드의 Getter
    public int getAge() {
        return age;
    }

    // active (boolean) 필드의 Getter
    // 자바 빈 규약에 따라 boolean 타입은 'get' 대신 'is'를 접두사로 사용합니다.
    public boolean isActive() {
        return active;
    }
}

## 💡 자바 빈(JavaBean) 명명 규칙

* 
* 일반 데이터 타입(String, int 등): get + 필드명(첫 글자 대문자)()
* boolean 데이터 타입: is + 필드명(첫 글자 대문자)() 형태로 생성되는 것이 표준 규약입니다. [2, 4]
