자바 스프링에서 @PathVariable은 URL 경로(Path)에 포함된 특정 값을 컨트롤러 메서드의 파라미터로 전달(바인딩)받을 때 사용하는 애노테이션입니다. 주로 RESTful API에서 /users/{id}와 같이 자원의 식별자를 경로로 지정할 때 쓰입니다.주요 특징URL 경로 추출: 물음표(?) 뒤에 오는 쿼리 스트링이 아니라, URL 주소 라인 자체의 값을 가져옵니다.중괄호 매칭: @GetMapping("/users/{id}")처럼 경로에 {변수명}을 넣고, 메서드 안에서 @PathVariable("id") Long id로 받습니다.이름 생략 가능: 변수 이름과 파라미터 이름이 같다면 @PathVariable Long id처럼 괄호 안의 이름을 생략할 수 있습니다.@PathVariable vs @RequestParam 차이@PathVariable: URL 경로의 일부를 변수로 취급합니다. (예: /boards/15)@RequestParam: URL의 물음표 뒤 쿼리 파라미터를 취급합니다. (예: /boards?id=15)
