스프링 부트(Spring Boot)에서 @AutoConfiguration은 프로젝트에 추가된 라이브러리와 클래스패스(Classpath) 환경을 분석하여, 
개발자가 일일이 설정하지 않아도 필요한 스프링 빈(Bean)들을 자동으로 구성하고 등록해 주는 핵심 기능 및 어노테이션을 의미합니다. 


주요 특징 및 의미

• 반복적인 설정 감소: 과거 스프링(Spring)에서는 데이터베이스, 웹 MVC, 보안 등을 사용하기 위해 수많은 XML이나 자바 
@Configuration 설정을 직접 작성해야 했으나, 스프링 부트는 이를 자동으로 처리해 줍니다. 
• 클래스패스 기반 동작: 프로젝트에 특정 라이브러리(예: spring-boot-starter-data-jpa, spring-boot-starter-web 등)가 포함되어 있는지 
확인하고, 그에 맞는 빈을 조건부로 생성합니다.
• 개발 집중: 인프라나 환경 설정에 쓰는 시간을 줄이고 비즈니스 로직 구현에 집중할 수 있게 해줍니다.

동작 방식 요약

1. 애플리케이션이 실행될 때 @SpringBootApplication 어노테이션 내부에 있는 @EnableAutoConfiguration이 작동합니다.
2. 스프링 부트는 META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports 
(또는 과거 버전의 spring.factories) 파일에 정의된 수많은 자동 설정 클래스들을 읽어옵니다.
3. 각 설정 클래스에 붙은 조건(@ConditionalOnClass, @ConditionalOnMissingBean 등)을 검사하여, 
조건을 만족하는 경우에만 스프링 컨테이너에 빈을 자동으로 등록합니다.
