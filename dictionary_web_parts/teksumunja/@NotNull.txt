자바 스프링 부트(Spring Boot)에서 @NotNull 어노테이션의 의미와 이것이 포함된 스타터 의존성(Starter Dependency)에 대한 핵심 요약입니다.
------------------------------
## 1. @NotNull이란 무엇인가요?
@NotNull은 데이터가 null 값을 가질 수 없도록 강제하는 데이터 검증(Validation) 어노테이션입니다.

* 검증 대상: 주로 사용자가 입력한 값(DTO, Request Body)이나 엔티티(Entity) 필드의 유효성을 검사할 때 사용합니다.
* 공백 허용: 값의 길이가 0이거나 공백(" ")인 문자열은 유효한 것으로 판단합니다. 오직 null만 차단합니다.
* 동작 시점: 컨트롤러 메서드 매개변수 앞에 @Valid 또는 @Validated를 붙여주어야 검증이 실제로 동작합니다.

public class UserRequest {
    @NotNull(message = "이름은 필수 항목입니다.")
    private String name; // null은 안 되지만, "" 이나 " " 은 통과됨
}

## 💡 @NotEmpty, @NotBlank와의 차이점 (문자열 기준)

* @NotNull: null만 허용 안 함. ("", " " 허용)
* @NotEmpty: null과 ""(빈 문자열) 허용 안 함. (" " 허용)
* @NotBlank: null, "", " " 모두 허용 안 함. (가장 엄격함)

------------------------------
## 2. @NotNull은 어떤 Start Dependency에 속해있나요?
@NotNull은 스프링 기본 코어 모듈이 아니므로, 사용하려면 유효성 검증 전용 스타터 의존성을 직접 추가해야 합니다.

* 실제 패키지 경로: jakarta.validation.constraints.NotNull (자바 표준 스펙)
* 추가해야 할 스타터 의존성: spring-boot-starter-validation

## 🛠️ 의존성 설정 방법
Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-validation'

Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-validation</artifactId>
</dependency>

------------------------------
현재 입력 폼이나 API 요청에서 사용자의 입력값을 검증하는 로직을 구현 중이신가요? 구현 과정에서 검증 실패 시 에러 메시지를 예쁘게 리턴하는 방법이나 @Valid 적용 위치가 궁금하시다면 언제든 말씀해 주세요!
