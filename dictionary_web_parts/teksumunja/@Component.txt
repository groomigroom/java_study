@Component.txt

@Component는 개발자가 작성한 클래스를 스프링 컨테이너에 빈(Bean)으로 자동 등록하라고 알려주는 자바 애노테이션입니다. 
이 애노테이션은 별도의 의존성을 추가할 필요 없이, 스프링의 가장 핵심이 되는 라이브러리인 spring-context 모듈에 기본적으로 포함되어 있습니다.
------------------------------
## 1. @Component의 핵심 의미

* 
* 스프링 빈(Bean) 자동 등록: 클래스 레벨에 이 애노테이션을 붙이면, 스프링이 구동될 때 컴포넌트 스캔(@ComponentScan)을 통해 해당 클래스의 인스턴스를 자동으로 생성하고 관리합니다. [1, 2, 4] 
* 의존성 주입(DI) 가능: 빈으로 관리되는 객체들은 스프링 컨테이너 안에서 서로 다른 객체에게 주입(@Autowired 등)될 수 있는 자격을 갖춥니다. [3, 5, 6] 
* 보편적 개념: 스프링이 제공하는 @Controller, @Service, @Repository, @Configuration 등은 모두 내부에 @Component를 포함하고 있는 특수화된 형태입니다. [7, 8] 
* 

------------------------------
## 2. 포함된 Start Dependency (의존성)
스프링 부트(Spring Boot)로 프로젝트를 생성할 때 지정하는 spring-boot-starter 의존성 계층 구조를 살펴보면 어디에 속해 있는지 쉽게 알 수 있습니다.
## 📦 가장 밑단의 모듈 (실제 위치)
@Component는 다음 jar 라이브러리 안에 들어있습니다.

* 
* org.springframework:spring-context
* 

## 🛠️ 스프링 부트 스타터(Starter) 기준
스프링 부트 프로젝트에서는 개발자가 spring-context를 직접 가져오지 않습니다. 대신 아래 스타터 중 어떤 것을 선택하더라도 자동으로 포함됩니다.

* 
* spring-boot-starter: 모든 스프링 부트 애플리케이션의 핵심 기반이 되는 기본 스타터입니다.
* spring-boot-starter-web: 웹 개발을 할 때 흔히 선택하는 스타터로, 내부적으로 spring-boot-starter를 포함하고 있으므로 당연히 @Component를 사용할 수 있습니다. [9] 
* 

즉, spring-boot-starter만 있으면 별도의 설정 없이 바로 사용할 수 있습니다. [10] 
------------------------------
## 3. 코드 예시

import org.springframework.stereotype.Component;

@Component // 1. 스프링이 이 클래스를 발견하고 빈으로 등록합니다.public class OrderService {
    
    public void process() {
        System.out.println("주문을 처리합니다.");
    }
}
