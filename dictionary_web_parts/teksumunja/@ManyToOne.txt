@Entity 내에서 N:1 관계를 나타낼 수 있다. 

자바 스프링 부트(Spring Boot)에서 @ManyToOne은 JPA(Java Persistence API) / Jakarta Persistence에서 사용하는 데이터베이스 연관 관계 매핑 어노테이션입니다.
우리말로 다대일(N:1) 관계를 의미하며, 객체지향 도메인 모델과 관계형 데이터베이스 테이블을 연결할 때 사용합니다.
------------------------------
## 1. @ManyToOne의 의미 (예시)
데이터베이스 설계에서 가장 흔하게 발생하는 "여러 개가 하나를 참조하는 구조"를 나타냅니다.

* 예시: 회원(Member)과 팀(Team)의 관계
* 여러 명의 회원(Many)이 하나의 팀(One)에 속할 수 있습니다.
   * 이 경우 Member 엔티티 클래스 내의 Team 필드 위에 @ManyToOne을 붙여 관계를 정의합니다.

@Entitypublic class Member {
    @Id @GeneratedValue
    private Long id;
    private String username;

    @ManyToOne // 여러 회원이 하나의 팀에 속함
    @JoinColumn(name = "team_id") // 외래 키(FK) 매핑
    private Team team;
}

------------------------------
## 2. 포함되어 있는 스타터 의존성 (Start Dependency)
@ManyToOne을 사용하기 위해 프로젝트에 추가해야 하는 스프링 부트 스타터 의존성은 spring-boot-starter-data-jpa입니다.
## 빌드 도구별 추가 방법
Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>

Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-data-jpa'

이 스타터 의존성을 추가하면 내부적으로 하이버네이트(Hibernate) 구현체와 관련 라이브러리(jakarta.persistence-api)가 함께 다운로드되어 @ManyToOne 어노테이션을 바로 사용할 수 있게 됩니다.
------------------------------
현재 작성 중이신 엔티티 코드에서 반대 방향(일대다, 1:N)의 연관 관계 설정이나 지연 로딩(FetchType.LAZY) 같은 성능 최적화 방법도 함께 알고 싶으신가요? 필요하시다면 관련 코드를 추가로 설명해 드릴 수 있습니다.
