스프링 부트 타임리프(Thymeleaf)에서 #temporals.format()은 자바 8의 새로운 날짜/시간 객체(예: LocalDate, LocalDateTime)를 웹 화면에 원하는 형식(포맷)으로 예쁘게 출력할 때 사용하는 유틸리티 메서드입니다.
타임리프는 날짜 객체를 다루기 위해 #temporals라는 특수 객체를 제공하며, 이를 통해 자바 코드를 복잡하게 쓰지 않고도 HTML 단에서 날짜 형식을 자유롭게 변경할 수 있습니다.
------------------------------
## 💡 기본 동작 방식 (예시)
만약 컨트롤러에서 현재 시간(LocalDateTime.now())을 currentDateTime이라는 이름으로 HTML에 넘겨주었다고 가정해 보겠습니다.
## 1. 포맷을 지정하지 않았을 때 (기본 출력)

<p>현재 시간: <span th:text="${currentDateTime}"></span></p>


* 출력 결과: 2026-09-12T19:32:00.123456 (컴퓨터가 읽는 포맷이라 가독성이 떨어짐)

## 2. #temporals.format()을 사용했을 때 (가독성 개선) ⭐

<p>현재 시간: <span th:text="${#temporals.format(currentDateTime, 'yyyy-MM-dd HH:mm:ss')}"></span></p>


* 출력 결과: 2026-09-12 19:32:00 (원하는 모양으로 깔끔하게 바뀜)

------------------------------
## 🔍 자주 사용하는 패턴(Pattern) 기호
포맷을 지정할 때 두 번째 인자(따옴표 안)에 들어가는 기호들은 자바의 DateTimeFormatter 기준을 따릅니다.

* yyyy : 연도 4자리 (예: 2026)
* MM : 월 2자리 (예: 09)
* dd : 일 2자리 (예: 12)
* HH : 24시간 형식 시간 (예: 19)
* hh : 12시간 형식 시간 (예: 07)
* mm : 분 2자리 (예: 32)
* ss : 초 2자리
* E : 요일 짧게 (예: 토)

------------------------------
## 📌 다양한 활용 예시

   1. 연/월/일만 깔끔하게 출력하기
   
   <span th:text="${#temporals.format(post.createdAt, 'yyyy.MM.dd')}"></span><!-- 결과: 2026.09.12 -->
   
   2. 오전/오후 표시하기 (a 이용)
   
   <span th:text="${#temporals.format(order.orderDate, 'yyyy년 MM월 dd일 a hh시 mm분')}"></span><!-- 결과: 2026년 09월 12일 오후 07시 32분 -->
   
   
------------------------------
## ⚠️ 주의할 점

* 과거에 쓰던 옛날 날짜 객체인 java.util.Date나 Calendar 객체는 #temporals를 사용할 수 없습니다. (옛날 객체들은 #dates.format()을 사용해야 합니다.)
* 스프링 부트에서 최신 기술로 개발 중이시라면 대부분 LocalDateTime을 사용하므로 지금 질문하신 #temporals.format()을 쓰시는 것이 정석입니다.

------------------------------
현재 타임리프 화면에 게시글 등록일(Board), 주문 일자(Order), 또는 회원 가입일 중 어떤 날짜를 뿌려주려고 하시나요? 화면에 보여주고 싶으신 날짜 모양(예: 26/09/12 등)을 말씀해 주시면 정확한 포맷 코드를 작성해 드릴게요!
