@RepositoryRestResource는 개발자가 별도의 컨트롤러(Controller) 코드를 짜지 않아도, 데이터베이스 레포지토리(Repository)를 RESTful API로 즉시 노출시켜 주는 어노테이션입니다.
이 기능은 Spring Data REST 라이브러리에 속해 있습니다.
------------------------------
## 1. 설정 속성의 의미
주어진 코드 @RepositoryRestResource(collectionResourceRel = "people", path = "people")의 세부 의미는 다음과 같습니다.

* path = "people"
* API를 호출할 엔드포인트 경로 주소를 설정합니다.
   * 예시: http://localhost:8080/people로 접근하면 해당 데이터에 접근할 수 있습니다.
* collectionResourceRel = "people"
* 반환되는 JSON 데이터(HAL 양식)에서 해당 데이터 목록을 가리키는 관계 이름(Relation Name)을 정의합니다.
   * API 응답 본문 내에서 데이터 리스트가 담기는 JSON 키(Key) 이름이 됩니다.

------------------------------
## 2. 필요한 스타터 의존성 (Starter Dependency)
이 기능을 사용하려면 프로젝트 설정 파일(pom.xml 또는 build.gradle)에 아래의 의존성을 추가해야 합니다.
## Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-data-rest'

## Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-rest</artifactId>
</dependency>

------------------------------
## 3. 핵심 특징과 장점

* CRUD 자동 생성: 별도의 @RestController나 서비스 레이어 없이도 GET(조회), POST(등록), PUT/PATCH(수정), DELETE(삭제) 기능이 자동 매핑됩니다.
* HATEOAS 지원: 응답 데이터에 다음 페이지, 연관 데이터 링크 정보 등이 포함된 HAL(Hypertext Application Language) JSON 포맷을 기본으로 제공합니다.
* 생산성 극대화: 단순 데이터 입출력이 대부분인 프로토타입 개발이나 가벼운 어드민 서비스 개발 시 시간을 극적으로 줄여줍니다.

------------------------------
현재 만들고 계신 프로젝트의 데이터베이스 종류(JPA, MongoDB 등)나 HATEOAS 응답 예시가 궁금하시면 추가로 말씀해 주세요. 구체적인 엔티티 구성 방법이나 API 테스트 방식을 제안해 드릴 수 있습니다.
