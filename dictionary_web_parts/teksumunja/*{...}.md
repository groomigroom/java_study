Thymeleaf에서 *{...}(별표) 문법을 사용하는 이유는 선택 변수 식별자(Selection Variable Expression)를 의미하기 때문입니다.
쉽게 말해, "특정 객체를 기준으로 삼고, 그 객체 내부의 필드에 바로 접근하겠다"는 선언입니다. *{password1}은 전체 경로를 다 적지 않고 특정 객체의 password1 필드를 지정하기 위해 사용합니다.
이 문법이 사용되는 핵심적인 원리와 이유는 다음과 같습니다.
## 1. th:object와의 쌍을 이룸
*{...} 문법은 반드시 부모 태그에 선언된 th:object와 함께 사용됩니다.
th:object로 지정된 객체가 기준(컨텍스트)이 되며, 그 하위 태그에서는 *{필드명}만으로 해당 객체의 속성에 접근할 수 있습니다.

<!-- userDTO라는 객체를 이 <form>의 기준으로 잡습니다 -->
<form th:action="@{/signup}" th:object="${userDTO}" method="post">
    
    <!-- ${userDTO.password1} 대신 *{password1}로 축약해서 사용합니다 -->
    <input type="password" th:field="*{password1}" />
    
</form>

## 2. ${...}(달러) 문법과의 차이점

* ${userDTO.password1}: 컨텍스트 전체에서 userDTO라는 객체를 찾고, 그 안의 password1을 가져옵니다. (어디서나 사용 가능)
* *{password1}: 이미 th:object로 지정된 객체가 있으므로, 앞부분을 생략하고 password1만 콕 집어서 가져옵니다. (코드 가독성이 좋아지고 중복이 줄어듦)

## 3. th:field와 만났을 때의 효과
질문하신 코드처럼 th:field="*{password1}"을 사용하면 Thymeleaf가 HTML을 생성할 때 다음과 같은 3가지 속성을 자동으로 만들어 줍니다.

   1. id="password1" (HTML ID 속성)
   2. name="password1" (서버로 전송될 Form 데이터 이름)
   3. value="값" (컨트롤러에서 넘어온 기존 데이터가 있다면 자동 바인딩)
