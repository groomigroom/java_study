전자정부프레임워크(Spring 기반)에서 @PropertySource 어노테이션은 외부
.properties 설정 파일을 스프링 환경(Spring Environment)에 등록하여, 
파일에 작성된 키-값(Key-Value) 형태의 설정 데이터를 자바 코드나 XML 설정에서 읽어올 수 있게 만드는 역할을 합니다. 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte3:fdl:property_source), 
[2] (https://velog.io/@modsiw/Spring-%EC%8A%A4%ED%94%84%EB%A7%81%EC%97%90%EC%84%9C-Property-%ED%8C%8C%EC%9D%BC-%EB%8B%A4%EB%A3%A8%EA%B8%B0-PropertySource-Value)

주요 의미 및 역할

• 외부 설정 파일 로드: 데이터베이스 접속 정보, 파일 업로드 경로, API 키 등 환경에 따라 자주 변할 수 있는 값들을 
소스코드(.java)와 분리하여 .properties 파일에 정의하고, 이를 스프링이 인식하도록 로드합니다. 
[1] (https://godogha9man.tistory.com/197), [2] (https://velog.io/@modsiw/Spring-%EC%8A%A4%ED%94%84%EB%A7%81%EC%97%90%EC%84%9C-Property-%ED%8C%8C%EC%9D%BC-%EB%8B%A4%EB%A3%A8%EA%B8%B0-PropertySource-Value)
• 환경별 설정 분리: 개발(dev), 테스트(test), 운영(prod) 환경에 따라 다른 .properties 파일을 교체하거나 지정하여 적용할 수 있습니다. 
[1] (https://godogha9man.tistory.com/197)
• 값 주입 연동: @PropertySource로 등록한 프로퍼티 값은 주로 @Value 어노테이션을 통해 자바 빈의 필드에 주입하거나, 스프링의 Environment 
객체를 통해 프로그램 코드에서 직접 꺼내 쓸 수 있습니다. 
[1] (https://www.egovframe.go.kr/wiki/doku.php?id=egovframework:rte3:fdl:property_source), 
[2] (https://velog.io/@modsiw/Spring-%EC%8A%A4%ED%94%84%EB%A7%81%EC%97%90%EC%84%9C-Property-%ED%8C%8C%EC%9D%BC-%EB%8B%A4%EB%A3%A8%EA%B8%B0-PropertySource-Value)

사용 예시 (개념적 구조)

java
@Configuration
@PropertySource("classpath:egovframework/prop/os.properties")
public class AppConfig {

    @Value("${file.upload.path}")
    private String uploadPath;

    // uploadPath 변수에 properties 파일의 file.upload.path 값이 주입됨
}
코드를 사용할 때는 주의가 필요합니다.
• classpath:: 프로젝트의 클래스패스(src/main/resources 등) 루트를 의미합니다.
• 전자정부 표준프레임워크에서는 보통 XML 기반 설정(context-properties.xml 및 EgovPropertyServiceImpl 등)을 자주 사용하지만, 
스프링 자바 기반(@Configuration) 설정 방식을 쓸 때 표준 스프링과 동일하게 @PropertySource를 사용해 프로퍼티를 적재합니다. 
[1] (https://javacpro.tistory.com/78), [2] (https://velog.io/@modsiw/Spring-%EC%8A%A4%ED%94%84%EB%A7%81%EC%97%90%EC%84%9C-Property-%ED%8C%8C%EC%9D%BC-%EB%8B%A4%EB%A3%A8%EA%B8%B0-PropertySource-Value)
만약 XML 기반 설정(context--properties.xml)에서 프로퍼티를 불러오는 방법이나, @Value 와의 차이점에 대해 더 알고 싶으시면 편하게 말씀해 주세요.
