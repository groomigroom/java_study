@Service

        자바 스프링에서 @Service는 해당 클래스가 비즈니스 로직(Business Logic)을 처리하는 
        서비스 계층(Service Layer)의 컴포넌트임을 스프링 컨테이너에 알리는 어노테이션입니다.
        이 어노테이션이 붙은 클래스는 스프링이 자동으로 Bean으로 등록(IoC/DI)하며, 
        주로 컨트롤러와 데이터 저장소 사이에서 핵심 연산과 규칙을 수행합니다.
        주요 역할과 특징
        Bean 자동 등록: 내부적으로 @Component를 포함하고 있어 스프링 컴포넌트 스캔 대상이 되며,
        애플리케이션 실행 시 스프링 컨테이너에 의해 객체(Bean)로 생성 및 관리됩니다.
        비즈니스 로직 분리: 사용자의 요청을 받는 Controller와 데이터베이스를 다루는 Repository(DAO) 사이에서 데이터를 가공하고 핵심 기능 규칙을 실행합니다.
        가독성과 의도 표현: 기술적으로는 @Component와 동일하지만, 
        코드를 읽는 사람에게 이 클래스가 '비즈니스 로직을 담고 있는 서비스 계층'임을 명확히 전달합니다.
