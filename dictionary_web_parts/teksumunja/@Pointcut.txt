org.aspectj.lang.annotation.Pointcut은 스프링 부트 AOP(관점 지향 프로그래밍)에서 공통 코드(Advice)를 "어느 곳에 적용할지" 그 대상을 지정하고 정의하는 애너테이션입니다.
AOP에서 @Aspect가 공통 코드가 담긴 주머니라면, @Pointcut은 그 코드가 실행될 핵심 비즈니스 로직(메서드)의 주소나 범위를 정하는 일종의 '과녁' 또는 '필터' 역할을 합니다.

💡 주요 역할 및 특징

• 적용 대상 필터링: 특정 패키지, 특정 클래스, 특정 메서드 이름 패턴, 혹은 특정 애너테이션이 붙은 곳만 콕 집어서 공통 코드가 실행되도록 설정할 수 있습니다.
• 코드 재사용성: 복잡한 대상 지정 수식(표현식)을 하나의 메서드 이름으로 정의해 두고, 여러 부가 기능(@Before, @Around 등)에서 이름만 가져와 재사용할 수 있게 해줍니다.

💻 실제 사용 예시 (코드)

보통 아무런 내용이 없는 빈(void) 메서드 위에 애너테이션을 붙여서 표현식을 정의합니다.
java
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.annotation.Pointcut;
import org.aspectj.lang.annotation.Before;
import org.springframework.stereotype.Component;

@Aspect
@Component
public class LogAspect {

    // 1. Pointcut 정의: egovframework 하위의 모든 web 패키지 내 메서드를 대상으로 지정
    @Pointcut("execution(* egovframework..web..*.*(..))")
    private void webLayer() {} // 이 메서드 이름이 포인트컷의 ID 역할을 합니다.

    // 2. 위에서 정의한 Pointcut을 호출하여 공통 코드(Advice) 적용
    @Before("webLayer()")
    public void logBefore() {
        System.out.println("웹 레이어 메서드가 실행되기 직전에 이 로그가 출력됩니다.");
    }
}
코드를 사용할 때는 주의가 필요합니다.

⚙️ 자주 쓰는 Pointcut 표현식 패턴

@Pointcut 안에는 주로 execution이라는 문법을 사용하여 범위를 지정합니다.
• execution(* com.example.service.*.*(..))
	• com.example.service 패키지 바로 아래에 있는 모든 클래스의 모든 메서드 대상
• execution(* egovframework..web..*.*(..))
	• egovframework 하위의 모든 web 패키지(및 그 자식 패키지) 내의 모든 메서드 대상
• @annotation(com.example.MyCustomAnnotation)
	• 특정 커스텀 애너테이션이 붙은 메서드만 골라서 대상 지정

🔍 요약

• 의미: 부가 기능을 결합할 핵심 로직의 지점(메서드)을 선정하는 AOP 선언문
• 용도: "로그를 남길 곳", "권한을 체크할 곳" 등의 타깃 범위를 명확하게 지정하고 재사용하고 싶을 때 사용
작성 중이신 프로젝트에서 특정 컨트롤러나 서비스 모듈에만 포인트컷을 정밀하게 타깃팅하셔야 하나요? 적용하고 싶으신 패키지 구조나 메서드 패턴을 알려주시면 알맞은 Pointcut 수식을 정확하게 만들어 드릴게요!
