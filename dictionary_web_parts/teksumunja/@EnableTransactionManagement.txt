@EnableTransactionManagement는 스프링 프레임워크가 선언적 트랜잭션 관리 기능(@Transactional)을 인식하고 사용할 수 있도록 활성화하는 어노테이션입니다.
이 기능은 스프링의 핵심인 Spring TX (Transaction) 라이브러리에 속해 있습니다.
------------------------------
## 1. @EnableTransactionManagement의 핵심 의미
데이터베이스의 등록, 수정, 삭제 작업을 안전한 하나의 단위(트랜잭션)로 묶어 처리할 때 사용합니다.

* 트랜잭션 기능 활성화: 이 어노테이션이 붙어야 스프링이 비즈니스 로직(Service 레이어 등)에 작성된 @Transactional 어노테이션을 감지하고 트랜잭션 프록시 객체를 만들어 냅니다.
* 자동 롤백/커밋 제어: 작업 중 예외(Exception)가 발생하면 자동으로 데이터베이스를 이전 상태로 되돌리고(Rollback), 성공하면 변경 사항을 영구 반영(Commit)하는 인프라를 구축합니다.

## 💡 스프링 부트(Spring Boot)에서의 특별한 점 (중요)
스프링 부트 환경에서는 이 어노테이션을 직접 붙이지 않아도 됩니다. 스프링 부트가 제공하는 자동 설정(Auto Configuration) 메커니즘이 데이터베이스 스타터(spring-boot-starter-data-jpa 등)를 감지하면 자동으로 @EnableTransactionManagement를 적용해 주기 때문입니다.
------------------------------
## 2. 필요한 스타터 의존성 (Starter Dependency)
스프링 부트에서 이 기능을 활성화하는 가장 대표적인 스타터는 다음과 같습니다.
## Gradle (build.gradle)

implementation 'org.springframework.boot:spring-boot-starter-data-jpa'

## Maven (pom.xml)

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-data-jpa</artifactId>
</dependency>

참고: 단순 JDBC나 MyBatis 환경이라면 spring-boot-starter-jdbc를 사용해도 그 내부에 spring-tx 라이브러리가 포함되어 있어 트랜잭션 관리가 자동으로 활성화됩니다.

------------------------------
## 3. 실제 사용 예시 코드
스프링 부트 환경에서는 별도의 설정 없이 비즈니스 로직 클래스나 메서드 위에 @Transactional만 얹어서 사용하면 됩니다.

import org.springframework.stereotype.Service;import org.springframework.transaction.annotation.Transactional;

@Servicepublic class PersonService {

    // 전체 메서드가 하나의 트랜잭션으로 묶입니다.
    @Transactional
    public void registerAndUpdate(Person person) {
        // 1. 데이터 저장 (성공)
        personRepository.save(person);
        
        // 2. 만약 여기서 예외가 발생하면 1번 저장 단계까지 전부 취소(Rollback)됩니다.
        if (checkCondition()) {
            throw new RuntimeException("오류 발생!");
        }
    }
}

------------------------------
앞서 질문하신 @RepositoryRestResource나 JpaRepository 내부 메서드들도 스프링 데이터가 기본적으로 트랜잭션 처리를 보장하도록 설계되어 있습니다.
현재 작성 중이신 설정 클래스(@Configuration)에서 트랜잭션을 수동으로 세밀하게 제어(예: 멀티 데이터소스 설정 등)해야 하는 상황이신가요? 구체적인 상황을 알려주시면 알맞은 트랜잭션 매니저 설정법을 안내해 드리겠습니다.
