스프링 부트와 타임리프 환경에서 ~{form_errors :: formErrorsFragment}는 'form_errors.html 파일에 작성되어 있는 formErrorsFragment라는 이름의 템플릿 조각(Fragment)을 지정하는 문법'입니다.
이 문법은 단독으로 쓰이지 않고, 앞서 질문하신 th:replace나 th:insert와 함께 결합하여 공통 에러 메시지 창을 화면에 끼워 넣을 때 사용합니다.
------------------------------
## 🔍 문법 쪼개어 보기
타임리프에서 ~{...}는 조각 표현식(Fragment Expression)이라고 부르며, :: 기호를 기준으로 앞뒤가 나뉩니다.

* ~{ ... }: "지금부터 템플릿 조각을 가져오겠다"는 선언입니다.
* form_errors: 가져올 HTML 파일의 경로와 이름입니다. 타임리프의 기본 경로인 src/main/resources/templates/ 아래에 있는 form_errors.html 파일을 가리킵니다.
* ::: 파일과 조각 이름을 구분하는 구분자입니다.
* formErrorsFragment: form_errors.html 파일 내부에서 th:fragment="formErrorsFragment"로 지정된 특정 태그 영역을 의미합니다.

------------------------------
## 💻 실제 활용 예시 (Spring Validation 에러 처리)
보통 회원가입이나 글쓰기 화면에서 사용자가 값을 잘못 입력했을 때(예: 비밀번호 미입력), 화면 상단에 빨간색 에러 박스를 공통으로 띄워주기 위해 자주 사용하는 패턴입니다.
## 1. 공통 에러 조각 파일 생성 (templates/form_errors.html)
스프링 검증(BindingResult) 결과 에러가 있다면 화면에 에러 리스트를 뿌려주는 공통 컴포넌트입니다.

<!DOCTYPE html>
<html xmlns:th="http://thymeleaf.org">
<!-- 이 div 영역의 이름을 formErrorsFragment로 정의합니다 -->
<div th:fragment="formErrorsFragment" 
     th:if="${#fields.hasErrors('${boardForm}')}" 
     class="alert alert-danger" role="alert">
    <ul>
        <!-- 발생한 모든 검증 에러를 반복문(th:each)으로 출력 -->
        <li th:each="err : ${#fields.errors('${boardForm}')}" th:text="${err}"></li>
    </ul>
</div>

</html>

## 2. 실제 등록 화면에서 불러오기 (templates/board_form.html)
th:replace와 결합하여 화면 상단에 에러 창을 불러옵니다.

<form th:action="@{/board/create}" th:object="${boardForm}" method="post">
    
    <!-- form_errors.html에서 에러 조각을 가져와 이 자리에 치환합니다 -->
    <div th:replace="~{form_errors :: formErrorsFragment}"></div>

    <div>
        <label for="title">제목</label>
        <input type="text" th:field="*{title}">
    </div>
    <button type="submit">저장하기</button>
</form>

------------------------------
## 💡 한 줄 요약
"form_errors.html 파일 안에 있는 formErrorsFragment(에러 출력용 태그 조각)를 이 자리에 불러와서 끼워 넣어라"라는 의미로 이해하시면 됩니다. 대개 스프링 부트에서 BindingResult를 활용한 데이터 검증 공통 레이아웃을 만들 때 핵심적으로 사용됩니다.
