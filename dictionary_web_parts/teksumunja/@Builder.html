@Builder

        자바 스프링에서 @Builder는 롬복(Lombok) 라이브러리가 제공하는 기능으로, 
        복잡한 객체를 쉽고 명확하게 만들 수 있게 돕는 빌더 패턴 코드를 자동으로 작성해 주는 도구입니다. 
        생성자 인자가 많을 때 어떤 값이 어떤 변수인지 헷갈리는 문제를 해결해 줍니다.
        주요 특징 및 장점가독성 향상: 이름과 값을 직접 지정하므로 어떤 변수에 어떤 값이 들어가는지 쉽게 알 수 있습니다.
        순서 무관: 생성자 호출과 달리 입력하는 순서가 상관없습니다.
        유연한 생성: 필요한 값만 골라서 객체를 만들 수 있습니다.
        안정성: 값을 바꿀 수 없는 안전한(불변) 객체를 만들기 좋습니다.
