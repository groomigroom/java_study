@Id spring-boot-starter-data-jpa 라는 start dependency에 있음. 자바 스프링(JPA/Hibernate)에서 @Id 어노테이션은 데이터베이스 테이블의 기본 키(Primary Key)에 매핑되는 엔티티 클래스의 필드를 지정할 때 사용합니다. 핵심 의미와 역할 식별자 지정: 자바 객체를 구별하는 고유 번호(식별자) 역할을 합니다. 데이터베이스 연동: 데이터베이스 테이블의 PK 컬럼과 자바 필드를 연결합니다. CRUD 기준: JPA가 데이터를 저장, 조회, 수정, 삭제(findById 등)할 때 어떤 행(row)을 대상으로 할지 판단하는 기준이 됩니다. 주요 특징보통 값 생성 전략을 정해주는 @GeneratedValue와 함께 쓰입니다.@GeneratedValue가 없으면 개발자가 직접 고유 값을 할당해야 합니다.
