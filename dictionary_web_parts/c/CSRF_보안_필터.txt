CSRF 보안 필터는 인증된 사용자의 권한을 도용해 원하지 않는 요청을 
서버에 보내는 크로스 사이트 요청 위조(CSRF) 공격을 막아주는 소프트웨어 장치입니다. 
주로 웹 요청 마다 무작위로 생성된 고유 토큰을 검사하여 가짜 요청을 차단합니다.
동작 방식
토큰 생성: 서버는 사용자의 세션마다 안전하고 예측할 수 없는 랜덤 CSRF 토큰을 만듭니다.
값 전달: 웹 페이지 폼이나 요청 헤더에 이 토큰 값을 포함해 클라이언트로 보냅니다.
요청 검증: 사용자가 데이터를 바꾸는 요청(POST, PUT, DELETE 등)을 보낼 때 필터가 서버의 토큰과 일치하는지 확인합니다.
공격 차단: 공격자는 이 비밀 토큰 값을 알 수 없으므로 위조된 요청은 필터에서 거부됩니다.
주요 특징
적용 대상: 주로 세션과 쿠키로 로그인 상태를 유지하는 웹사이트에서 쓰입니다
제외 대상: 데이터를 조회만 하는 GET 요청이나, 
토큰 인증을 쓰는 무상태(Stateless) REST API 환경에서는 보통 사용하지 않습니다.
