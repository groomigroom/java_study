.csrf()

.csrf (Cross-Site Request Forgery)개념: 사용자가 의도하지 않게 공격자가 지정한 행동(예: 비밀번호 변경, 결제 요청 등)을 
신뢰하는 웹사이트에 요청하게 만드는 '사이트 간 요청 위조' 공격을 의미합니다.
역할: 스프링 시큐리티는 이 공격을 막기 위해 기본적으로 CSRF 토큰 검증 메커니즘을 켭니다. 
하지만 서버가 세션을 쓰지 않고 상태를 유지하지 않는(Stateless) JWT 
기반의 REST API를 제공할 때는 이 보호 기능을 보통 비활성화(disable)합니다.


Spring Security 라이브러리에 내장되어 있습니다. 

Gradle (build.gradle)groovyimplementation 'org.springframework.boot:spring-boot-starter-security'
