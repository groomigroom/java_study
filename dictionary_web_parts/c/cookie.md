# 쿠키 데이터 구성

## name=value;
* name => 쿠키 이름
* value => 쿠키 값

## Expires=[Date];
* 쿠키의 유효 시간

## Domain=[Domain];
* 쿠키를 필요로 하는 웹 서버 도메인

## Path=[Path];
* 쿠키를 필요로 하는 웹 페이지 경로명

## [Secure];
* 암호화한 경우에만 쿠키 전송 가능

## [HttpOnly];
* HTTP 통신 외에 다른 통신으로 쿠키 전송 불허

## [SameSite=None|Strict|None]
* 크로스 사이트로 전송하는 요청의 경우 쿠키 전송에 제한

## set-cookie: 1P_JAR=2021-11-27-06; expires=Mon, 27-Dec-2021 06:21:38 GMT; path=/; domain=.google.com; Secure; SameSite=none

* 위와 같은 쿠키 확인하는 법?
```
구글 크롬 브라우저에서 구글(.google.com)에 접속했을 때 해당 쿠키를 확인하는 방법은 다음과 같습니다. 개발자 도구(Developer Tools)를 이용하면 가장 정확하게 확인할 수 있습니다.

🛠️ 크롬 개발자 도구로 확인하는 방법

1. 구글 홈페이지 접속: 브라우저 주소창에 https://google.com을 입력하여 접속합니다.
2. 개발자 도구 열기:
	• 키보드에서 F12를 누르거나, Ctrl + Shift + I (Mac은 Cmd + Option + I)를 누릅니다.
3. Application 탭 이동:
	• 개발자 도구 상단 메뉴에서 Application(애플리케이션) 탭을 클릭합니다.
	• 만약 보이지 않는다면 우측 끝의 >> 모양 아이콘을 누르면 숨겨진 메뉴에 있습니다.
4. 쿠키 목록 확인:
	• 왼쪽 사이드바 메뉴에서 Storage > Cookies를 확장(▶ 클릭)합니다.
	• 하위에 있는 https://google.com을 클릭합니다.
5. 쿠키 값 찾기:
	• 오른쪽에 나타나는 쿠키 목록에서 Name이 1P_JAR인 항목을 찾습니다.
	• 표의 각 열(Column)에서 질문하신 속성들을 매칭하여 볼 수 있습니다.
		• Value: 2021-11-27-06 (쿠키의 실제 값)
		• Domain: .google.com
		• Path: /
		• Expires / Max-Age: 2021-12-27T06:21:38... (만료일)
		• Secure: 체크마크(v) 표시됨
		• SameSite: None

🔒 주소창 옆 '자물쇠' 아이콘으로 확인하는 방법 (간이 방법)

1. 구글 홈페이지 주소창 왼쪽에 있는 조절기(설정) 아이콘 또는 자물쇠 모양 아이콘을 클릭합니다.
2. 쿠키 및 사이트 데이터 > 기기에 저장된 쿠키 보기를 클릭합니다.
3. google.com 폴더를 열고 쿠키 폴더 내에서 1P_JAR를 찾아 클릭하면 세부 정보가 표시됩니다.
혹시 쿠키를 단순히 보는 것 외에 삭제, 수정하거나 자바스크립트 코드(콘솔)로 추출하는 방법이 필요하신가요? 원하시는 추가 작업을 말씀해 주시면 안내해 드리겠습니다.
```
