localhost:6379

윈도우에서 `redis-server.exe`를 실행했을 때 창이 잠깐 떴다가 바로 사라지는 현상은 대부분 Redis 서버 실행 중 오류가 발생하거나, 실행 환경 및 설정 파일에 문제가 있기 때문이야.

특히 Windows에서 Redis를 실행할 때는 단순히 `redis-server.exe`를 더블클릭하는 것보다 CMD(명령 프롬프트)에서 실행하는 것을 추천해.

## 1. 가장 흔한 원인 5가지

| 원인          | 설명                            |
| ----------- | ----------------------------- |
| 설정 파일 문제    | `redis.conf` 설정 오류 또는 파일 누락   |
| 포트 충돌       | 기본 포트인 6379번을 다른 프로그램이 사용 중   |
| 실행 경로 문제    | Redis 실행 파일과 설정 파일의 경로가 맞지 않음 |
| 권한 문제       | 실행 권한 또는 폴더 접근 권한 문제          |
| Redis 버전 문제 | Windows와 호환되지 않는 Redis 빌드 사용  |

## 2. CMD에서 실행해서 오류 확인하기

가장 먼저 아래 방법으로 실행해 보자.

1. Redis가 설치된 폴더로 이동해.
2. 폴더 주소창에 `cmd` 입력 후 Enter.
3. 명령 프롬프트에서 다음 명령어 입력.

```
redis-server.exe
```

이렇게 실행하면 창이 바로 닫히지 않고 오류 메시지를 확인할 수 있어.

정상적으로 실행되면 다음과 비슷한 메시지가 나와.

```
Ready to accept connections
```

이 메시지가 나오면 Redis 서버가 정상적으로 실행된 거야.

## 3. 포트 6379번 충돌 확인하기

CMD에서 다음 명령어를 입력해 봐.

```
netstat -ano | findstr :6379
```

결과가 나온다면 이미 6379번 포트를 사용하고 있는 프로그램이 있을 수 있어.

## 4. 내가 원인을 정확히 찾아줄게!

우선 아래 세 가지를 확인하고 싶어.

1. Redis 설치 방식: Redis 압축 파일을 다운로드해서 설치했어? 아니면 다른 프로그램을 통해 설치했어?
2. 실행 방식: `redis-server.exe`를 더블클릭했을 때 바로 꺼지는 거야?
3. 실행 환경: Windows에서 Spring Boot 프로젝트와 연동하려고 Redis를 설치한 거야?

가능하면 Redis 설치 폴더 화면이나 CMD에서 `redis-server.exe`를 실행한 결과를 캡처해서 보내줘.

그러면 오류 메시지를 보고 원인을 파악해서 Redis 서버가 정상적으로 실행될 때까지 한 단계씩 같이 해결해 줄게.
