스프링 부트(Spring Boot)에서 org.springframework.data.redis.connection.RedisConnectionFactory는 Spring Data Redis가 
Redis 서버와 연결을 맺고 커넥션(Connection)을 생성·관리하기 위해 제공하는 핵심 인터페이스입니다. 

주요 의미 및 역할

• Redis 연결 관리:
	• 호스트(Host)와 포트(Port), 비밀번호, 타임아웃 등의 접속 정보를 바탕으로 실제 Redis 서버와의 네트워크 
연결(RedisConnection)을 생성하고 관리합니다.
• 클라이언트 라이브러리 추상화:
	• Java에서 Redis를 다룰 때 주로 사용하는 클라이언트 라이브러리(Lettuce 또는 Jedis 등)의 
구체적인 구현체 차이를 감싸는 추상화 계층입니다.
	• 덕분에 코드가 특정 클라이언트 라이브러리에 종속되지 않고 RedisConnectionFactory 인터페이스를 
통해 일관되게 연결을 제어할 수 있습니다.
• 스프링 부트 자동 설정(Auto-Configuration):
	• 스프링 부트는 spring-boot-starter-data-redis 의존성이 있을 때, 설정 파일(application.yml 
또는 application.properties)의 spring.data.redis.* 속성을 읽어 기본 RedisConnectionFactory 빈(Bean)을 자동으로 생성해 줍니다 
(주로 비동기 기반의 고성능 클라이언트인 LettuceConnectionFactory가 기본으로 등록됨). 
• RedisTemplate이나 @Cacheable의 기반:
	• 우리가 자주 사용하는 RedisTemplate이나 Redis 기반 캐시 매니저를 설정할 때, 반드시 이 RedisConnectionFactory를 
주입받아 연결 팩토리로 사용합니다. 

활용 예시 (RedisConfig 설정)

실무에서 직렬화 방식이나 커넥션 풀(Pool) 등을 커스터마이징할 때 직접 빈으로 등록해 사용합니다: 

java
@Configuration
public class RedisConfig {

    @Bean
    public RedisConnectionFactory redisConnectionFactory() {
        // 예: Lettuce를 이용한 연결 팩토리 생성 (host, port 지정)
        return new LettuceConnectionFactory("localhost", 6379);
    }
}
코드를 사용할 때는 주의가 필요합니다.
만약 Lettuce와 Jedis의 차이점이나, 커넥션 풀(Pool) 설정 방법에 대해 더 알고 싶으시다면 편하게 말씀해 주세요.
