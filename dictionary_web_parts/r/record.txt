자바의 레코드(record)는 데이터를 단순하게 담기 위해 사용하는 불변(immutable) 데이터 전용 클래스입니다. 자바 14에서 처음 소개되었고 자바 16부터 정식 기능이 되었습니다. [1, 2, 3] 
## 주요 특징

* 자동 생성: 생성자, 게터(getter), equals(), hashCode(), toString() 메서드를 자동으로 만듭니다.
* 불변성: 모든 필드는 기본적으로 private final이므로 생성 후 값을 바꿀 수 없습니다.
* 간결한 코드: 반복해서 작성해야 하는 지루한 코드(boilerplate code)를 크게 줄여줍니다. [2, 4] 

## 사용 방법

// 선언부 하나로 클래스가 완성됩니다public record Person(String name, int age) {}

private final과 record는 같지 않으며, 포함 관계에 가깝습니다. private final은 변수를 바꿀 수 없게 만드는 수식어이고, record는 이 private final 필드를 기본으로 사용하는 클래스 종류입니다.
## 핵심 차이점

| 구분 | private final | record |
|---|---|---|
| 정체 | 변수의 접근과 수정을 제한하는 키워드 | 불변 데이터를 다루는 특별한 클래스 타입 |
| 대상 | 일반 클래스의 필드, 지역 변수, 매개변수 등 | 클래스 선언 전체 |
| 자동화 | 아무것도 자동으로 생성하지 않음 | 생성자, 게터, toString(), equals() 등 자동 생성 |

------------------------------
## 코드 비교로 이해하기## 1. 일반 클래스에서 private final을 쓸 때
일반 클래스에서 불변 데이터를 만들려면 필드에 private final을 붙이고, 필요한 메서드들을 직접 다 작성해야 합니다.

public class User {
    // 필드를 바꾸지 못하게 고정 (private final)
    private final String name;
    private final int age;

    // 생성자, 게터, toString 등을 모두 직접 구현해야 함
    public User(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public String getName() { return name; }
    public int getAge() { return age; }
}

## 2. record를 쓸 때
record를 선언하면, 자바 컴파일러가 내부적으로 모든 필드를 private final로 알아서 생성하고 관련된 메서드까지 전부 만들어 줍니다.

// 아래 한 줄이 위의 일반 클래스 코드와 완벽히 같은 역할을 합니다public record User(String name, int age) {}

요약하자면, record를 만들면 그 안의 필드들은 자동으로 private final이 된다고 이해하시면 됩니다.
