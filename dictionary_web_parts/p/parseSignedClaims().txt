자바 스프링 부트 환경에서 .parseSignedClaims(token)는 디지털 서명이 된 JWT(JSON Web Token)의 유효성을 검증하고, 그 안에 담긴 데이터(Claims)를 추출하는 메서드입니다.
이 메서드 역시 이전 질문과 동일하게 오픈소스 라이브러리인 JJWT(Java JWT)에 속해 있습니다.
## 🔑 소속 의존성 (Starter Dependency)
스프링 부트 내장 스타터가 아니므로, JJWT 라이브러리를 프로젝트 의존성에 추가해야 합니다. (build.gradle 기준)

* implementation 'io.jsonwebtoken:jjwt-api:0.12.3'
* runtimeOnly 'io.jsonwebtoken:jjwt-impl:0.12.3'
* runtimeOnly 'io.jsonwebtoken:jjwt-jackson:0.12.3'

## 📝 메서드와 매개변수의 의미
이 코드는 토큰의 위변조 여부, 만료 시간 등을 검사하고 데이터를 읽어오는 핵심 관문입니다.

* .parseSignedClaims(): 암호화 서명(Signature)이 포함된 JWT를 해석하겠다는 뜻입니다. 만약 토큰이 변조되었거나, 만료되었거나, 형식에 맞지 않으면 예외(Exception)를 발생시킵니다.
* token (매개변수): 클라이언트가 HTTP 헤더(Authorization) 등을 통해 서버로 보낸 문자열 형태(String)의 JWT 토큰입니다.
* 반환값: 검증이 성공하면 토큰 내부의 Payload(유저 ID, 권한 등)에 접근할 수 있는 Jws<Claims> 객체를 반환합니다. [1] 

## 💻 흐름 이해를 위한 예시 코드

try {
    Jws<Claims> claims = Jwts.parser()
        .verifyWith(secretKey) // 1. 검증할 키 설정
        .build()
        .parseSignedClaims(token); // 2. 토큰을 매개변수로 받아 검증 및 파싱

    // 3. 검증 성공 시 내부 데이터 추출
    String username = claims.getPayload().getSubject(); 
} catch (JwtException e) {
    // 토큰이 유효하지 않거나 만료된 경우 예외 처리
    System.out.println("유효하지 않은 토큰입니다.");
}
