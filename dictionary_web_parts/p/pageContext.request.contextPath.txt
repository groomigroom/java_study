${pageContext.request.contextPath}는 현재 웹 애플리케이션의 기본 경로(Root Path, 즉 Context Path)를 동적으로 가져오는 JSP EL(Expression Language) 표현식입니다.
구체적인 의미와 값이 설정되는 위치는 다음과 같습니다.

1. 의미와 역할

• 동적 경로 생성: 서버 환경이나 배포 설정에 따라 프로젝트의 시작 URL이 바뀔 수 있습니다. 이때 경로를 하드코딩하지 않고 현재 프로젝트의 최상위 경로를 자동으로 붙여주기 위해 사용합니다.
• 작동 예시:
	• 프로젝트의 Context Path가 /egov로 설정되어 있다면:
action="/egov/uat/uia/actionLogin.do" 로 변환됩니다.
	• Context Path가 루트(/)로 설정되어 있다면 (빈 문자열 반환):
action="/uat/uia/actionLogin.do" 로 변환됩니다.

2. 내부 동작 원리 (EL 표현식)

이 코드는 JSP 기본 내장 객체인 pageContext를 통해 Java의 HttpServletRequest 객체에 접근하는 축약 문법입니다.
• pageContext.getRequest().getContextPath() 메서드를 호출한 결과와 같습니다.

3. 이 값은 어디서 나오나? (설정 위치)

전자정부표준프레임워크(eGovFrame) 5.0(Spring Boot 기반 또는 일반 Web 프로젝트) 환경에서 이 값은 WAS(Tomcat 등) 또는 프로젝트 설정 파일에서 결정됩니다.

환경 / 도구	설정 위치 및 확인 방법
Spring Boot (eGovFrame 5.0 기본)	application.properties 또는 application.yml 파일 내의 server.servlet.context-path 속성 값 (미설정 시 기본값은 빈 문자열 "")
이클립스 (eGovFrame Dev)	프로젝트 우클릭 → Properties → Web Project Settings → Context root 항목에 입력된 값
Tomcat 서버 직접 설정	Tomcat의 conf/server.xml 파일 내 <Context path="/프로젝트명" ... />의 path 속성 값
WAR 배포 시	별도 설정이 없다면 Tomcat의 webapps 폴더에 배포되는 WAR 파일의 이름(예: myapp.war → /myapp)이 자동으로 Context Path가 됩니다.


💡 참고: <form:form> 태그 사용 시 팁

현재 코드처럼 스프링 폼 태그(<form:form>)를 사용할 때는 action 속성에 컨텍스트 경로를 직접 적지 않고 <form:form action="/uat/uia/actionLogin.do" ...>처럼 작성해도 스프링이 내부적으로 contextPath를 자동으로 붙여줍니다. 다만, 기존 전자정부프레임워크 공통컴포넌트 템플릿에서는 명시적으로 ${pageContext.request.contextPath}를 붙여 작성하는 관례가 많이 남아 있습니다.
혹시 현재 작업 중이신 환경이 Spring Boot 기반인지, 아니면 외장 Tomcat에 WAR로 배포하는 방식인지 알려주시면 정확한 설정 파일 위치와 경로 변경 방법을 안내해 드릴 수 있습니다.
