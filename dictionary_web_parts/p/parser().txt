자바 스프링 부트 환경에서 parser()는 클라이언트가 전송한 JWT(JSON Web Token) 문자열을 해독(Parsing)하고 검증하기 위해 파서 빌더(JwtParserBuilder) 객체를 생성하는 메서드입니다. [1, 2, 3] 
이 메서드 역시 이전 답변에서 안내해 드린 JJWT(Java JWT) 라이브러리에 속해 있습니다. [4, 5] 
------------------------------
## 1. parser()의 의미와 역할
클라이언트가 요청 헤더(Authorization: Bearer <토큰>)에 담아 보낸 JWT가 유효한지 검사할 때 시작점이 되는 메서드입니다. [3, 5, 6] 

* 
* 서명 검증: 토큰이 중간에 위변조되지 않았는지 서버의 비밀키(Secret Key)로 확인합니다.
* 만료 여부 확인: 토큰의 유효 기간(exp)이 지나지 않았는지 체크합니다.
* 클레임(Claims) 추출: 토큰 내부에 저장된 사용자의 아이디, 권한 등의 데이터를 꺼냅니다. [3, 5, 7, 8] 
* 

------------------------------
## 2. 소속된 스타터 의존성 (Starter Dependency)
앞서 설명해 드린 것과 동일하게 스프링 공식 스타터가 아닌 JJWT 외부 라이브러리의 io.jsonwebtoken.Jwts 클래스에 포함되어 있습니다. 프로젝트의 빌드 파일(build.gradle 또는 pom.xml)에 아래 의존성이 추가되어 있어야 사용할 수 있습니다. [1, 4, 5, 9] 

* 
* Gradle: implementation 'io.jsonwebtoken:jjwt-api:0.12.5'
* Maven: <artifactId>jjwt-api</artifactId> [10] 
* 

------------------------------
## ⚠️ 중요: JJWT 버전에 따른 parser() 사용법 변화
JJWT 라이브러리는 버전에 따라 parser()의 동작 방식과 추천 코드가 크게 달라졌으므로 주의해야 합니다. [2, 11] 
## 1) 최신 버전 (JJWT 0.12.x 이상 단위) 🌟
최신 버전에서 Jwts.parser()는 바로 파서 객체를 주는 것이 아니라, 설정을 조율하는 빌더(JwtParserBuilder)를 반환합니다. 따라서 반드시 마지막에 .build()를 호출해야 파싱이 가능합니다. [1, 2] 

// 최신 표준 코드 방식
Claims claims = Jwts.parser()
    .verifyWith(secretKey)     // 1. 검증할 비밀키 지정 (기존 setSigningKey 대체)
    .build()                   // 2. parser 객체 생성 (필수!)
    .parseSignedClaims(token)  // 3. 토큰 해석 및 서명 검증
    .getPayload();             // 4. 내부 데이터(Claims) 추출 (기존 getBody 대체)

## 2) 구버전 (JJWT 0.11.x)
이 버전에서는 parser() 대신 parserBuilder()라는 메서드를 임시로 사용했었습니다. (최신 0.12.x 버전에서는 parserBuilder()가 삭제되고 다시 parser()를 쓰도록 롤백되었습니다.) [2, 5, 12] 

// 0.11.x 방식 (현재는 사용을 권장하지 않음)
Jwts.parserBuilder().setSigningKey(key).build().parseClaimsJws(token).getBody();

## 3) 아주 오래된 구버전 (JJWT 0.9.x 이하)
몇 년 전 블로그 글에서 자주 보이는 방식입니다. 이때는 .build() 과정 없이 parser()가 곧바로 파서 객체를 반환했습니다. [2, 11, 12] 

// 0.9.x 방식 (보안 및 멀티스레드 이슈로 인해 완전히 구식이 된 코드)
Jwts.parser().setSigningKey(secretKey).parseClaimsJws(token).getBody();

------------------------------
스프링 부트 프로젝트를 빌드할 때 parser() 부분에서 빨간 줄(에러)이 뜨거나 경고가 발생하나요? 사용 중이신 JJWT 라이브러리의 정확한 버전을 알려주시면 환경에 맞는 정확한 토큰 검증 코드를 수정해 드릴 수 있습니다. [7]
