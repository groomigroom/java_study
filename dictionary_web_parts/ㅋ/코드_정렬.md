인텔리제이(IntelliJ)에서 코드를 저장할 때 자동으로 들여쓰기와 정렬이 되도록 설정하는 방법과 수동 단축키는 다음과 같습니다. [1, 2] 
## 1. 저장할 때 자동 정렬 설정하기
파일을 저장(Ctrl + S 또는 Cmd + S)할 때마다 코드가 자동으로 정렬되도록 설정할 수 있습니다: [1, 3] 

* 설정 경로 열기:
* Windows/Linux: File > Settings
   * macOS: IntelliJ IDEA > Preferences (또는 Settings, 단축키 Ctrl + Alt + S / Cmd + ,) [2] 
* 자동 정렬 활성화:
* 왼쪽 메뉴에서 Tools > Actions on Save로 이동합니다.
   * Reformat code 항목에 체크합니다.
   * (선택 사항) 사용하지 않는 import 문을 정리하고 싶다면 Optimize imports에도 체크합니다. [1, 2] 
* 적용: 하단의 Apply 또는 OK를 눌러 설정을 저장합니다.

------------------------------
## 2. 수동 코드 정렬 (단축키 및 메뉴)
저장 설정과 별개로, 필요할 때 언제든 즉시 정렬을 실행할 수 있습니다: [1] 

* 단축키:
* Windows / Linux: Ctrl + Alt + L
   * macOS: Cmd (⌘) + Option (⌥) + L
   * (일부 옵션 창을 띄우고 정렬하려면 Windows는 Ctrl + Alt + Shift + L, 맥은 Cmd + Option + Shift + L을 누릅니다.) [1, 4, 5, 6] 
* 메뉴 방식:
* 상단 메뉴바에서 Code > Reformat Code를 선택합니다.
   * 특정 코드 블록만 마우스로 드래그하여 선택한 뒤 단축키를 누르면 해당 부분만 정렬됩니다. [1, 7] 

------------------------------
## 3. 들여쓰기 간격(스페이스 탭 칸 수) 설정
들여쓰기 칸 수(기본 4칸 등)를 바꾸고 싶다면 다음 경로에서 수정할 수 있습니다: [4] 

* 경로: File > Settings (macOS는 Preferences) > Editor > Code Style
* 원하는 언어(예: Java, Kotlin, JavaScript 등)를 선택한 뒤 Tabs and Indents 탭에서 Tab size나 Indent 값을 원하는 숫자로 변경합니다. [4, 8] 

혹시 특정 프로그래밍 언어(예: Java, Python, React 등)나 팀 표준 컨벤션(Google 스타일 등)에 맞춘 상세 들여쓰기 규칙 설정이 필요하신가요?
