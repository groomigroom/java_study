자바 스프링에서 Getter와 Setter는 객체의 데이터를 안전하게 보호하고 유지보수성을 높이는 캡슐화(Encapsulation) 원칙을 지키기 위해 사용합니다. 필드를 직접 열어두지 않고 메서드를 거쳐 접근하게 함으로써 데이터 무결성을 유지합니다.캡슐화와 데이터 보호직접 접근 방지: 필드를 private으로 숨기고 메서드로만 접근하게 합니다.잘못된 값 차단: Setter 안에서 조건문을 써서 이상한 값이 들어오는 것을 막습니다.읽기 전용 구현: Setter를 만들지 않으면 값을 바꾸지 못하게 막을 수 있습니다.유지보수와 유연성내부 구조 변경 숨김: 필드 이름이나 자료형이 바뀌어도 Getter/Setter 이름이 같으면 외부 코드는 고칠 필요가 없습니다.동적 연산 추가: Getter 안에서 값을 가공하거나 추가 계산을 해서 돌려줄 수 있습니다.스프링 프레임워크와의 연동프레임워크 기술 호환: 스프링은 JSON 변환(Jackson), 데이터 바인딩, JPA/ORM 등에서 객체의 Getter와 Setter 이름을 기준으로 속성을 인식합니다.
