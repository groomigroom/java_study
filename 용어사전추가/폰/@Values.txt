@Value

자바 스프링 부트에서 @Value는 설정 파일(application.properties 또는 application.yml)에 정의된 값을 자바 코드의 필드에 자동으로 주입(의존성 주입)해 주는 역할을 합니다. [1] 
이 어노테이션은 별도의 추가 외부 라이브러리 설치 없이, 스프링 부트 프로젝트를 생성할 때 무조건 포함되는 spring-boot-starter 디펜던시에 기본적으로 포함되어 있습니다. [2, 3] 
------------------------------
## 1. @Value어노테이션의 핵심 역할

* 
* 환경 변수 분리: 소스 코드와 설정 값(포트 번호, API 비밀키, DB 접속 정보 등)을 분리하여 관리할 수 있게 합니다. [1] 
* 유연한 값 주입: 개발 환경(Dev), 테스트 환경(Test), 운영 환경(Prod)마다 각각 다른 값을 코드 변경 없이 주입할 수 있습니다.
* SpEL(스프링 표현 언어) 지원: 단순 값 주입뿐만 아니라 #{...} 구조를 사용해 연산이나 시스템 프로퍼티 값을 계산하여 가져올 수 있습니다. [4] 
* 

사용 예시 코드:

// application.yml 파일 내용// my.app.timeout: 5000

@Componentpublic class AppConfig {

    // 외부 설정 파일의 값을 필드에 자동으로 주입
    @Value("${my.app.timeout}")
    private int timeout;
    
    // 값이 없을 경우 기본값(:3000)을 설정하는 것도 가능
    @Value("${my.app.retry-count:3}")
    private int retryCount;
}

------------------------------
## 2. 포함되어 있는 Start Dependency (의존성)
@Value는 스프링 프레임워크의 코어 기능인 spring-beans 및 spring-context 모듈에 속해 있습니다.
스프링 부트 환경에서는 프로젝트를 만들 때 무조건 추가되는 최상위 핵심 스타터인 아래 디펜던시에 기본 탑재되어 제공됩니다. [2, 3] 

* 
* spring-boot-starter [2] 
* 

만약 웹 애플리케이션을 만들기 위해 spring-boot-starter-web을 추가했다면, 이 스타터가 내부에 spring-boot-starter를 자동으로 포함(의존)하고 있으므로 그대로 사용하시면 됩니다. 결론적으로 어떤 종류의 스프링 부트 프로젝트를 생성하더라도 별도 설정 없이 즉시 사용할 수 있습니다. [3, 5, 6] 
------------------------------
추가적으로 @Value 외에 여러 설정 값을 묶어서 안전하게 관리하는 @ConfigurationProperties 방식에 대해서도 궁금하시다면 언제든 질문해 주세요!
