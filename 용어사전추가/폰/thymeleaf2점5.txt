5.4 추가 및 전치 추가
Thymeleaf는 또한 평가 결과를 기존 속성 값에 접미사(suffix) 또는 접두사(prefix)로 추가하는 속성을 th:attrappend제공 합니다.th:attrprepend

예를 들어, 버튼에 추가할(설정하는 것이 아니라 추가하는) CSS 클래스의 이름을 컨텍스트 변수에 저장하고 싶을 수 있습니다. 왜냐하면 사용할 특정 CSS 클래스는 사용자가 이전에 수행한 작업에 따라 달라지기 때문입니다.

<input type="button" value="Do it!" class="btn" th:attrappend="class=${' ' + cssStyle}" />
cssStyle변수를 로 설정하여 이 템플릿을 처리하면 다음과 같은 "warning"결과가 나옵니다.

<input type="button" value="Do it!" class="btn warning" />
표준 다이얼렉트에는 CSS 클래스나 스타일 조각을 기존 속성을 덮어쓰지 않고 요소에 추가하는 데 사용되는 두 가지 특정 속성인 `append` 및 `append` 속성 이 있습니다 .th:classappendth:styleappend

<tr th:each="prod : ${prods}" class="row" th:classappend="${prodStat.odd}? 'odd'">

5.5 고정값 부울 속성
HTML에는 불리언 속성 이라는 개념이 있습니다 . 불리언 속성은 값이 없는 속성으로, 값이 존재하면 "참"을 의미합니다. XHTML에서는 이러한 속성이 오직 하나의 값, 즉 자기 자신만을 가집니다.

예를 들어, checked:

<input type="checkbox" name="option2" checked /> <!-- HTML -->
<input type="checkbox" name="option1" checked="checked" /> <!-- XHTML -->
표준 방언에는 조건을 평가하여 속성을 설정할 수 있는 속성이 포함되어 있습니다. 즉, 조건이 참으로 평가되면 해당 속성은 고정된 값으로 설정되고, 거짓으로 평가되면 속성은 설정되지 않습니다.

<input type="checkbox" name="active" th:checked="${user.active}" />
표준 방언에는 다음과 같은 고정값 부울 속성이 있습니다.

5.6 속성 값 설정(기본 속성 처리기)
Thymeleaf는 기본 속성 처리기를 제공하므로 표준 방언에서 특정 처리기가 정의되지 않은 속성이라도 모든 속성 의 값을 설정할 수 있습니다 .th:*

예를 들면 다음과 같습니다.

<span th:whatever="${user.name}">...</span>
결과는 다음과 같습니다:

<span whatever="John Apricot">...</span>
5.7 HTML5 친화적인 속성 및 요소 이름 지원
또한 완전히 다른 구문을 사용하여 HTML5 친화적인 방식으로 템플릿에 프로세서를 적용할 수도 있습니다.

<table>
    <tr data-th-each="user : ${users}">
        <td data-th-text="${user.login}">...</td>
        <td data-th-text="${user.name}">...</td>
    </tr>
</table>
이 data-{prefix}-{name}구문은 개발자가 네임스페이스 이름(예: `<code>`)을 사용하지 않고도 HTML5에서 사용자 지정 속성을 작성하는 표준 방식입니다 th:*. Thymeleaf는 이 구문을 모든 방언트(표준 방언뿐만 아니라)에서 자동으로 사용할 수 있도록 지원합니다.

또한 사용자 정의 태그를 지정하는 구문도 있습니다. {prefix}-{name}이는 W3C 사용자 정의 요소 사양 (더 큰 W3C 웹 구성 요소 사양 의 일부 )을 따릅니다. 예를 들어, 이 구문은 th:block요소(또는 ) 에 사용할 수 있으며 th-block, 이는 뒷부분에서 설명하겠습니다.

중요: 이 구문은 네임스페이스 th:*구문에 추가되는 기능이며, 기존 구문을 대체하는 것이 아닙니다. 향후 네임스페이스 구문을 더 이상 사용하지 않도록 할 계획은 전혀 없습니다.

6.2 반복 상태 유지
Thymeleaf를 사용할 때 th:each, Thymeleaf는 반복 작업의 상태를 추적하는 데 유용한 메커니즘인 ` status` 변수를 제공합니다 .

상태 변수는 속성 내에 정의되며 th:each다음과 같은 데이터를 포함합니다.

현재 반복 인덱스 (0부터 시작). 이것이 index속성입니다.
현재 반복 인덱스는 1부터 시작합니다. 이것이 count속성입니다.
반복 변수에 포함된 요소의 총 개수입니다. 이것이 size속성입니다.
각 반복마다 사용되는 iter 변수입니다 . 이것이 current속성입니다.
현재 반복이 짝수인지 홀수인지 여부. 이것은 even/odd부울 속성입니다.
현재 반복이 첫 번째 반복인지 여부입니다. 이는 first부울 속성입니다.
현재 반복이 마지막 반복인지 여부입니다. 이는 last부울 속성입니다.

6.3 지연 데이터 검색을 통한 최적화
때때로 우리는 데이터 모음(예: 데이터베이스)의 검색을 최적화하여 실제로 사용될 경우에만 해당 모음을 검색하도록 하고 싶을 수 있습니다.

사실 이는 어떤 데이터 에든 적용할 수 있는 내용이지만 , 메모리 내 컬렉션의 크기를 고려할 때, 반복 처리가 필요한 컬렉션을 검색하는 경우가 이 시나리오에서 가장 일반적인 경우입니다.

이를 지원하기 위해 Thymeleaf는 컨텍스트 변수를 지연 로드 하는 메커니즘을 제공합니다 . 인터페이스를 구현하는 컨텍스트 변수 ILazyContextVariable(대부분 LazyContextVariable기본 구현을 확장하는 방식)는 실행 시점에 해석됩니다. 예를 들면 다음과 같습니다.

context.setVariable(
     "users",
     new LazyContextVariable<List<User>>() {
         @Override
         protected List<User> loadValue() {
             return databaseRepository.findAllUsers();
         }
     });
이 변수는 지연 평가 방식 이라는 사실을 몰라도 다음과 같은 코드에서 사용할 수 있습니다 .

<ul>
  <li th:each="u : ${users}" th:text="${u.name}">user name</li>
</ul>
하지만 동시에, 다음과 같은 코드에서 값이 로 평가 loadValue()되면 해당 객체는 절대 초기화되지 않습니다(해당 메서드는 절대 호출되지 않습니다) .conditionfalse

<ul th:if="${condition}">
  <li th:each="u : ${users}" th:text="${u.name}">user name</li>

값이 문자이고 0이 아닌 경우
값이 문자열이고 "false", "off" 또는 "no"가 아닌 경우
값이 불리언, 숫자, 문자 또는 문자열이 아닌 경우.
(값이 null인 경우, th:if는 false로 평가됩니다.)
또한, th:if에는 역 속성인 가 있는데, 이전 예제에서 OGNL 표현식 내부에 th:unless를 사용하는 대신 이 속성을 사용할 수도 있었습니다 .not

<a href="comments.html"
   th:href="@{/comments(prodId=${prod.id})}" 
   th:unless="${#lists.isEmpty(prod.comments)}">view</a>
7.2 스위치 문
자바의 switch 문과 유사한 방식으로 조건을 걸어 콘텐츠를 표시하는 방법도 있습니다 . 바로 ` th:switch/` th:case속성 세트를 사용하는 것입니다.

<div th:switch="${user.role}">
  <p th:case="'admin'">User is an administrator</p>
  <p th:case="#{roles.manager}">User is a manager</p>
</div>
th:case참고로, 하나의 속성이 로 평가되는 즉시 동일한 스위치 컨텍스트에 있는 true다른 모든 속성도 로 평가됩니다 .th:casefalse

기본 옵션은 다음과 같이 지정됩니다 th:case="*".

<div th:switch="${user.role}">
  <p th:case="'admin'">User is an administrator</p>
  <p th:case="#{roles.manager}">User is a manager</p>
  <p th:case="*">User is some other thing</p>
</div>
8가지 템플릿 레이아웃
8.1 템플릿 조각 포함
조각 정의 및 참조
템플릿을 만들 때, 푸터, 헤더, 메뉴 등 다른 템플릿의 요소들을 포함시키고 싶을 때가 많습니다.

이를 위해 Thymeleaf는 포함할 부분, 즉 "조각"을 정의해야 하며, 이는 th:fragment속성을 사용하여 수행할 수 있습니다.

예를 들어 모든 식료품점 페이지에 표준 저작권 바닥글을 추가하고 싶다고 가정해 보겠습니다. 그래서 /WEB-INF/templates/footer.html다음과 같은 코드가 포함된 파일을 만듭니다.

<!DOCTYPE html>

<html xmlns:th="http://www.thymeleaf.org">

  <body>
  
    <div th:fragment="copy">
      &copy; 2011 The Good Thymes Virtual Grocery
    </div>
  
  </body>
  
</html>
위 코드는 `<script>`라는 이름의 조각을 정의하며, `<script>` 또는 `<script>` 속성 copy중 하나를 사용하여 홈페이지에 쉽게 포함할 수 있습니다 .th:insertth:replace

<body>

  ...

  <div th:insert="~{footer :: copy}"></div>
  
</body>
참고로, 이는 단편 표현식 ( ) 을 th:insert예상하는데 , 이는 단편을 생성하는 표현식 입니다 .~{...}

조각 명세 구문
프래그먼트 표현식 의 구문은 매우 간단합니다. 세 가지 형식이 있습니다.

"~{templatename::selector}"지정된 마크업 선택기를 이름이 지정된 템플릿에 적용하여 생성된 조각을 포함합니다 templatename. 여기서 는 selector단순한 조각 이름일 수 있으므로 위와 ~{templatename::fragmentname}같이 간단하게 지정할 수도 있습니다 ~{footer :: copy}.

마크업 선택자 구문은 기본 AttoParser 구문 분석 라이브러리에 의해 정의되며 XPath 표현식이나 CSS 선택자와 유사합니다. 자세한 내용은 부록 C를 참조하십시오.

"~{templatename}"이라는 이름의 전체 템플릿이 포함되어 있습니다 templatename.

th:insert참고로, `/` 태그 에 사용하는 템플릿 이름은 th:replace현재 템플릿 엔진에서 사용 중인 템플릿 확인자가 해석할 수 있어야 합니다.

~{::selector}"또는 "~{this::selector}"동일한 템플릿에서 일치하는 조각을 삽입합니다 selector. 표현식이 나타나는 템플릿에서 해당 조각을 찾지 못하면 템플릿 호출(삽입) 스택을 원래 처리된 템플릿(루트 ) 방향 으로 탐색하여 selector어떤 수준에서든 일치하는 항목을 찾습니다.

위 예시의 ` and`는 모두 다음 templatename과 같이 완전한 기능을 갖춘 표현식(조건문 포함!)이 될 수 있습니다.selector

<div th:insert="~{ footer :: (${user.isAdmin}? #{footer.admin} : #{footer.normaluser}) }"></div>
프래그먼트는 어떤 th:*속성이든 포함할 수 있습니다. 이러한 속성은 프래그먼트가 대상 템플릿(` th:insert/` th:replace속성이 있는 템플릿)에 포함되면 평가되며, 대상 템플릿에 정의된 컨텍스트 변수를 참조할 수 있습니다.

이러한 프래그먼트 접근 방식의 큰 장점은 완전하고 유효한 마크업 구조를 갖춘, 브라우저에서 완벽하게 표시 가능한 페이지에 프래그먼트를 작성할 수 있으면서도 Thymeleaf가 다른 템플릿에 해당 프래그먼트를 포함할 수 있도록 하는 기능을 유지할 수 있다는 것입니다.

참고로, 프래그먼트 표현식은 보안상의 이유로 더 엄격한 표현식 평가 제한을 받습니다. 부록 D: 표현식 제한 사항을 참조하십시오 .

참조 조각 없이th:fragment
마크업 선택자의 강력한 기능 덕분에 th:fragment속성을 전혀 사용하지 않는 코드 조각도 포함할 수 있습니다. 심지어 Thymeleaf에 대해 전혀 알지 못하는 다른 애플리케이션에서 가져온 마크업 코드도 포함할 수 있습니다.

...
<div id="copy-section">
  &copy; 2011 The Good Thymes Virtual Grocery
</div>
...
id위 코드 조각은 CSS 선택자와 유사한 방식으로 속성 을 참조하여 사용할 수 있습니다 .

<body>

  ...

  <div th:insert="~{footer :: #copy-section}"></div>
  
</body>
th:insert와 의 차이점th:replace
th:insert그렇다면 와 의 차이점은 무엇일까요 th:replace?

th:insert지정된 조각을 호스트 태그의 본문으로 삽입합니다.

th:replace실제로 호스트 태그를 지정된 조각으로 바꿉니다 .

다음과 같은 HTML 조각입니다.

<footer th:fragment="copy">
  &copy; 2011 The Good Thymes Virtual Grocery
</footer>
…호스트 <div>태그에 다음과 같이 두 번 포함됩니다.

<body>

  ...

  <div th:insert="~{footer :: copy}"></div>

  <div th:replace="~{footer :: copy}"></div>
  
</body>
…는 다음과 같은 결과를 초래할 것입니다:

<body>

  ...

  <div>
    <footer>
      &copy; 2011 The Good Thymes Virtual Grocery
    </footer>
  </div>

  <footer>
    &copy; 2011 The Good Thymes Virtual Grocery
  </footer>
  
</body>
8.2 매개변수화 가능한 프래그먼트 시그니처
템플릿 조각에 보다 함수적인 메커니즘을 구현하기 위해 , 정의된 조각은 th:fragment일련의 매개변수를 지정할 수 있습니다.

<div th:fragment="frag (onevar,twovar)">
    <p th:text="${onevar} + ' - ' + ${twovar}">...</p>
</div>
이를 위해서는 다음 두 구문 중 하나를 사용하여 해당 조각 을 호출해야 합니다 th:insert.th:replace

<div th:replace="~{ ::frag (${value1},${value2}) }">...</div>
<div th:replace="~{ ::frag (onevar=${value1},twovar=${value2}) }">...</div>
마지막 옵션에서는 순서가 중요하지 않다는 점에 유의하세요.

<div th:replace="~{ ::frag (twovar=${value2},onevar=${value1}) }">...</div>
프래그먼트 인자 없이 프래그먼트 로컬 변수 사용
조각이 다음과 같이 인자 없이 정의되더라도:

<div th:fragment="frag">
    ...
</div>
위에서 언급한 두 번째 구문을 사용하여 해당 함수들을 호출할 수 있습니다(그리고 두 번째 구문만 사용 가능합니다).

<div th:replace="~{::frag (onevar=${value1},twovar=${value2})}">
th:replace이는 와 의 조합과 같습니다 th:with.

<div th:replace="~{::frag}" th:with="onevar=${value1},twovar=${value2}">
참고 로, 프래그먼트에 대한 지역 변수 지정은 인자 시그니처가 있든 없든 관계없이 실행 전에 컨텍스트를 비우지 않습니다. 프래그먼트는 현재와 마찬가지로 호출 템플릿에서 사용되는 모든 컨텍스트 변수에 계속 접근할 수 있습니다.

th:템플릿 내 어설션을 위한 assert
이 th:assert속성은 평가해야 하는 표현식 목록을 쉼표로 구분하여 지정할 수 있으며, 모든 평가에서 참을 반환해야 하고 그렇지 않을 경우 예외를 발생시켜야 합니다.

<div th:assert="${onevar},(${twovar} != 43)">...</div>
이는 프래그먼트 서명에서 매개변수를 검증하는 데 유용합니다.

<header th:fragment="contentheader(title)" th:assert="${!#strings.isEmpty(title)}">...</header>

예를 들어, 사용자가 관리자인 경우 에만common :: adminhead 조각을 삽입하고, 관리자가 아닌 경우에는 아무것도 삽입하지 않도록(빈 조각) 다음과 같이 할 수 있습니다 .

...
<div th:insert="${user.isAdmin()} ? ~{common :: adminhead} : ~{}">...</div>
...

...
<div th:insert="${user.isAdmin()} ? ~{common :: adminhead} : _">
    Welcome [[${user.name}]], click <a th:href="@{/support}">here</a> for help-desk support.
</div>
...
또한, 템플릿 리졸버가 플래그 를 통해 템플릿 리소스의 존재 여부를 확인 하도록 구성한 경우 , 기본checkExistence 작업 에서 해당 프래그먼트 자체의 존재 여부를 조건으로 사용할 수 있습니다 .

...
<!-- The body of the <div> will be used if the "common :: salutation" fragment  -->
<!-- does not exist (or is empty).                                              -->
<div th:insert="~{common :: salutation} ?: _">
    Welcome [[${user.name}]], click <a th:href="@{/support}">here</a> for help-desk support.
</div>

8.4 템플릿 조각 제거
예제 애플리케이션으로 돌아가서, 제품 목록 템플릿의 이전 버전을 다시 살펴보겠습니다.

<table>
  <tr>
    <th>NAME</th>
    <th>PRICE</th>
    <th>IN STOCK</th>
    <th>COMMENTS</th>
  </tr>
  <tr th:each="prod : ${prods}" th:class="${prodStat.odd}? 'odd'">
    <td th:text="${prod.name}">Onions</td>
    <td th:text="${prod.price}">2.41</td>
    <td th:text="${prod.inStock}? #{true} : #{false}">yes</td>
    <td>
      <span th:text="${#lists.size(prod.comments)}">2</span> comment/s
      <a href="comments.html" 
         th:href="@{/product/comments(prodId=${prod.id})}" 
         th:unless="${#lists.isEmpty(prod.comments)}">view</a>
    </td>
  </tr>
</table>
이 코드는 템플릿으로는 괜찮지만, 정적 페이지(Thymeleaf를 사용하지 않고 브라우저에서 직접 열었을 때)로는 좋은 프로토타입이 되지 못할 것입니다.

왜냐하면 브라우저에서는 완벽하게 표시되지만, 해당 표에는 행이 하나뿐이고 그 행에는 가상의 데이터만 있기 때문입니다. 프로토타입으로서 현실감이 떨어지죠. 제품이 하나 이상 있어야 하고, 행도 더 필요합니다 .

그럼 몇 가지를 더 추가해 보겠습니다.

<table>
  <tr>
    <th>NAME</th>
    <th>PRICE</th>
    <th>IN STOCK</th>
    <th>COMMENTS</th>
  </tr>
  <tr th:each="prod : ${prods}" th:class="${prodStat.odd}? 'odd'">
    <td th:text="${prod.name}">Onions</td>
    <td th:text="${prod.price}">2.41</td>

8.5 레이아웃 상속
레이아웃을 하나의 파일로 구성하려면 프래그먼트를 사용할 수 있습니다. 다음은 프래그먼트를 사용하는 title간단한 레이아웃의 예입니다 .contentth:fragmentth:replace

<!DOCTYPE html>
<html th:fragment="layout (title, content)" xmlns:th="http://www.thymeleaf.org">
<head>
    <title th:replace="${title}">Layout Title</title>
</head>
<body>
    <h1>Layout H1</h1>
    <div th:replace="${content}">
        <p>Layout content</p>
    </div>
    <footer>
        Layout footer
    </footer>
</body>
</html>
이 예제는 제목 과 내용을 매개변수로 받는 '레이아웃' 이라는 프래그먼트를 선언합니다 . 이 프래그먼트를 상속받는 페이지에서는 제목과 내용이 아래 예제에 제공된 프래그먼트 표현식으로 대체됩니다.

<!DOCTYPE html>
<html th:replace="~{layoutFile :: layout(~{::title}, ~{::section})}">
<head>
    <title>Page Title</title>
</head>
<body>
<section>
    <p>Page content</p>
    <div>Included on page</div>
</section>
</body>
</html>
이 파일에서 태그는 레이아웃html 으로 대체되지만 , 레이아웃에서는 와 가 각각 및 블록으로 대체됩니다 .titlecontenttitlesection

원하는 경우, 레이아웃은 헤더 와 푸터 와 같은 여러 조각으로 구성할 수 있습니다 .

9 지역 변수
Thymeleaf에서는 로컬 변수를 템플릿의 특정 부분에 대해 정의된 변수로, 해당 부분 내에서만 평가할 수 있는 변수라고 합니다 .

이미 살펴본 예시로 prod제품 목록 페이지의 iter 변수를 들 수 있습니다.

<tr th:each="prod : ${prods}">
    ...
</tr>
해당 prod변수는 태그 범위 내에서만 사용 가능합니다 <tr>. 구체적으로는 다음과 같습니다.

th:*해당 태그에서 우선순위가 낮은 다른 속성에 대해 이 속성을 사용할 수 있습니다 th:each(즉, 해당 속성이 실행된 후에 실행됩니다 th:each).
<tr>이 기능은 태그의 모든 하위 요소, 예를 들어 다른 요소들 에서도 사용할 수 있습니다 <td>.
Thymeleaf는 속성을 사용하여 반복문 없이 지역 변수를 선언하는 방법을 제공하며 th:with, 그 구문은 속성 값 할당과 유사합니다.

<div th:with="firstPer=${persons[0]}">
  <p>
    The name of the first person is <span th:text="${firstPer.name}">Julius Caesar</span>.
  </p>
</div>
th:with해당 변수가 처리될 때 , firstPer로컬 변수로 생성되어 컨텍스트에서 가져온 변수 맵에 추가됩니다. 따라서 컨텍스트에 선언된 다른 변수들과 함께 평가할 수 있지만, 포함하는 <div>태그의 범위 내에서만 가능합니다.

일반적인 다중 변수 할당 구문을 사용하여 여러 변수를 동시에 정의할 수 있습니다.

<div th:with="firstPer=${persons[0]},secondPer=${persons[1]}">
  <p>
    The name of the first person is <span th:text="${firstPer.name}">Julius Caesar</span>.
  </p>
  <p>
    But the name of the second person is 
    <span th:text="${secondPer.name}">Marcus Antonius</span>.
  </p>
</div>
이 th:with속성을 사용하면 동일한 속성에 정의된 변수를 재사용할 수 있습니다.

<div th:with="company=${user.company + ' Co.'},account=${accounts[company]}">...</div>
이 코드를 우리 식료품점 홈페이지에 사용해 봅시다! 형식화된 날짜를 출력하기 위해 작성했던 코드 기억하시죠?

<p>
  Today is: 
  <span th:text="${#calendars.format(today,'dd MMMM yyyy')}">13 february 2011</span>
</p>
그런데 만약 이 기능이 지역 설정에 따라 달라지도록 하고 싶다면 어떻게 해야 할까요 "dd MMMM yyyy"? 예를 들어, 다음과 같은 메시지를 추가하고 싶을 수도 있습니다 home_en.properties.

date.format=MMMM dd'','' yyyy
…그리고 우리와 동등한 것 home_es.properties:

date.format=dd ''de'' MMMM'','' yyyy
