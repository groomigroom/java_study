
자바 스프링 부트로 서버 사이트 페이지 만드는 법
자바 스프링 부트로 서버 사이트 페이지를 만들려면 프로젝트 생성, 
템플릿 엔진 설정, 컨트롤러 작성의 3가지 핵심 단계를 거쳐야 합니다.
프로젝트 생성Spring Initializr 사이트를 이용해 프로젝트를 만듭니다.
필수 의존성으로 Spring Web과 타임리프(Thymeleaf) 같은 템플릿 엔진을 추가합니다.
자바(Java) 버전을 선택한 뒤 프로젝트를 내려받아 IDE에서 엽니다.
템플릿 엔진 및 화면 파일 준비src/main/resources/templates 폴더 안에 HTML 파일을 만듭니다.
타임리프를 사용하면 서버에서 전달받은 데이터를 HTML에 쉽게 출력할 수 있습니다.
컨트롤러 작성 및 실행@Controller 어노테이션이 붙은 자바 클래스를 만듭니다.
@GetMapping을 이용해 특정 주소(URL)로 접속했을 때 보여줄 HTML 파일 이름을 반환하도록 코드를 작성합니다.
서버를 실행하고 브라우저에 주소를 입력해 페이지가 잘 뜨는지 확인합니다.
