th:each


타임리프(Thymeleaf)의 th:each는 자바의 for-each 문처럼 목록(List, 배열 등)의 데이터를 반복해서 처리할 때 사용하는 반복문 속성입니다. HTML 태그에 지정해 컬렉션의 요소를 하나씩 꺼내며 동적인 요소를 쉽게 만들 수 있습니다. [1, 2, 3, 4] 
## 기본 사용법

* 형식: th:each="변수명 : ${리스트}"
* 동작: 지정한 리스트(${...})에서 값을 하나씩 꺼내 왼쪽 변수(변수명)에 담고, 해당 HTML 태그를 데이터 개수만큼 반복합니다.
* 예시: <tr th:each="user : ${users}"><td th:text="${user.name}">이름</td></tr> [1, 2, 4, 5] 

## 반복 상태 유지 (Status Variable)

* 두 번째 파라미터를 추가해 반복 상태(인덱스, 짝/홀수 여부 등)를 알 수 있습니다. [3, 6] 
* 형식: th:each="user, stat : ${users}" 또는 변수명 뒤에 Stat 자동 생성 (th:each="user : ${users}"일 때 userStat 사용 가능).
* 제공하는 주요 상태 값:
* index: 0부터 시작하는 순서
   * count: 1부터 시작하는 순서
   * size: 전체 개수
   * even, odd: 짝수/홀수 여부 (boolean)
   * first, last: 첫 번째/마지막 여부 (boolean) [6]

타임리프(th:each)의 실제 활용 예시 코드입니다.
컨트롤러에서 users라는 리스트에 사용자 3명(홍길동, 이순신, 강감찬)의 데이터를 담아 보냈다고 가정하고 작성한 HTML입니다.
## 1. 기본 반복문 예시
가장 단순하게 이름 목록을 반복해서 출력하는 방법입니다.

<ul>
  <!-- users 리스트를 반복하며, 각 데이터를 user 변수에 담습니다 -->
  <li th:each="user : ${users}" th:text="${user.name}">기본 이름</li>
</ul>

브라우저 렌더링 결과:

* 홍길동
* 이순신
* 강감찬

------------------------------
## 2. 상태 변수(Stat)를 활용한 표(Table) 예시
순번, 홀짝 스타일 변경, 첫 번째/마지막 요소 체크 등을 적용한 데이터 표 예시입니다.

<table border="1">
  <thead>
    <tr>
      <th>번호 (count)</th>
      <th>인덱스 (index)</th>
      <th>이름</th>
      <th>특이사항</th>
    </tr>
  </thead>
  <tbody>
    <!-- userStat이라는 상태 변수를 명시적으로 선언했습니다 -->
    <tr th:each="user, userStat : ${users}" th:style="${userStat.odd} ? 'background-color: #f2f2f2;' : ''">
      <!-- 1부터 시작하는 번호 표시 -->
      <td th:text="${userStat.count}">1</td>
      <!-- 0부터 시작하는 인덱스 표시 -->
      <td th:text="${userStat.index}">0</td>
      <!-- 데이터 출력 -->
      <td th:text="${user.name}">이름</td>
      <!-- 첫 번째와 마지막 요소에만 텍스트 표시 -->
      <td>
        <span th:if="${userStat.first}">★ 첫 손님</span>
        <span th:if="${userStat.last}">끝</span>
      </td>
    </tr>
  </tbody>
</table>

------------------------------
## 3. 상태 변수 생략 예시 (자동 생성)
두 번째 파라미터(userStat)를 적지 않아도, 타임리프가 [변수명] + Stat 조합으로 자동 생성해 줍니다.

<div th:each="user : ${users}">
  <!-- userStat을 선언하지 않았지만 자동으로 사용할 수 있습니다 -->
  <p th:text="${userStat.count} + '번째 사용자: ' + ${user.name}">1번째 사용자</p>
</div>

타임리프(th:each)와 연동되는 Spring Boot 컨트롤러 및 데이터 클래스(DTO) 예시 코드입니다.
## 1. 데이터 클래스 작성 (UserDto)
화면에 전달할 사용자 정보를 담을 가상의 객체입니다.

package com.example.demo.dto;
public class UserDto {
    private String name;
    private int age;

    // 생성자
    public UserDto(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // Getter (타임리프가 데이터를 읽을 때 필수)
    public String getName() { return name; }
    public int getAge() { return age; }
}

------------------------------
## 2. 스프링 컨트롤러 작성 (UserController)
리스트에 데이터를 담아 Model 객체를 통해 타임리프로 넘겨줍니다.

package com.example.demo.controller;
import com.example.demo.dto.UserDto;import org.springframework.stereotype.Controller;import org.springframework.ui.Model;import org.springframework.web.bind.annotation.GetMapping;
import java.util.ArrayList;import java.util.List;

@Controllerpublic class UserController {

    @GetMapping("/users")
    public String getUserList(Model model) {
        // 1. 가상의 리스트 데이터 생성
        List<UserDto> userList = new ArrayList<>();
        userList.add(new UserDto("홍길동", 20));
        userList.add(new UserDto("이순신", 30));
        userList.add(new UserDto("강감찬", 40));

        // 2. Model에 "users"라는 이름으로 리스트 전달
        // 이 이름이 타임리프의 ${users}와 매핑됩니다.
        model.addAttribute("users", userList);

        // 3. 호출할 HTML 뷰 파일명 반환 (src/main/resources/templates/user-list.html)
        return "user-list";
    }
}

------------------------------
## 3. 타임리프 HTML 작성 (user-list.html)
컨트롤러가 넘겨준 users 키값을 받아 화면에 반복 출력합니다.

<!DOCTYPE html>
<html xmlns:th="http://thymeleaf.org">
<head>
    <meta charset="UTF-8">
    <title>사용자 목록</title>
</head>
<body>
    <h1>사용자 리스트</h1>
    <table border="1">
        <thead>
            <tr>
                <th>순번</th>
                <th>이름</th>
                <th>나이</th>
            </tr>
        </thead>
        <tbody>
            <!-- ${users}는 컨트롤러의 model.addAttribute("users", ...)와 일치해야 합니다 -->
            <tr th:each="user, stat : ${users}">
                <td th:text="${stat.count}">1</td>
                <td th:text="${user.name}">이름</td>
                <td th:text="${user.age}">나이</td>
            </tr>
        </tbody>
    </table>
</body>
</html>

브라우저에서 http://localhost:8080/users로 접속하면 컨트롤러가 가공한 3명의 데이터가 표 형태로 반복되어 출력됩니다.
