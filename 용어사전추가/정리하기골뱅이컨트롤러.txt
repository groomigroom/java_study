@Entity 어노테이션을 사용하기 위해 필요한 스타터 의존성은 spring-boot-starter-data-jpa입니다. 

자바 스프링(JPA)에서 @Entity는 자바 클래스를 데이터베이스의 테이블과 연결(매핑)하는 선언입니다.
이 어노테이션이 붙은 클래스는 데이터베이스의 행(row) 하나와 대응되며,
JPA(Java Persistence API)가 데이터를 영구적으로 관리하는 기준 객체가 됩니다.
주요 특징
테이블 매핑: 클래스 이름이나 지정한 테이블 이름이 실제 DB 테이블과 연결됩니다.
필드 매핑: 클래스의 멤버 변수는 DB 테이블의 열(column)로 작동합니다.
관리 대상: JPA 영속성 컨텍스트가 데이터를 감지하고 저장, 수정(Dirty Checking)할 수 있게 됩니다.
함께 쓰이는 필수 어노테이션@Id: 테이블의 기본 키(Primary Key)를 지정합니다.
@GeneratedValue: 기본 키의 자동 생성 전략을 설정합니다 (예: Auto Increment).
@Table: 매핑할 DB 테이블 이름을 따로 지정할 때 사용합니다.

@Controller
클라이언트의 웹 요청을 받아 처리하고 뷰(View, HTML 화면 등)를 반환하는 클래스에 붙이는 어노테이션(Annotation)입니다.
스프링이 이 클래스를 빈(Bean)으로 등록해 웹 요청을 연결하는 길잡이로 쓰게 만듭니다.

@Controller (전통적인 MVC 컨트롤러)
주요 목적: HTML 화면(View) 렌더링 및 반환
동작 방식:메서드가 문자열을 반환하면 이를 View 이름(예: index.html)으로 인식하여 ViewResolver가 파일을 찾아 화면에 띄움
#####데이터를 직접 반환하려면 메서드에 @ResponseBody를 붙여야 함
