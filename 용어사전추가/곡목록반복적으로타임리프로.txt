곡 목록이 여러 개로 늘어났을 때 하나씩 일일이 손으로 적지 않고, 자바의 List와 타임리프의 th:each 반복문을 조합해 테이블 행(<tr>)을 자동으로 생성하는 구조로 확장해 보겠습니다.
기존 코드에서 1번 상품과 마지막 상품을 나누어 처리하던 하드코딩 방식을 제거하고, 데이터 중심의 세련된 웹 아키텍처로 바꾸는 작업입니다.

## 1. 자바 도메인 객체 수정 (SongMainProduct.java)
기존의 songNum1, songTitle1, songNumLast, songTitleLast와 같이 쪼개져 있던 수록곡 필드들을 과감히 삭제하고, 하나의 깔끔한 List<String> 형태로 통합합니다.

* 경로: src/main/java/groomi/groomgroom/SongMainProduct.java

package groomi.groomgroom;
import java.util.List; // ⭕ List 임포트 추가
public class SongMainProduct {
    private String albumTitleId;
    private String htmlTitle; 
    private String albumTitle; 
    private String introPp; 
    private String imgBorderColor; 
    private String genre; 
    private String agency; 
    private String company;
    
    // ⭕ 기존 개별 수록곡 변수들을 지우고, 곡 제목들을 담을 리스트 구조로 교체합니다.
    private List<String> songList; 

    // 생성자 수정
    public SongMainProduct(String albumTitleId, String htmlTitle, String albumTitle, String introPp, String imgBorderColor, String genre, String agency, String company, List<String> songList) {
        this.albumTitleId = albumTitleId;
        this.htmlTitle = htmlTitle;       
        this.albumTitle = albumTitle;
        this.introPp = introPp;
        this.imgBorderColor = imgBorderColor;
        this.genre = genre;
        this.agency = agency;
        this.company = company;
        this.songList = songList;
    }

    // Getter & Setter (기존 곡 관련 소스는 지우고 songList 용으로 추가)
    public List<String> getSongList() { return songList; }
    public void setSongList(List<String> songList) { this.songList = songList; }

    // 나머지 필드(albumTitleId, genre 등)의 기존 Getter/Setter는 그대로 둡니다.
    public String getAlbumTitleId() { return albumTitleId; }
    public String getHtmlTitle() { return htmlTitle; }
    public String getAlbumTitle() { return albumTitle; }
    public String getIntroPp() { return introPp; }
    public String getImgBorderColor() { return imgBorderColor; }
    public String getGenre() { return genre; }
    public String getAgency() { return agency; }
    public String getCompany() { return company; }
}

## 2. 비즈니스 로직 서비스 수정 (SongMainProductService.java)
이제 새 앨범 데이터를 가동할 때, List.of()를 사용해 원하는 만큼 곡 목록을 마음껏 담아줄 수 있습니다.

* 경로: src/main/java/groomi/groomgroom/SongMainProductService.java

package groomi.groomgroom;
import org.springframework.stereotype.Service;import java.util.HashMap;import java.util.List;import java.util.Map;

@Service public class SongMainProductService {
    private static final Map<String, SongMainProduct> SongMainRepository = new HashMap<>();

    public SongMainProductService() {
        // ⭕ List.of(...) 내부에 원하는 만큼 곡 제목을 콤마로 연결해 전달합니다.
        List<String> trackList = List.of(
            "Baby Flower (Original)",
            "Baby Flower (Tokyo Remix : Full8loom)",
            "Baby Flower (Instrumental)",
            "Baby Flower (Acapella Ver.)"
        );

        SongMainSave(new SongMainProduct(
            "baby-flower-remix", 
            "Baby Flower City", 
            "Baby Flower Remixes Album", 
            "소개글 1줄<br>소개글 2줄<br>소개글 3줄", 
            "#333333", 
            "Dance/Remix", 
            "MODHAUS", 
            "Kakao Entertainment",
            trackList // ⭕ 생성자 인자로 리스트 주입
        ));
    }

    public SongMainProduct SongMainSave(SongMainProduct songMainProduct) {
        SongMainRepository.put(songMainProduct.getAlbumTitleId(), songMainProduct);
        return songMainProduct;
    }

    public SongMainProduct SongMainFindById(String albumTitleId) {
        return SongMainRepository.get(albumTitleId);
    }
}

## 3. 타임리프 HTML 템플릿 수정 (SongMain.html)
가장 핵심이 되는 화면 영역입니다. 기존 템플릿 파일 하단의 <table class='song_main_tb2'> 내부 구조를 th:each 반복문으로 전면 교체합니다.

* 경로: src/main/resources/templates/SongMain/SongMain.html

<table class='song_main_tb2'>
    <tbody>
        <!-- 테이블의 제목 행 (반복문 제외) -->
        <tr class='song_main_tb2_tr1'>
            <td><p>번호</p></td>
            <td><p>제목</p></td>
        </tr>
        
        <!-- ⭕ 핵심: th:each를 통해 자바 리스트에 담긴 데이터 수만큼 <tr> 행이 자동 생성됩니다 -->
        <!-- song : 리스트에서 순서대로 꺼낸 한 곡의 제목 문자열 -->
        <!-- status : 타임리프가 제공하는 상태 변수로 인덱스, 순번 등을 계산할 때 씁니다 -->
        <tr th:each="song, status : ${songMainProduct.songList}">
            <td>
                <!-- status.count는 1부터 시작하는 순번을 자동으로 매겨줍니다 (1, 2, 3...) -->
                <p th:text="${status.count}">1</p>
            </td>
            <td>
                <!-- 꺼내온 곡 제목을 매핑합니다 -->
                <p th:text="${song}">곡 제목 내용</p>
            </td>
        </tr>
    </tbody>
</table>

## 💡 타임리프 반복문 상태 변수(status) 꿀팁
th:each="변수명, 상태변수명" 구조에서 뒤에 적어준 status 객체는 루프를 돌 때 매우 유용한 정보들을 품고 있어 동적 UI 구현에 필수적입니다.

* status.count: 1부터 시작하는 현재 순번 (1, 2, 3...)
* status.index: 0부터 시작하는 현재 인덱스 번호 (0, 1, 2...)
* status.size: 전체 리스트의 총 데이터 개수
* status.first / status.last: 현재 도는 루프가 첫 번째 행인지, 혹은 마지막 행인지 판별하여 true/false 반환 (특정 줄에만 테두리 곡률 CSS나 밑줄을 지우고 싶을 때 조건문 th:if와 엮어 쓰기 좋습니다.)
