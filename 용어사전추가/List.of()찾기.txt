List.of()는 자바 9(Java 9)부터 도입된 수정할 수 없는 빈 리스트(Unmodifiable List)를 생성하는 
불변 메서드입니다. 
## 💡 핵심 특징

* 변경 불가능 (Immutable): 생성 후 요소를 추가(add), 삭제(remove), 변경(set)할 수 없습니다. 
시도하면 UnsupportedOperationException 에러가 발생합니다.
* 메모리 효율성: 내부적으로 고정된 빈 리스트 인스턴스를 재사용하므로 
메모리를 거의 차지하지 않습니다.
* Null 허용 안 함: 빈 리스트일 때는 상관없지만, 
List.of(A, B)처럼 값을 넣을 때 null을 입력하면 NullPointerException이 발생합니다.

## 🛠 주요 용도

* 안전한 기본값 반환: 메서드에서 조건에 맞아 돌려줄 데이터가 없을 때, 
null 대신 안전한 빈 리스트를 반환하여 NullPointerException을 방지할 때 사용합니다.
* 데이터 보호: 외부에서 리스트의 내용을 함부로 조작하지 못하도록 읽기 전용 
데이터를 전달할 때 씁니다.

## 💻 코드 예시

// 1. 빈 불변 리스트 생성
List<String> emptyList = List.of(); 
// 2. 값이 있는 불변 리스트 생성도 가능
List<String> names = List.of("Kim", "Lee"); 

names.add("Park"); // ❌ 에러 발생 (java.lang.UnsupportedOperationException)
