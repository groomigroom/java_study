자바에서 불변 객체(Immutable Object)란
한 번 생성되면
그 내부의 상태(필드 값)를 절대 변경할 수
없는 객체를 말합니다.
즉, 객체 안의 데이터를 수정하는 것이 불가능하며,
값을 바꾸고 싶다면 기존 객체를 수정하는 대신
새로운 객체를 생성해야 합니다.

자바의 대표적인 불변 객체로는 String 클래스가 있습니다.불변 객체의 핵심 구조와 원칙자바에서 불변 클래스를 만들려면 다음과 같은 구조적 규칙을 지켜야 합니다.모든 필드를 private과 final로 선언: 외부에서 직접 필드에 접근하거나 값을 바꿀 수 없으며, 생성자를 통해서만 초기화됩니다.Setter 메서드 미제공: 객체 생성 이후 상태 변경을 유도하는 수정자(Setter) 메서드를 아예 제공하지 않습니다.상속 방지 (final 클래스): 하위 클래스가 필드나 메서드를 오버라이딩하여 가변 상태로 만드는 것을 막기 위해 클래스 자체를 final로 선언합니다.가변 필드 방어적 복사 (Defensive Copy): 내부에 가변 객체(예: Date, List 등) 필드가 있다면, 생성자와 Getter에서 객체를 그대로 반환하지 않고 복사본을 주고받아야 합니다.불변 객체를 사용하는 이유스레드 안전성 (Thread-Safe): 여러 스레드가 동시에 객체를 읽어도 상태가 변하지 않으므로 별도의 동기화(Synchronized) 작업이 필요 없습니다.높은 신뢰성과 안정성: 코드가 복잡해도 객체의 값이 어디선가 예기치 않게 변경될 공포가 없어 디버깅이 쉽습니다.사이드 이펙트(Side Effect) 방지: 참조를 공유해도 원본 데이터가 훼손되지 않아 함수형 프로그래밍이나 맵(Map)의 키(Key), 셋(Set)의 요소로 쓰기에 적합합니다.불변 객체를 만드는 구체적인 자바 코드 예제나 가변 객체와의 성능 및 메모리 차이에 대해 더 알고 싶으신가요?티스토리[Java] 불변 객체(Immutable Object)란 무엇일까? - Green Lawn - 티스토리2022. 2. 15. — 불변 객체란 객체가 생성된 이후에 상태를 바꿀 수 없는 객체를 말합니다. 즉, 힙 영역에서 객체가 가리키고 있는 데이터 자체의 변화가 불가능한 것을 ...YouTube·우아한테크4m[10분 테코톡] 🔪시카의 Java final과 불변 객체YouTube·쉬운코드9mBJ.26 불변 객체(immutable object)는 안정적인 개발에 도움이 됩니다! ...티스토리[Java] 불변 객체(Immutable Object) 및 final을 사용해야 하는 이유2021. 3. 4. — 불변 객체란 객체 생성 이후 내부의 상태가 변하지 않는 객체이다. 불변 객체는 read-only 메소드만을 제공하며, 객체의 내부 상태를 제공하는 메소드를 제공하...티스토리[Java] Immutable 객체란? - 어제 오늘 내일 - 티스토리2026. 1. 4. — Java에서 Immutable 객체(불변 객체)란 한 번 생성되면 내부 상태가 절대로 변경되지 않는 객체를 말합니다. 즉, 객체의 필드 값을 수정할 수 없으며 .YouTube·Neso Academy1mImmutable Classes and Objects in JavaGitHubJava Functional Programming - 불변성 (Immutability)2025. 11. 19. — 2.1. 클래스 선언: final 키워드 사용 클래스를 final 로 선언하여 다른 클래스가 이 클래스를 상속(Extend)하는 것을 방지해야 합니다. 상속을 허...GitHub[이펙티브 자바 3판] 4장. 클래스와 인터페이스2019. 5. 21. — 불변 클래스를 만드는 규칙 객체의 상태를 변경하는 메서드(변경자)를 제공하지 않는다. 클래스를 확장할 수 없도록 한다. 모든 필드를 final로 선언한다. 모든 ...
