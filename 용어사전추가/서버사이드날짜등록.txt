thymeleaf_LocalDateTime.txt

자바 스프링과 타임리프를 사용할 때, 날짜 데이터는 Date 대신 LocalDate나 LocalDateTime (Java 8+ 정적 날짜/시간 API)을 사용하는 것이 훨씬 좋습니다.
Date 클래스는 낡았고 멀티스레드 환경에서 안전하지 않으며, 타임리프에서 포맷팅(형식 지정)하기도 더 까다롭습니다.
원하시는 2026.06.01. 형식으로 출력하는 방법과 추천 클래스를 정리해 드립니다.
## 1. 자바 컨트롤러 구성 (추천)
Date 대신 java.time.LocalDate를 사용하여 데이터를 넘기세요.

@Controllerpublic class MyController {
    @GetMapping("/date-page")
    public String getPage(Model model) {
        // 원하는 날짜 설정 (2026년 6월 1일)
        LocalDate targetDate = LocalDate.of(2026, 6, 1);
        model.addAttribute("myDate", targetDate);
        return "myTemplate";
    }
}

## 2. 타임리프에서 형식 맞추기 (2026.06.01.)
타임리프의 #temporals 유틸리티 객체를 사용하면 자바 코드를 건들지 않고 원하는 형식을 쉽게 만들 수 있습니다. 뒤에 마침표(.)를 꼭 붙이고 싶다면 포맷 문자열 끝에 점을 넣어주면 됩니다.

<!-- 결과: 2026.06.01. -->
<p th:text="${#temporals.format(myDate, 'yyyy.MM.dd.')}"></p>

------------------------------
## 꼭 Date 타입을 써야만 하는 상황이라면?
만약 기존 레거시 코드 때문에 java.util.Date를 반드시 써야 한다면, 타임리프에서 #dates 객체를 사용해야 합니다.

<!-- Date 타입일 경우 결과: 2026.06.01. -->
<p th:text="${#dates.format(myDate, 'yyyy.MM.dd.')}"></p>

## 요약

* 데이터 타입: LocalDate 사용을 강력히 권장합니다.
* 타임리프 문법: #temporals.format(데이터, 'yyyy.MM.dd.')를 사용하세요.

------------------------------
현재 프로젝트가 스프링 부트 3.x 버전인지 아니면 2.x 버전인지에 따라 타임리프 자바8 날짜 라이브러리 의존성 추가 필요 여부가 달라질 수 있습니다. 혹시 화면에 날짜가 뜨지 않고 에러가 발생하거나, 스프링 버전에 맞는 의존성 설정이 필요하시면 말씀해 주세요!
