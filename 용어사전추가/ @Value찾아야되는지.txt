스프링 부트에서 @Value는 외부 설정 파일(properties, yml)에 정의된 값을 자바 변수에 주입하는 어노테이션이며, 가장 기본이 되는 spring-boot-starter에 포함되어 있습니다. [1, 2] 
------------------------------
## 1. @Value의 의미와 역할

* 
* 값 주입: application.properties나 application.yml에 적어둔 설정값을 가져옵니다.
* 타입 변환: 설정 파일의 문자열을 String, int, Boolean, List 등 필드 타입에 맞춰 자동 변환합니다.
* 코드 분리: 환경별(개발, 운영)로 달라지는 보안 키나 서버 주소를 소스코드 수정 없이 관리할 수 있습니다. [2, 3, 4, 5] 
* 

// application.properties 예시// jwt.secret-key=my-super-secret-key

@Componentpublic class JwtProvider {
    @Value("${jwt.secret-key}")
    private String secretKey; // "my-super-secret-key"가 자동으로 주입됨
}

------------------------------
## 2. 속해있는 Starter Dependency

* 
* spring-boot-starter (핵심 의존성): @Value는 스프링 프레임워크의 코어 기능(spring-context)에 속해 있습니다. 스프링 부트에서는 모든 스타터 라이브러리의 뼈대가 되는 spring-boot-starter에 기본 포함되어 있습니다.
* 자동 포함: 웹 개발용 spring-boot-starter-web이나 데이터베이스용 spring-boot-starter-data-jpa 등 어떤 스타터를 사용하더라도 내부적으로 spring-boot-starter를 참조하므로 항상 사용 가능합니다. [1] 
* 

------------------------------
## 3. 사용할 때 주의할 점 ⚠️

* 
* Spring Bean에서만 작동: @Value는 스프링이 관리하는 객체(@Component, @Service, @Controller 등) 내부에서만 작동하며, new 키워드로 직접 생성한 인스턴스에서는 작동하지 않고 null이 됩니다. [3] 
* 오타 취약성: 문자열 형태로 키값을 입력하기 때문에, 설정 파일의 키값과 다르게 적으면 애플리케이션 구동 시점에 에러가 발생합니다. [4] 
* 

------------------------------
