




@RequestParam
자바 스프링(Spring)에서 @RequestParam은 HTTP 요청 파라미터를 컨트롤러 메서드의 변수에 연결(바인딩)해 주는 어노테이션입니다. 주로 웹 브라우저의 쿼리 스트링(?name=abc)이나 폼(Form) 데이터를 코드로 쉽게 가져올 때 씁니다.
주요 기능과 특징
값 연결: URL 뒤에 붙은 쿼리 파라미터나 HTML 폼 데이터를 메서드의 매개변수와 바로 연결합니다.
필수 값 설정: required = true(기본값)로 지정하면 값이 없을 때 오류가 나며, required = false로 바꾸면 값이 없을 때 비워둡니다.
기본값 지정: 값이 없을 때 대신 쓸 기본값을 defaultValue = "값" 형태로 정할 수 있습니다.

데이터를 화면(HTML)이 아닌 JSON 같은 순수 데이터로 바로 보낼 때 씁니다.

@RestController (RESTful API 컨트롤러)
주요 목적: JSON, XML 등의 객체 데이터(Data) 직접 반환
동작 방식:@Controller + @ResponseBody의 조합메서드의 반환값이 View를 거치지 않고,
HttpMessageConverter를 통해 HTTP 응답 본문(Body)에 직접 쓰임 (문자열이나 객체가 JSON 등으로 변환되어 전송됨)

api

API는 Application Programming Interface(응용 프로그램 프로그래밍 인터페이스)의 약자로,
서로 다른 소프트웨어가 서로 통신하고 데이터를 주고받을 수 있게 해주는 규칙이나 도구입니다.
식당에서 손님(클라이언트)이 주문을 하면 웨이터(API)가 주방(서버)에 전달하고 음식을 다시 가져다주는 것과 비슷한 역할을 합니다.
API의 핵심 특징
연결성: 프로그램과 프로그램을 이어줍니다.
규칙 제공: 정해진 방식대로 요청하고 응답을 받게 돕습니다.
은닉성: 내부 작동 방식을 몰라도 기능을 쓸 수 있습니다.
일상 속 API 예시
날씨 앱: 기상청의 데이터를 가져와 화면에 보여줍니다.
지도 연동: 배달 앱에서 가게 위치를 지도에 띄울 때 네이버나 카카오 지도를 불러옵니다.
간편 로그인: 다른 웹사이트에서 '카카오로 로그인'을 누르면 인증 정보를 받아옵니다.

redirect:

자바 스프링에서 return "redirect:/result.html"; 코드의 redirect:는 클라이언트(브라우저)에게 지정한 URL로 새로운 요청을 다시 보내라고 명령하는 지시어입니다.
스프링 MVC 구조에서 이 구문이 작동하는 원리와 특징은 다음과 같습니다.
## 1. 작동 원리 (동작 방식)

   1. 서버의 응답: 컨트롤러가 redirect:/result.html을 반환하면, 스프링은 브라우저에 HTTP 상태 코드 302(또는 303)와 함께 Location: /result.html 헤더를 보냅니다.
   2. 브라우저의 재요청: 응답을 받은 브라우저는 주소창의 URL을 /result.html로 변경하고, 해당 주소로 새로운 GET 요청을 자동으로 보냅니다.

## 2. Forward(포워드)와의 차이점

* 
* forward (기본값): 서버 내부에서 페이지를 이동합니다. 브라우저는 이동 사실을 모르기 때문에 주소창의 URL이 변하지 않고, Request/Response 객체가 유지됩니다.
* redirect: 브라우저를 거쳐서 완전히 새로운 요청을 만듭니다. 주소창의 URL이 새로 요청한 주소로 바뀌며, 기존 Request/Response 객체는 소멸하고 새로 생성됩니다. 
* 

## 3. 주요 사용 목적

* 
* 중복 제출 방지 (PRG 패턴): 게시판 글쓰기나 결제 같은 POST 요청을 처리한 후 화면을 그대로 두면, 사용자가 '새로고침'을 했을 때 동일한 데이터가 중복 요청됩니다. 
이를 막기 위해 처리 후 결과 페이지로 redirect(GET 요청)를 시켜 주소창을 바꾸는 Post-Redirect-Get 패턴을 구현할 때 필수적으로 사용합니다.
* 페이지 전환: 로그인 성공 후 메인 페이지로 이동시키거나, 권한이 없는 사용자를 로그인 페이지로 튕겨낼 때 사용합니다.

RedirectAttributes (자바 스프링)
리다이렉트(redirect:) 수행 시 다른 컨트롤러나 페이지로 데이터를 안전하게 전달하기 위해 사용하는 인터페이스입니다.
핵심 기능인 addAttribute와 addFlashAttribute를 제공합니다.
주요 기능
addAttribute:전달할 데이터를 URL 쿼리 파라미터(?name=value) 형태로 붙여서 보냅니다.
새로고침을 해도 URL에 남아 계속 유지됩니다.
addFlashAttribute:데이터를 일시적인 세션에 저장했다가 리다이렉트 후 바로 소멸시키는 방식입니다.
URL에 데이터가 노출되지 않아 보안상 안전하며, 
새로고침 시 데이터가 사라집니다. 
(주로 "회원가입이 완료되었습니다" 같은 일회성 알림 메시지에 사용)

Scanner

Scanner 클래스는 콘솔 입력을 편리하게 처리할 때 사용합니다.
import java.util.Scanner;로 클래스를 불러온 후 Scanner sc = new Scanner(System.in);으로 객체를 생성해 사용합니다.
주요 메서드로 문자열은 sc.next()(공백 포함 안 됨)와 sc.nextLine(), 숫자는 sc.nextInt() 등이 있습니다.기
본 사용 방법
Scanner를 사용하기 위한 필수 단계는 다음과 같습니다:
클래스 가져오기 (Import): java.util 패키지에 있으므로 코드 상단에 추가해야 합니다.
객체 생성: 키보드 입력을 받기 위해 System.in을 매개변수로 넘겨 객체를 생성합니다.
입력 메서드 호출: 변수 타입에 맞는 메서드를 사용하여 콘솔의 값을 변수에 저장합니다.
주요 메서드 종류
sc.next(): 공백(띄어쓰기) 전까지의 한 단어만 문자열로 읽어옵니다.
sc.nextLine(): Enter 키를 누르기 전까지 문장의 한 줄 전체를 읽어옵니다.
sc.nextInt(): 정수(int) 값을 읽어옵니다.
sc.nextDouble(): 실수(double) 값을 읽어옵니다.
간단한 활용 예제
사용자로부터 이름과 나이를 입력받아 출력하는 예제입니다.java

import java.util.Scanner; // 1. Scanner 클래스 불러오기

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in); // 2. Scanner 객체 생성

        System.out.print("이름을 입력하세요: ");
        String name = sc.next(); // 3. 문자열 입력 받기

        System.out.print("나이를 입력하세요: ");
        int age = sc.nextInt(); // 3. 정수 입력 받기

        System.out.println(name + "님의 나이는 " + age + "세입니다.");
        
        sc.close(); // 4. 사용이 끝난 스캐너는 닫아주는 것이 좋습니다.
    }
}

Spring project 생성하기

플러그인 설치를 완료하셨으니, 이제 이클립스 안에서 바로 프로젝트를 만드시면 됩니다. 
아래 순서대로 클릭하며 따라 해보세요.

## 1단계: 스프링 부트 생성 창 열기

   1. 이클립스 상단 메뉴에서 [File] ➔ [New] ➔ [Project...]를 누릅니다.
   * (단축키: 키보드 Ctrl + N을 동시에 누르셔도 됩니다.) 
   2. 마법사 창이 뜨면 아래로 내려 [Spring Boot] 폴더를 찾아서 엽니다.
   3. [Spring Starter Project]를 마우스로 선택하고 [Next]를 누릅니다.

## 2단계: 프로젝트 기본 설정 입력
설정 창이 나오면 아래 주요 항목들을 입력하거나 선택합니다.

* Name: 프로젝트 이름 (예: demo)
* Type: 빌드 도구 선택 (Maven 또는 Gradle-Groovy 중 선택, 보통 Maven을 많이 씁니다.)
* Java: 내 컴퓨터에 설치된 자바 버전에 맞춥니다. (예: 17 또는 21)
* Group: 회사나 본인의 도메인 주소 역순 (예: com.example)
* Artifact: 프로젝트 식별자 (보통 Name과 동일하게 입력됩니다.)
* 설정을 마쳤다면 [Next]를 누릅니다. [6, 7] 

## 3단계: 부트 버전 및 필수 라이브러리 추가
이 단계는 어떤 기능(웹, 데이터베이스 등)을 쓸지 고르는 단계입니다.

   1. Spring Boot Version: 가장 상단에서 버전을 고릅니다. (이름 뒤에 SNAPSHOT이나 M이 붙지 않은 가장 높은 버전을 고르는 것이 안전합니다.)
   2. Frequently Used / Search: 필요한 라이브러리를 검색해서 체크합니다. 처음에 공부하거나 웹 사이트를 만드실 때는 아래 3개를 가장 추천합니다.
   * Spring Web: 웹 기능 및 REST API 만들 때 필수
      * Spring Boot DevTools: 코드를 고치면 서버를 자동으로 껐다 켜주는 편리한 도구
      * Lombok: 자바의 Getter/Setter 코드를 자동으로 만들어주는 도구
   3. 체크를 완료했다면 우측 하단의 [Finish]를 누릅니다.


## 생성 후 최종 확인 (실행하기)

   1. 왼쪽 Package Explorer 창에 프로젝트가 새로 생겼는지 확인합니다.
   2. 처음 만들 때는 오른쪽 아래에 Downloading... 게이지가 올라가며 필요한 파일들을 인터넷에서 가져옵니다.
(이 작업이 완전히 끝날 때까지 1~2분 정도 기다려 주세요.)
   3. src/main/java 폴더 안에 있는 [프로젝트이름]Application.java 파일을 찾아서 엽니다.
   4. 파일 안에서 마우스 우클릭을 한 뒤 [Run As] ➔ [Spring Boot App]을 누르면 하단 콘솔 창에 스프링 로고가 뜨면서 서버가 켜집니다.

spring web 라이브러리

자바 스프링(Spring)의 Spring Web 라이브러리는 웹 애플리케이션과 RESTful API를 쉽게 만들 수 있게 돕는 핵심 도구이며, 
주로 Spring MVC, 내장 톰캣, JSON 변환 기능을 포함합니다. 보통 Spring Initializr에서 spring-boot-starter-web 형태로 추가해 사용합니다. 

주요 포함 기능
Spring MVC: 웹 요청을 받고 처리하는 DispatcherServlet 및 @Controller, @RestController 기능 제공
내장 톰캣(Tomcat): 별도의 외장 서버 설치 없이 실행 가능한 웹 서버 포함
JSON 변환(Jackson): 객체를 JSON 데이터로 바꾸거나 그 반대로 바꾸는 기능 기본 탑재 
주요 역할과 특징
HTTP 요청 처리: GET, POST 등 클라이언트의 요청을 받아 알맞은 로직으로 연결
간편한 설정: 복잡한 XML 설정 없이 어노테이션만으로 웹 서비스 구축 가능
스타터 패키지: spring-boot-starter-web을 쓰면 웹 개발에 필요한 필수 라이브러리들이 자동으로 함께 모여 편리함

String.format( title=%s / content=%s , title, content);
String.format() 메서드는 지정한 형식(Format)에 맞춰 문자열을 생성하는 기능이며,
%s 자리에 변수 title과 content의 값을 순서대로 넣어 title=값 / content=값 형태의 문자열로 만들어 줍니다.
주요 구성 요소
"title=%s / content=%s": 첫 번째 인수로 전달된 틀(템플릿)이며,
%s는 문자열이 들어갈 자리(플레이스홀더)를 뜻합니다.
title: 첫 번째 %s 자리에 들어갈 변수 값입니다.
content: 두 번째 %s 자리에 들어갈 변수 값입니다.
