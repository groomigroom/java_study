Scanner 클래스는 콘솔 입력을 편리하게 처리할 때 사용합니다. import java.util.Scanner;로 클래스를 불러온 후 Scanner sc = new Scanner(System.in);으로 객체를 생성해 사용합니다. 주요 메서드로 문자열은 sc.next()(공백 포함 안 됨)와 sc.nextLine(), 숫자는 sc.nextInt() 등이 있습니다.기본 사용 방법Scanner를 사용하기 위한 필수 단계는 다음과 같습니다:클래스 가져오기 (Import): java.util 패키지에 있으므로 코드 상단에 추가해야 합니다.객체 생성: 키보드 입력을 받기 위해 System.in을 매개변수로 넘겨 객체를 생성합니다.입력 메서드 호출: 변수 타입에 맞는 메서드를 사용하여 콘솔의 값을 변수에 저장합니다.주요 메서드 종류sc.next(): 공백(띄어쓰기) 전까지의 한 단어만 문자열로 읽어옵니다.sc.nextLine(): Enter 키를 누르기 전까지 문장의 한 줄 전체를 읽어옵니다.sc.nextInt(): 정수(int) 값을 읽어옵니다.sc.nextDouble(): 실수(double) 값을 읽어옵니다.간단한 활용 예제사용자로부터 이름과 나이를 입력받아 출력하는 예제입니다.javaimport java.util.Scanner; // 1. Scanner 클래스 불러오기

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in); // 2. Scanner 객체 생성

        System.out.print("이름을 입력하세요: ");
        String name = sc.next(); // 3. 문자열 입력 받기

        System.out.print("나이를 입력하세요: ");
        int age = sc.nextInt(); // 3. 정수 입력 받기

        System.out.println(name + "님의 나이는 " + age + "세입니다.");
        
        sc.close(); // 4. 사용이 끝난 스캐너는 닫아주는 것이 좋습니다.
    }
}
