자바 롬복(Lombok)의 @RequiredArgsConstructor는 클래스 내부에 final이나 @NonNull이 붙은 필드를 모아 생성자를 자동으로 만들어주는 어노테이션입니다. 스프링에서는 이를 통해 번거로운 생성자 코드 작성 없이 생성자 주입(Constructor Injection) 방식을 편하게 구현합니다.주요 특징과 동작 방식자동 생성: final 키워드가 붙은 필드만 매개변수로 받는 생성자를 컴파일 시점에 만들어줍니다.스프링 빈 주입: 스프링 4.3부터는 클래스에 생성자가 단 하나만 있고 그 생성자의 매개변수가 빈으로 등록되어 있다면 @Autowired를 생략할 수 있습니다. 이 덕분에 롬복과 결합해 깔끔한 의존성 주입이 가능합니다.사용 예시java@Service
@RequiredArgsConstructor // final 필드를 받는 생성자를 자동 생성
public class MemberService {
    
    private final MemberRepository memberRepository; // 필수 의존성
    private final EmailService emailService;         // 필수 의존성
    
    // 개발자가 직접 생성자를 쓰지 않아도 롬복이 아래와 같은 생성자를 만들어 줌
    // public MemberService(MemberRepository memberRepository, EmailService emailService) {
    //     this.memberRepository = memberRepository;
    //     this.emailService = emailService;
    // }
}
코드를 사용할 때는 주의가 필요합니다.왜 쓰나요? (장점)코드 간결화: 의존성 개수가 늘어나거나 줄어들어도 생성자를 직접 수정할 필요가 없습니다.불변성 보장: final을 사용하므로 객체가 생성된 이후에 의존성 객체가 바뀔 위험이 없습니다.순환 참조 방지: 필드 주입(@Autowired)과 달리 애플리케이션 구동 시점에 순환 참조 에러를 미리 발견할 수 있습니다.
