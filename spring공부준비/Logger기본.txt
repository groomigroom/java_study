자바 스프링에서 Logger는 프로그램이 실행되는 동안 발생하는 기록(로그)을 남기기 위해 사용하는 인터페이스(데이터 타입)입니다. System.out.println 대신 파일이나 콘솔에 단계별(정보, 경고, 에러 등) 상태를 안전하고 체계적으로 출력하는 도구입니다. [1, 2, 3, 4] 
## Logger의 주요 특징과 의미

* 기록 도구: 변수나 상태 값, 에러 발생 시점을 콘솔이나 파일에 남기는 역할을 합니다.
* 인터페이스 구조: Logger는 보통 직접 구현체를 쓰지 않고 SLF4J 같은 표준 인터페이스 타입을 사용합니다.
* 성능과 효율: 단순히 글을 찍는 것을 넘어, 로그 단계를 조절(INFO, DEBUG, ERROR 등)해 불필요한 연산을 줄입니다. [1, 2, 5, 6] 

## 사용 방식

* 선언 방법: private static final Logger log = LoggerFactory.getLogger(MyClass.class); 형태로 선언합니다.
* 간편식: 롬복(Lombok) 라이브러리를 쓰면 @Slf4j 어노테이션 하나로 위 선언을 대신할 수 있습니다. [1, 7]

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class LogController {

    // 1. Logger 타입의 변수를 직접 선언하고 생성합니다.
    private static final Logger log = LoggerFactory.getLogger(LogController.class);

    @GetMapping("/api/greet")
    public String greet(@RequestParam(value = "name", defaultValue = "Guest") String name) {
        
        // 2. Logger 타입을 이용한 레벨별 로그 출력
        log.trace("TRACE 레벨: 상세한 경로 추적용");
        log.debug("DEBUG 레벨: 개발 단계에서 변수 값 확인용. 입력값 = {}", name);
        log.info("INFO 레벨: 주요 흐름 기록. 사용자 요청 처리 중");
        log.warn("WARN 레벨: 시스템 문제는 없지만 주의가 필요함");
        
        try {
            if ("admin".equals(name)) {
                throw new IllegalArgumentException("관리자 계정은 접근 제한");
            }
        } catch (Exception e) {
            // 에러 발생 시 예외 객체(e)를 넘겨 StackTrace를 함께 출력
            log.error("ERROR 레벨: 치명적인 에러 발생! 사유: {}", e.getMessage(), e);
            return "Error occurred";
        }

        return "Hello, " + name;
    }
}
