@Component
public class ScheduledTasks {

	private static final Logger log = LoggerFactory.getLogger(ScheduledTasks.class);

	private static final SimpleDateFormat dateFormat = new SimpleDateFormat("HH:mm:ss");

	@Scheduled(fixedRate = 5000)
	public void reportCurrentTime() {
		log.info("The time is now {}", dateFormat.format(new Date()));
	}
}


스프링 프레임워크(Spring Framework)에서 제공하는 스케줄러(Scheduler) 기능을 활용하여 5초마다 현재 시간을 로그로 출력하는 자바 클래스입니다.
각 코드 라인별 기능과 핵심 개념을 상세히 설명해 드리겠습니다.
------------------------------
## 1. 애너테이션 및 클래스 선언부

@Componentpublic class ScheduledTasks {


* @Component: 스프링 프레임워크에게 이 클래스를 스프링 빈(Bean)으로 등록하라고 알려주는 애너테이션입니다. 스프링이 관리하는 객체가 되어야 내부에 작성된 @Scheduled 스케줄러 기능이 정상적으로 동작합니다.
* public class ScheduledTasks: 주기적인 작업을 수행할 메소드들을 모아두는 클래스입니다.

------------------------------
## 2. 로그 및 날짜 포맷 설정부

private static final Logger log = LoggerFactory.getLogger(ScheduledTasks.class);


* Logger: 애플리케이션의 실행 상태나 정보를 파일이나 콘솔에 기록(로그)하기 위한 객체입니다. 여기서는 SLF4J 라이브러리의 LoggerFactory를 사용해 현재 클래스(ScheduledTasks.class) 전용 로거를 생성했습니다. System.out.println 대신 로그 라이브러리를 쓰는 것이 실무 표준입니다.

private static final SimpleDateFormat dateFormat = new SimpleDateFormat("HH:mm:ss");


* SimpleDateFormat: 날짜와 시간 데이터를 원하는 문자열 포맷으로 변환해주는 클래스입니다. "HH:mm:ss" 패턴을 지정했으므로, 시간 데이터를 "시:분:초" 형태로 출력하게 됩니다.

------------------------------
## 3. 스케줄러 메소드 구현부

@Scheduled(fixedRate = 5000)public void reportCurrentTime() {
        log.info("The time is now {}", dateFormat.format(new Date()));
}


* @Scheduled(fixedRate = 5000): 이 메소드를 주기적으로 자동 실행하도록 지정하는 핵심 애너테이션입니다.
* fixedRate = 5000: 메소드가 시작하는 시점을 기준으로 밀리초(ms) 단위로 실행 간격을 설정합니다. 즉, 5000ms = 5초마다 이 메소드가 반복 실행됩니다. (이전 작업의 종료 여부와 상관없이 정확히 5초 주기로 실행을 시도합니다.)
* public void reportCurrentTime(): 실제 예약되어 실행될 작업 내용을 담은 메소드입니다. 반환 타입은 없어야(void) 하며, 매개변수도 받지 않아야 합니다.
* new Date(): 현재 시점의 날짜와 시간 정보를 가진 객체를 생성합니다.
* dateFormat.format(...): 생성된 현재 시간을 앞서 설정한 "HH:mm:ss" 포맷의 문자열로 변환합니다.
* log.info("The time is now {}", ...): 콘솔 창에 정보를 출력합니다. {} 부분에 변환된 시간 문자열이 차례대로 대입되어 최종적으로 "The time is now 12:15:30"과 같은 형태로 로그가 기록됩니다.
