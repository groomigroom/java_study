스프링 부트에서 implements CommandLineRunner는 스프링 부트 애플리케이션이 실행된 직후에 특정 코드를 자동으로 실행하고 싶을 때 사용하는 [인터페이스](https://hoft.tistory.com/entry/Spring-%EC%95%A0%ED%94%8C%EB%A6%AC%EC%BC%80%EC%... run() 메서드를 구현하여 서버가 켜질 때 필요한 초기화 작업을 수행합니다.주요 특징자동 실행: 스프링 빈(@Component 등)으로 등록하면 서버 구동 완료 후 run() 메서드가 한 번 실행됩니다.인자 전달: 프로그램 실행 시 전달된 커맨드 라인 인자(String[] args)를 파라미터로 받아 활용할 수 있습니다.주로 언제 쓰나요?초기 데이터(Dummy Data) 삽입: DB에 기본 계정이나 테스트 데이터를 미리 넣을 때서버 시작 확인 및 로그 출력: 연결 상태를 테스트하거나 준비 완료 상태를 알릴 때캐시 미리 로딩: 앱 구동 전 미리 메모리에 올려야 할 데이터가 있을 때
